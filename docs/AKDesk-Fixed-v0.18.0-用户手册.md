# AKDesk Fixed v0.18.0 用户手册

> 适用系统：macOS 12 或更高版本  
> 默认地址：`http://127.0.0.1:8765`

## 1. 使用前须知

AKDesk Fixed 是本地个人研究工具，不是交易终端。使用市场数据时请同时检查：

- 观测时间：数据代表的市场、统计或自然年度；
- 抓取时间：本机取得数据的时间；
- 数据状态：最新、缓存、过期、降级或演示；
- 研究可用性：来源、时点和质量是否满足研究门禁。

盘前、午休、盘后和非交易日不等于数据不可用。应用会保留最近可信快照并标明市场阶段。

## 2. 安装、启动与关闭

系统要求：

- Python 3.11、3.12 或 3.13；
- 首次安装依赖时可访问网络；
- 推荐至少保留 1 GB 可用空间；
- Safari、Chrome 或其他现代浏览器。

在 Finder 中双击 `start-macos.command`。首次启动会创建独立 `.venv`、安装依赖、检查前端构建并打开：

```text
http://127.0.0.1:8765
```

服务只监听本机。关闭启动终端或在原启动窗口按 `Control+C` 即可停止；只关闭浏览器标签不会停止服务。

`Control+C` 只对当前终端前台运行的服务有效。如果找不到原启动窗口，或服务由其他终端、IDE 或 Codex 会话启动，请双击 `stop-macos.command`。停止器会先确认 `127.0.0.1:8765` 返回当前 AKDesk 版本，再向对应进程发送正常终止信号；如果端口属于其他程序，不会误杀。

需要离线体验时，双击 `start-macos-demo.command`。演示数据不代表真实市场，不会触发正式提醒，也不能保存为可信市场证据。

如 macOS 阻止脚本，右键选择“打开”。若脚本没有执行权限，在项目目录运行：

```bash
chmod +x start-macos.command start-macos-demo.command stop-macos.command
```

## 3. 首次进入与入口设置

首次打开会看到四类任务：

1. 每日看市场：进入“市场变化”；
2. 利率与宏观研究：进入“研究首页”；
3. 信用观察：进入“信用观察 R2”；
4. 全球跨市场：进入“外汇市场”。

选择会保存为默认场景，只影响落地页和导航顺序，不会拆分数据。顶部可随时切换“市场 / 投研”导航；点击齿轮“入口设置”可更换默认场景，并可直接打开数据健康或 AI 隐私设置。

常用快捷键：

- `Command + 1`：回到当前模式首页；
- `Command + K`：打开全局搜索；
- 浏览器后退 / 前进：返回应用内上一页或下一页。

## 4. 推荐的每日市场流程

### 第一步：看市场变化

进入“市场变化”，先查看：

- 上一收盘以来：适合盘前或跨日观察；
- 上次查看后：适合盘中再次进入；
- 优先级和质量阈值：先保留高优先级、质量合格的变化；
- 来源、观测时间和可信状态：决定是否可以继续研究。

点击一条变化可回到资金、曲线、期货、现券或外汇原始模块。确认阅读后可“标记已读”；该操作只改变本机阅读状态，不修改行情数据。

市场变化只呈现满足可信和可行动门禁的变化。某模块没有结果时，应先查看空状态说明，再到“数据健康”检查数据源，而不是把零条变化理解为市场没有变化。

### 第二步：回原始模块核验

按变化类型检查原始数据：

- 资金变化 → 资金面；
- 关键期限与利差 → 收益率曲线；
- 合约方向 → 国债期货；
- 单券与成交 → 现券市场；
- 人民币或外币对 → 外汇市场。

确认来源、时点、缓存年龄和质量后，再加入自选、保存市场快照或建立项目。

### 第三步：复盘

在“每日复盘”检查系统汇总，补充个人判断后归档或导出 Markdown / 打印 PDF。周末或固定研究日进入“每周复盘”，处理到期项目、反证和下周待验证事项。

## 5. 建立研究项目与使用行动助手

在“研究项目”中可以从模板或空白问题立项。建议至少填写研究问题、假设和复盘日期，再逐步补充证据、反证、结论和置信度。

选择一个项目后，“研究行动助手”会检查项目缺口：

1. 点击生成建议；
2. 阅读每条草稿的依据、类型和来源；
3. 只勾选希望写入的任务、反证或复盘；
4. 点击采纳；
5. 在系统确认框中再次确认；
6. 检查写入结果。

未勾选或未确认的草稿不会修改项目。同一草稿有重复保护；误写后可在行动助手中撤销。AI 生成的内容仍是待核验草稿，不能替代用户判断。

“导入、备份与恢复”区域支持：

- 导出 / 导入单个项目 JSON；
- 下载完整研究库备份；
- 立即创建安全备份；
- 从备份恢复整个研究库。

恢复会覆盖当前研究库，系统会先保存恢复前副本。执行前仍建议额外下载一份备份。

## 6. 专题投研与跨源综述

“专题投研”适合长期跟踪一个主题、主体或研究对象。可添加市场历史、FRED 图表、World Bank 比较、GDELT 事件雷达、项目摘要和最近证据组件，并在跨源时间线中查看研究活动。

推荐流程：

1. 新建专题并明确问题；
2. 添加所需组件；
3. 将市场快照、FRED 引用、主权比较或已核验事件加入证据篮；
4. 批量提交到研究项目并关联专题；
5. 在专题时间线中检查证据、笔记、反证和结论变化；
6. 定期生成专题 AI 综述。

专题 AI 只接收标题级摘要、来源和时点元数据，不发送笔记正文、新闻正文或完整结论。它会整理共同变化、来源分歧、证据缺口和下一步核验，不会自动写入专题或项目。

## 7. 信用观察 R2

### 导入

进入“信用观察 R2”，使用 CSV / Excel 映射导入。先确认字段映射、日期和单位，再提交。空白可选列可以保留为空。

### 观察

- 单券：查看最多 20 条一段的多期记录；
- 发行人：汇总主体相关债券，并可进入事件专题或一键立项；
- 组合：搜索成员、仅看已选并建立自定义观察范围；
- 事件与信号：查看到期事项和待人工确认的规则信号。

利差只有在字段、评级日期、收益率与基准同日、期限匹配时才会显示。缺失结果是可信门禁生效，不应手工把不同口径数据强行拼接。

所有信号均需人工核验。可记录核验备注并沉淀到研究项目；系统不生成评级或违约概率。

## 8. FRED、World Bank 与 GDELT

### FRED

在“美国宏观与利率”输入本人 32 位 FRED API Key并验证。成功后 Key 只存于 macOS Keychain。

- 观测值按需请求，不写入 SQLite；
- 图表证据只保存序列、来源、观察区间和变换引用；
- 用户主动导出的 CSV 可包含本次请求取得的数值；
- 使用前请遵守 FRED 及上游数据提供者条款。

### World Bank

无需 Key。在“全球主权比较”选择 2–8 个经济体、指标和年份。系统按同一年度对齐，不跨年填充；数值排名不代表主权信用或投资判断。成功观测缓存 7 天。

### GDELT

无需 Key。事件雷达只缓存标题、链接、来源、语言和时间等元数据 12 小时，不保存新闻正文。所有结果都是待核验线索；加入证据前应打开原文核对主体、事实和上下文。

## 9. 配置 AI 助手与页面洞察

点击顶部“AI 助手”，输入本人 AIHubMix API Key，阅读第三方处理说明并验证保存。Key 只存于 macOS Keychain，也可通过环境变量 `AKDESK_AIHUBMIX_API_KEY` 提供。

顶部助手包括：

- 产品向导：解释当前页面和操作路径；
- 市场观察：整理当前可信市场线索；
- 研究教练：依据所选项目的裁剪摘要提出下一步与反证问题。

每次对话调用前都要检查发送预览并确认。回答只存在于当前抽屉，不自动写入研究资料。

展开“预算与页面洞察”可以：

1. 设置每日调用次数和 token 预算；
2. 分别授权今日市场、研究项目、信用观察和专题综述；
3. 选择仅手动、数据变化后或每日首次打开；
4. 查看今日总用量与各模块用量。

四个模块默认关闭。页面 AI 卡片会明确显示发送范围、摘要生成时间、模型和缓存状态。可清除当前摘要；清除只删除本地最终摘要，不删除业务数据。页面摘要可以带入助手继续追问，但仍不会自动落库。

不要把 AI 输出视为事实、信用判断或投资建议。涉及数字、时点和结论时，应回到原始来源核验。

## 10. 自选、提醒与搜索

统一自选支持证券、外汇和宏观指标，可设置分组、标签、状态、置顶、备注和复盘日期。

提醒只对可判断的可信实时字段生效。设置阈值前可用当前值试算，并配置静默时段与每日上限。宏观指标、缺少可信观测时点的外汇、演示数据和过期缓存不会被误当作实时触发条件。

使用 `Command + K` 可搜索页面、现券、期货、转债、外汇、FRED 指标和专题。未输入文字时提供常用任务入口，该过程不调用 AI。

## 11. 数据不可用时的检查顺序

1. 看页面上的市场阶段：是否未开盘、午休、盘后或非交易日；
2. 看数据状态：最新、缓存、过期、降级或演示；
3. 打开“数据健康”，检查连接状态和研究可用性；
4. 查看错误、缓存年龄、连续失败和熔断状态；
5. 对单一数据源执行重试；
6. 如多个模块都无法访问，确认本机网络与系统代理；
7. 刷新浏览器；若顶部提示本地服务断开，确认启动终端仍在运行。

“Failed to fetch”通常表示浏览器无法连接本地服务、外部接口超时或系统代理中断。先确认 `http://127.0.0.1:8765/api/v1/health` 可打开，再查看数据健康。AI 单独失败时还要检查 Key 验证、预算、模块授权和 AIHubMix 连接。

不要因为已过交易时间就直接判断数据不可用。日频或收盘数据在盘后仍可有效，只是不会被标记为盘中实时。

## 12. 隐私、备份与重置

- AIHubMix 与 FRED Key 只保存在 macOS Keychain，不写 SQLite、日志、前端缓存或导出；
- 全新 v1.0 发布包默认使用 `~/Library/Application Support/AKDesk Fixed/`；已有旧版项目检测到本地 `data/` 时继续使用原目录；
- 数据目录中的 `akdesk-fixed.db` 保存研究项目、专题、信用观察、自选、提醒和最终 AI 摘要等本地资料；
- 数据目录中的 `market-cache.db` 保存最近一次中国市场真实行情；
- FRED 观测值与 GDELT 新闻正文不持久化；
- 自动备份默认每 24 小时检查一次并滚动保留 14 份；
- 数据健康中的“清空缓存”不会删除研究项目、研究证据、自选、提醒或日报归档。

完全重置前先停止应用并下载研究库备份。删除数据库会不可逆地丢失本地资料，因此不要在未备份时操作旧版 `data/` 或 `~/Library/Application Support/AKDesk Fixed/`。

## 13. 使用边界

公开接口可能调整、限流或临时不可用。AKShare / AKTools 是数据访问层，不代表交易所授权行情；FRED 序列可能继承上游版权要求；World Bank WDI 使用其开放许可；GDELT 原文仍受来源网站条款约束。

AKDesk Fixed 不承诺实时性、连续性或准确性，仅供个人学习与研究，不构成投资建议。

## 14. 升级到后续正式版

升级前应先在“研究项目 → 导入、备份与恢复”下载一份完整研究库备份，再关闭旧版服务。不要把新版文件直接覆盖到仍在运行的旧版目录，也不要手工复制 `.db-wal` 或 `.db-shm` 文件。

v0.18.0 已用 schema 701、800、900、1100、1201 和 1301 的真实历史备份副本验证升级到 schema 1600；正式版仍会继续保留迁移与恢复门禁。将来使用 v1.0 候选版时，应优先在副本上验证：

1. 新版首次启动成功；
2. 数据健康可打开；
3. 原有项目、自选、信用观察和日报数量正确；
4. 下载备份与恢复演练成功；
5. 再把新版作为日常目录使用。
