## Review 要点与用例

| 检查 | 验收口径 |
| --- | --- |
| E01 首任务路由 | 静态首页主按钮进入 `#/start`，本地帮助入口进入独立合成任务；旧演示和案例深链仍可用。 |
| E02 合成数据与核验门槛 | 两个共同日期的价格变化为 +2.00% / -1.00%，缺失日保留为空；用户核对后才能继续。 |

| E04 草稿与反馈 | 上一步保留、离开或重置清空。反馈不默认选中“完成”；结果、安装和真实复访独立，预览只包含白名单选项。 |
| E05 真实页面退化 | 一组报价失败或缺值时明确分类；另一组仍显示。故障详情不外泄，跳合成任务须用户主动操作，不替换真实数据。 |
| E06 启动预检 | 缺少入口 JS/CSS、空入口、越界路径或远端入口均拦截，并给出重新解压/构建指引；不连接外网或创建数据目录。 |
| E07 交付 | 正式和独立演示构建、ZIP 文件检查、解压后本地 HTTP 冒烟。无用户数据或凭据，不连接真实行情和 AI。 |

## 本地验证结果

- 后端 Python 3.11、3.12、3.13 各 320 项通过；前端 40 个测试文件、153 项通过。Ruff、ESLint、CSS 变量检查、TypeScript、正式/静态演示构建、启动脚本语法检查均通过。
- Python 锁定运行环境依赖检查通过；npm 完整审计（含开发依赖）未发现告警。本次未升级任何依赖版本。
- 本地候选 ZIP 通过版本、文件清单、脚本权限、文档链接、凭据与用户数据排除检查。解压后以隔离 HOME/数据目录和既有锁定 Python 环境启动，预检、健康版本、首页/首任务资源、FRED 不落盘响应标记和既有跨资产/研究工作流合成冒烟通过。
- 未认证全新机器冷安装、实机视觉和外部用户任务耗时。合成验证不使用真实行情或付费 AI，也不证明真实用户完成、安装或复访。

## 测量口径

通过合成案例和 GitHub 自愿反馈验证，而非后台追踪。阅读、样例完成、安装成功、七日内实际复访各自记录；同一人的重复反馈不算新用户。任务用时是体验目标，单元测试不证明外部用户能在三分钟内完成。

建议发布后让外部用户不经指导走同一条路径：争取至少 3 位完成并核对底稿、2 位在七日内实际再次使用。记录他们在理解、核验、导出、安装中的卡点。样本不足继续验证，不据此扩充资产或下单能力。真实用户使用及兼容性观察尚未发生在这次本地验证中。
