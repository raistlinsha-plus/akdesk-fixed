# AKDesk Fixed v1.4.0 · 开发与验收记录

日期：2026-11-07。范围：本地候选，不含 GitHub Release、Pages 上线或 Inkstone 同步。

## 变更与验收口径

| 范围 | 验收口径 |
| --- | --- |
| 实例识别 | 同实例可复用；同版本演示/正式冲突、数据目录变化应拒绝；另一安装停止器不发信号；自定义端口可用对应停止器停机 |
| 资源完整性 | 缺少按需页面、清单不全或 ZIP 内资源被改动时预检失败，不提示为上游行情异常 |
| 体验反馈 | 默认「未说明」，仅用户主动选择才记录安装结果 |
| 复盘口径 | 两个紧邻区间的最后有效观测；本期或前期缺失不算变化；债券用 BP，其余使用各自价格或汇率百分比；不会补入期外数据 |
| 降级与导出 | 各来源独立；区分读取失败、旧缓存和本地无观测；真实导出只含引用和用户输入，合成版无需 API |
| 安装包路径 | 校验压缩包及清单，从解压副本启动；加载首任务并实际下载底稿，再验证合成周复盘导出 |

开发者可用 `python scripts/smoke_local_release.py` 做隔离启停；可指定已解压且已备好锁定依赖的路径，并加 `--browser` 在 macOS Chrome 临时配置中验证下载。该测试不碰现有研究库，也不检查上游当前可用性。

## 本轮验证

- 后端 Python 3.11／3.12／3.13 各 328 项通过；前端 159 项通过，正式与静态演示均完成构建。
- macOS 解压副本完成自定义端口启停、同实例复用、模式/数据目录冲突拒绝和跨目录停止拒绝。移除按需帮助页资源后预检拒绝启动。
- 解压包的首任务与固定合成周复盘在 Chrome 中完成交互，实测下载并核对两份 Markdown 内容；测试复用既有锁定依赖，不代表冷安装已验证。

外部冷安装、Safari 手动验收和七日真实复访需另行观察；自动化验证不等同于外部用户证据。没有扩大个股、持仓或实盘范围。
