# AKDesk Fixed v0.6 投研工作台规划 v2

> 实施状态：v0.6.1 市场投研联动版已完成；中国固收市场线索、可信市场快照和观点轨迹已落地。为控制版本风险，信用观察 R1 与 World Bank 主权比较调整到后续独立版本。

> 本文替代“仅以自选研究工作台＋信用观察为核心”的初版设想。新版定位扩展为个人宏观固收投研工作台，自选和信用观察仍保留，但不再是全部主线。

## 1. 版本定位

版本代号：`v0.6「宏观固收投研工作台版」`

版本目标：让用户在一个本地应用里完成“发现问题—组织数据—形成观点—跟踪证据—输出复盘”的完整研究流程，而不只是查看行情或收藏标的。

核心价值：

1. 把 AKShare 的中国固收行情、FRED 的美国宏观与利率数据、World Bank 的跨国结构数据统一为可追溯的研究数据层。
2. 把证券自选升级为“证券＋宏观指标＋研究主题”的统一关注体系。
3. 用研究项目、证据卡片、数据快照和复盘记录承载观点，避免图表看完即丢失。
4. 所有结论均能追溯到数据源、观察期、发布日期、版本和变换方法。

## 2. 数据源定位

### 2.1 AKShare / AKTools

继续作为中国市场层，覆盖资金面、国债收益率曲线、现券、国债期货、可转债和发行事件。

### 2.2 FRED

定位为高优先级的美国宏观、货币政策和利率研究源，首期接入：

- 序列元数据和历史观测值；
- 数据发布日历；
- 序列更新时间和修订版本；
- 利率、通胀、就业、增长、流动性和金融条件主题指标包。

FRED API 必须使用用户自己的 API Key。应用只提供本地配置入口，不内置公共 Key。API Key 优先保存在 macOS Keychain，环境变量作为开发模式回退，禁止写入 SQLite、日志、导出文件或前端状态。

FRED 序列可能由第三方拥有版权。每条序列必须保留原始来源、版权说明和推荐署名；应用设置页和数据页需显示 FRED 要求的非背书声明。

### 2.3 World Bank Indicators API v2

定位为低频的主权基本面和跨国结构研究源，首期接入：

- GDP 增长、通胀、财政与政府债务；
- 经常账户、外汇储备和外债；
- 人均收入、产业结构和人口等长期变量；
- 国家、地区、收入分组和指标元数据。

World Bank Indicators API v2 无需 API Key。数据刷新按指标频率采用日级或周级调度，不进入盘中行情刷新队列。

### 2.4 接入原则

FRED 和 World Bank 均采用直接官方 API 适配器，不通过 AKShare 二次转接。三个 Provider 共享统一研究数据契约，但拥有独立缓存、熔断、重试和健康状态，任一海外源故障不得影响中国行情主链路。

## 3. 核心投研场景

### 3.1 每日宏观固收晨报

用户打开首页即可看到：

- 中国资金面、收益率曲线和国债期货状态；
- 美国政策利率、国债期限利差、实际利率和通胀预期；
- 最近更新的宏观指标及其前值、修订值和变化；
- 今日/未来七天宏观数据发布日历；
- 自选证券与自选指标的异常变化；
- 当前研究项目的待验证证据和下次复盘日期。

首期不提供“市场预期差”，因为 FRED 和 World Bank 不稳定提供一致的市场一致预期。允许用户手工录入预期值，系统只计算“实际－用户预期”。

### 3.2 中美利率与宏观传导研究

提供预设研究模板：

- 美联储政策路径—美国国债曲线—中美国债利差；
- 通胀—实际利率—期限利差；
- 就业与增长—政策利率—风险偏好；
- 中国资金面—国债曲线—国债期货基差/价格变化。

用户可以替换指标、调整区间和变换方式，并把结果保存为研究证据卡片。

### 3.3 数据发布复盘

围绕单次数据发布展示：

- 发布日期和对应观察期；
- 最新值、上一期值、上一期修订前后值；
- 同一数据发布前后的利率与曲线变化；
- 用户预期、研究笔记和结论；
- 下一次计划发布日期。

发布日历只代表数据提供方公布的计划，不承诺该时刻 FRED 已经完成数据更新。

### 3.4 主权基本面比较

用户选择 2–8 个国家或经济体，对比 World Bank 的年度/季度指标：

- 增长与通胀；
- 政府债务与财政状况；
- 经常账户、外储和外债；
- 人均收入和结构性指标。

支持水平值、同比、区间变化、排名、分位数和标准化显示。不同频率和不同年份的数据不得自动填充为同一期，必须显式显示可比年份和缺失值。

### 3.5 自选研究工作台

自选对象扩展为三类：

- 证券：现券、国债期货、可转债；
- 指标：FRED、World Bank 和中国宏观/利率指标；
- 研究主题：用户创建的研究项目。

支持分组、标签、研究状态、置顶、最近变化、笔记、提醒和下次复盘日期。首页展示“需要处理的自选”，而不只是完整列表。

### 3.6 信用观察 R1

保留原规划中的信用债列表、发行人观察、评级日期、剩余期限和参考信用利差，并增加宏观研究联动：

- 信用利差与国债/政策金融债曲线对比；
- 发行人所属行业与宏观主题关联；
- 信用标的一键加入研究项目；
- 信用异动进入每日复盘的“待研究证据”。

信用观察仍是筛查工具，不输出内部评级、违约概率或买卖建议。

## 4. 核心产品模块

### 4.1 投研首页

- 市场状态与宏观状态摘要；
- 今日数据发布和最近更新；
- 自选异动、待研究、待复盘；
- 当前研究观点摘要；
- 数据健康与最新缓存时间。

### 4.2 宏观数据库

- 按国家、主题、频率、来源搜索指标；
- 查看元数据、单位、季调方式、观察期和更新时间；
- 收藏指标并加入研究项目；
- 提供官方链接、版权和署名信息。

首期采用精选指标目录加搜索，不在本地预抓取 FRED 全库或 World Bank 全量指标。

### 4.3 图表研究室

支持最多 6 条序列组合，并提供：

- 原值、环比、同比、年化、差分；
- 移动平均、累计变化、基期归一化；
- Z-Score、分位数；
- 两序列利差、比率和相关性；
- 双轴、不同频率对齐和缺失值策略说明。

每张图必须保存“输入序列＋时间范围＋变换链＋数据版本”，并能冻结为研究证据快照。

### 4.4 研究项目

研究项目是 v0.6 的核心新对象，字段包括：

- 研究标题、研究问题和初始假设；
- 研究期限、状态、标签和下次复盘日期；
- 证据卡片：图表、数据表、自选标的快照；
- 研究笔记、反方证据和风险点；
- 当前结论、主观置信度及其变更记录。

工作流：`草稿 → 跟踪中 → 已形成观点 → 待复盘 → 已归档`。

### 4.5 研究输出

- 日报：市场、宏观更新、自选异动和待验证观点；
- 周报：一周数据变化、研究项目进展和下周发布日历；
- 专题导出：研究问题、核心图表、证据、结论和数据说明；
- 支持 Markdown、打印/PDF；所有输出自动附带来源和数据日期。

## 5. 数据可信设计

统一研究序列模型：

```text
provider / series_id / title
country / topic / source_organization
frequency / unit / seasonal_adjustment
observation_period / value
release_date / realtime_start / realtime_end
fetched_at / transformation_chain
license / attribution / source_url
trust_level / quality_issues
```

必须区分四种时间：

1. `observation_period`：指标描述的经济时期；
2. `release_date`：数据对外发布日；
3. `vintage_date`：当时可获得的数据版本；
4. `fetched_at`：应用实际抓取时间。

任何图表、结论和导出都不能只保留一个模糊的“日期”。

研究快照默认冻结数据版本，后续官方修订时显示“数据已修订”，但不静默改写历史研究结论。

## 6. 技术架构

### 6.1 Provider

```text
AKShareProvider ───── 中国市场行情
FredProvider ──────── 美国宏观、利率、发布与版本
WorldBankProvider ─── 主权与跨国结构指标
          │
          ▼
Unified Research Series Contract
          │
          ├── SQLite 元数据与观测值缓存
          ├── 研究快照与变换记录
          ├── 有界刷新队列与独立熔断
          └── 数据健康与署名信息
```

### 6.2 FRED 接口范围

首期使用按序列增量查询能力：

- series metadata；
- series observations；
- series vintage dates；
- releases / release dates；
- series search 作为可选搜索补充。

不在 v0.6 全量同步 FRED 数据库。FRED API v2 的按 Release 批量历史能力留待后续数据仓库版本评估。

### 6.3 World Bank 接口范围

- API v2；
- country、region、income level、indicator 元数据；
- 多国家、多指标查询；
- JSON 响应与分页；
- 首期限定精选 WDI 指标包。

### 6.4 刷新策略

- AKShare：保持现有盘中/收盘 TTL；
- FRED 自选序列：按频率和发布日期调度，事件窗口适度加密，其他时间低频检查；
- FRED 发布日历：每日刷新；
- World Bank 元数据：每周刷新；
- World Bank 指标：每日或每周刷新，不参与盘中轮询；
- 所有源遇到 429 或服务端错误时指数退避，手工刷新仍受去重和队列上限约束。

## 8. 分阶段交付

### v0.6.0 — 投研工作台基础版

P0：

- 研究项目、证据卡片、研究笔记和复盘状态；
- 证券/指标/主题统一自选；
- FRED API Key 本地安全配置；
- FRED 精选指标、观测值、元数据、发布日历和版本信息；
- 图表研究室基础变换与研究快照；
- 投研首页和日报联动。

### v0.6.1 — 市场投研联动版（已完成）

P1：

- 中国固收市场研究线索；
- 可信市场快照与研究项目联动；
- 观点、置信度和证据变更轨迹；
- 演示、低质量和异常数据的证据写入闸门。

### v0.6.2 — 数据修订与研究复盘增强

P2：

- FRED 修订版本对比；
- 数据发布前后市场窗口分析；
- 研究结论版本历史；
- 用户手工预期与实际偏差；
- 研究项目归因和复盘统计。

信用观察 R1 与 World Bank 主权比较从 v0.6.1 拆出，待数据覆盖率和字段 POC 通过后分别立项。

## 9. 验收标准

### 投研闭环

- 用户可在 5 分钟内完成“选择指标—生成图表—冻结证据—写入观点—设置复盘日期”。
- 任一研究结论可回溯到原始序列、数据日期、版本和变换方法。
- 数据官方修订后，历史证据不被静默覆盖。
- 日报可汇总中国固收、FRED 更新、自选异动和待复盘观点。

### 数据源

- 未配置 FRED Key 时功能清晰降级，不影响其他模块。
- FRED Key 不出现在 API 响应、日志、SQLite 和导出文件中。
- World Bank 缺失年份保持为空，不自动填零或跨年冒充。
- 任一海外 Provider 失败不会阻塞 AKShare 行情。

### 性能与设备

- MacBook Air 有缓存时投研首页 P95 API 响应低于 300 ms；
- 图表最多 6 条序列、20 年月频数据时交互流畅；
- 外部抓取继续受固定并发和有界队列约束；
- 离线时可查看最近缓存、研究项目和冻结证据。

### 测试

- 覆盖频率对齐、同比/环比、版本修订、缺失值和数据日期语义；
- 覆盖 FRED Key 脱敏、401/429、熔断和缓存回退；
- 覆盖 World Bank 分页、多国家查询和缺失年份；
- 覆盖研究项目、快照冻结、导出署名和数据库迁移；
- 完成键盘可访问性、1440×900 布局和 macOS 启动回归。

## 10. 明确不做

v0.6 不包含：

- 自动生成买卖建议或违约概率；
- 未经授权的专业实时行情或一致预期数据；
- 全量镜像 FRED / World Bank；
- 新闻爬虫、舆情情绪模型；
- 云同步、多人协作和券商交易接口；
- 自动用最新修订数据重写历史研究结论。

## 11. 开发前硬门槛

1. 用 20–30 条 FRED 精选序列完成 API Key、元数据、观测值和 vintage POC。
2. 用 8–12 个 World Bank 指标、10 个经济体完成频率/缺失值/年份对齐 POC。
3. 确认 macOS Keychain 方案和开发环境变量回退方案。
4. 完成统一研究序列、研究快照和数据署名的数据模型评审。
5. 先交付研究项目与 FRED 主链路，再启动信用和 World Bank 页面，避免范围失控。
