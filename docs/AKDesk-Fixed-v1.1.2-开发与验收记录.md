## Review 中额外修复

1. 启动器仍硬编码旧 AKShare 1.19.1，与现有锁定 1.20.22 不一致，会导致重复启动再次走安装。现直接从实际 lock 读取预期版本，增加匹配/不匹配回归；不变更生产依赖。
2. 既有限流测试将 time.time 前移 299 秒，接近午夜时会令 date.today 的样例跳到次日，而未来日期校验用 datetime.now，造成假失败。现独立固定来源观测日，并参数化午夜边界。没有放宽生产未来数据保护或冷却门禁。
3. 原静态简报“已经完成路径”的文案改为“到达成品页”，不再凭页面到达宣称完成；补上新路由/模板待部署说明与小屏导航横向容纳保护。

反馈字段使用 GitHub 文档明确支持 URL 预填的文本输入，不依赖下拉框的未确认预选行为。依据：[GitHub 创建 Issue 的 URL 查询说明](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue#creating-an-issue-from-a-url-query)。没有为验证而在公网提交测试 Issue。
