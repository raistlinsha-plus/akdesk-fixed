# AKDesk Fixed v1.0.0 用户手册

## 1. 运行要求

- macOS 12 或更高版本；
- Apple Silicon MacBook Air 为主要适配设备；
- Python 3.11、3.12 或 3.13；
- 首次安装依赖时需要网络；
- 日常运行不需要 Docker、Rust 或常驻 Node.js。

## 2. 安装与启动

解压发布包后，双击：

```text
start-macos.command
```

首次启动会：

1. 创建当前程序目录专属的 `.venv`；
2. 按 `backend/requirements.lock` 安装精确生产依赖；
3. 启动只监听本机的服务；
4. 打开 `http://127.0.0.1:8765`。

依赖没有变化时，后续启动不会重复安装。

若 macOS 首次阻止脚本运行，请右键脚本并选择“打开”。若执行权限丢失，在项目目录运行：

```bash
chmod +x start-macos.command start-macos-demo.command stop-macos.command
```

完全离线体验界面时，可双击 `start-macos-demo.command`。演示数据不可用于研究。

## 3. 停止服务

推荐两种方式：

- 在原启动终端窗口按 `Control+C`；
- 双击 `stop-macos.command`。

`Control+C` 只对当前获得键盘输入的原启动窗口生效。如果服务由另一个终端、IDE 或 Codex 会话启动，在新终端按 Control+C 不会影响旧进程，此时应使用停止脚本。

停止脚本会先确认 8765 端口运行的是当前版本 AKDesk，再发送正常终止信号，不会盲目结束其他本地服务。

只关闭浏览器页面不会停止服务。

## 4. 数据保存位置

全新正式版默认使用：

```text
~/Library/Application Support/AKDesk Fixed/
```

主要内容包括：

- `akdesk-fixed.db`：研究项目、自选、信用观察、设置和本地摘要；
- `market-cache.db`：行情缓存；
- `backups/`：自动和手工备份；
- 运行时临时文件。

旧版目录如果已经存在自身 `data/` 数据库，会继续使用旧路径，不自动移动。可在“数据健康”页面查看实际数据目录。

不要在服务运行时直接复制或替换 SQLite、WAL、SHM 文件。

## 5. 首次使用

首次打开可选择：

- 每日看市场；
- 利率与宏观研究；
- 信用观察；
- 全球跨市场。

选择只影响默认落地页和导航顺序。顶部“市场 / 投研”可以临时切换，入口设置可以随时更改默认场景。

建议第一次按以下顺序：

1. 打开“数据健康”确认服务和数据源状态；
2. 打开“今日市场”了解页面结构；
3. 将一个债券、期货、外汇或宏观对象加入“我的自选”；
4. 创建一个研究项目；
5. 保存一条笔记或反证，并设置下次复盘日期；
6. 打开“每周复盘”查看研究活动如何被汇总。

## 6. 如何理解数据状态

每组数据都会尽量展示：

- 来源；
- 观测时间；
- 抓取时间；
- 市场阶段；
- 缓存和过期状态；
- 质量分；
- 可信级别；
- 是否可用于研究或提醒。

常见状态：

- 实时或最新：公开源返回了当前可用数据；
- 缓存：使用仍在有效期内的最近成功结果；
- 过期：实时刷新失败，保留最近真实数据供参考；
- 降级：部分字段或数据源不可用；
- 演示：内置样例，只用于体验；
- 未开盘 / 休市 / 已收盘：市场阶段，不等于数据源故障；
- 不可用于研究：来源、时点、质量或演示状态未通过门禁。

看到“数据不可用”时不要只根据交易时间猜测，应打开“数据健康”查看具体原因。

## 7. 市场入口

### 今日市场

用于每天快速查看资金、曲线、现券、国债期货、事件和外汇背景。首次使用清单会引导完成数据检查、自选、专业模块和复盘。

### 市场变化

把“相较上一收盘发生了什么”和“自上次查看后发生了什么”放在一页。可按可信可行动、最低质量分和优先级筛选。

只有非演示、质量达标且可信状态合格的信号才可保存为研究证据。

### 我的自选与提醒

自选统一容纳多个对象类型。提醒只对健康、未过期的真实数据生效；演示和过期缓存不会触发系统通知。

### 每日复盘

自动汇总资金、曲线、期货、现券、事件和可信状态。归档保存在本机，可导出 Markdown 或打印为 PDF。

## 8. 中国固收模块

### 资金面

观察 Shibor 和资金利率变化。用于判断短端流动性，不代表实际成交价格。

### 收益率曲线

观察不同期限国债收益率和期限利差。可从曲线对象创建研究项目或进入图表研究。

### 现券市场

查看活跃券价格、收益率和变动。公开源字段不完整时，页面会明确降级，不应据此执行交易。

### 国债期货

查看 TS、TF、T、TL 等合约。产品提供观察线索，不计算正式套保方案。

### 信用观察 R2

信用工作台依赖用户核验字段，支持：

- 单券快照和历史；
- 主体聚合；
- 自定义组合；
- 基准利差；
- 评级和复盘时间线；
- 字段覆盖率；
- 规则信号和信用日程；
- CSV / Excel 导入预览。

缺少必要字段时不计算严格利差。规则信号不是评级或违约判断。

### 可转债和国债发行

可转债用于观察价格、转股价值、溢价率和双低等公开字段；国债发行用于安排待发行和近期发行事件。

## 9. 全球与宏观模块

### 外汇市场

人民币参考价为日频观察数据；全球外币对是公开银行间询价快照，不是可成交报价。两条链路分别显示健康状态。

### FRED

进入“美国宏观与利率”后输入本人申请的 FRED API Key。连接验证成功后，Key 只保存在 macOS Keychain。

FRED 观测值按请求获取，不写入 SQLite。用户主动导出 CSV 时会保存数值、vintage、来源和变换说明。

### World Bank

用于跨经济体结构比较。数据会持久缓存，并保留 World Bank 来源与许可说明。

### GDELT

用于发现事件线索。产品不缓存新闻全文；研究人员必须打开原文并交叉核验。

### 图表研究室和发布复盘

图表研究室支持多序列、差值、同比、频率处理和标准化。数据发布复盘用于记录预期、官方值、偏差和事件窗口。

## 10. 研究工作流

### 研究项目

一个项目可以记录：

- 研究问题和假设；
- 状态、信心和时间范围；
- 证据与反证；
- 笔记、任务和复盘；
- 结论和下一复盘日；
- 观点变化时间线；
- 市场、主权和图表快照。

项目支持 Markdown 和 JSON 导出。

### 专题投研

专题可以关联多个项目和外部数据组件，用于组织中美利率、人民币利率、信用主题等跨源研究。

### 每周复盘

每周复盘汇总活跃项目、本周更新、研究笔记、反证、完成和未完成任务，并提示下周需要验证的内容。它不自动生成投资结论。

## 11. AI 助手

点击顶部“AI 助手”，输入本人 AIHubMix API Key。当前固定使用 `deepseek-v4-flash-think`。

Key 验证后只保存到 macOS Keychain，也可由环境变量 `AKDESK_AIHUBMIX_API_KEY` 提供。

使用原则：

- 对话发送前展示数据范围并要求确认；
- 页面洞察默认全部关闭；
- 可分别授权市场、项目、信用和专题场景；
- 只发送当前场景需要的裁剪摘要；
- 不发送数据库、完整行情表、附件正文或新闻全文；
- 对话不落库；
- 页面只缓存最终摘要和生成元数据；
- AI 不自动修改项目、评级、仓位或交易指令；
- 研究行动草稿只有经用户选择和确认后才写入。

达到每日次数或 token 预算后，系统会拒绝新请求但不影响其他功能。

## 12. 备份、升级和恢复

升级前在“研究项目”页面创建备份。

升级流程：

1. 停止旧服务；
2. 保留旧程序目录；
3. 解压新版本；
4. 启动新版本；
5. 在“数据健康”确认版本、schema 和数据路径；
6. 打开既有项目检查内容。

恢复备份前应先创建当前状态备份。损坏或不是 AKDesk 数据库的文件会被拒绝。

## 13. 常见问题

### 页面显示 Failed to fetch 或无法连接本地服务

确认启动终端仍在运行。若已关闭，重新双击 `start-macos.command`。

### Control+C 没有反应

确认光标位于原启动终端。若找不到该窗口，双击 `stop-macos.command`。

### 首次安装出现证书错误

启动器会优先使用 Python 的 certifi CA。若仍失败，运行 Python 安装目录中的 `Install Certificates.command` 后重试。

### 行情过了交易时间就不可用吗

不一定。页面会区分未开盘、休市、收盘、缓存过期、连接失败和字段异常。请在“数据健康”查看数据源错误和缓存年龄。

### 如何完全删除个人数据

先停止服务，确认“数据健康”显示的实际数据目录，再自行备份并删除该目录。仅删除程序解压目录不一定会删除位于 `~/Library/Application Support/AKDesk Fixed/` 的用户数据。

## 14. 使用边界

本产品仅供研究参考，不构成投资建议。不要将其作为交易执行、正式估值、会计核算、自动评级、监管报送或机构数据再分发系统。
