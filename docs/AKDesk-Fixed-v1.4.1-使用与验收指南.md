# AKDesk Fixed v1.4.1 · 周复盘可用性版

2026-11-08。沿用 [v1.4.0 的四条序列和观测口径](./AKDesk-Fixed-v1.4.0-产品与使用指南.md)，重点解决「一项读取慢」「某周数据不足」和「查完来源找不到之前的草稿」。安装包见 [v1.4.1 Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/tag/v1.4.1)。

## 怎么用

1. 从市场或投研入口进入「股债金汇周复盘」。用日期框、前一周／后一周或最近已过周五选定日期，点击「读取本周」。切周不主动取数，不展示旧周结果。
2. 先看已返回的卡片，不用等齐四项。区分「读取失败」「旧缓存」「前期／本期没有观测」和「尚未读取」。出现缺项可只重读那一项；不会因此换源或绕过冷却。
3. 本地债、汇历史不足时，点卡片上的「到原模块核验」。在原模块核对或补充数据，再点页面顶部的「返回周复盘」。所选周及草稿会保留，可只重读刚核验的一项，其余项会标记为尚未读取。
4. 将判断和待核验事项导出为 Markdown。真实模式仍只有查询引用、所选区间及人工文字；未获取的值不补零，派生变化与观测日期不自动导出。文字不写库、不写浏览器存储；重载或关闭标签页后清空。合成样例的草稿与真实模式分开。

## 验收口径

- 一个来源挂起时其余卡片可用；重读只请求选中的序列，不触发其他请求。
- 切换日期中止旧请求，迟到的响应不会进入新日期或污染导出。
- 原模块回跳恢复选定日期和草稿，单项读取后其他项明确标记为「尚未读取」。
- 正式包经清单与 SHA-256 校验；解压后用隔离数据验证启停、首任务及周复盘，导出不得混入行情或样例值。
