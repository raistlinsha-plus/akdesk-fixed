# AKDesk Fixed v1.1.0 测试用例清单

编制日期：2026-10-22。对应版本：v1.1.0「GitHub 自助体验版」。本清单定义验收范围与预期，**不登记执行结果，也不表示已通过**；最终环境、计数、结果和证据由封版记录填写。

v1.0 的原有功能继续纳入回归，基线列表见 [v1.0 测试用例清单](./AKDesk-Fixed-v1.0.0-测试用例清单.md)。旧文档中的“通过”只代表该历史版本结果，不自动继承为 v1.1 结果。

类型：A＝自动化；M＝人工/浏览器；R＝构建与发布门禁。真实源、网络及需要用户 Key 的测试应单独记录条件，不能用演示结果替代。

## 1. 静态三步演示

| ID | 类型 | 操作/场景 | 预期 |
| --- | --- | --- | --- |

## 2. 一页简报与归档兼容

| ID | 类型 | 操作/场景 | 预期 |
| --- | --- | --- | --- |
| BRIEF-001 | A/M | 真实数据日报进入每日复盘 | 默认简报；可切完整复盘；资金、曲线、期货字段对应同一日报 |
| BRIEF-002 | A | `null`、缺省值、NaN、无穷与真实0 | 缺失不变成0，非有限数值不显示NaN；真实0保留 |
| BRIEF-003 | A | 无资金变化或无10Y水平/变动 | headline和模块提示待核验，不把空值判断为平稳或方向信号 |
| BRIEF-004 | A/M | 全示例、真实、混合、无来源元数据 | 标识对应真实模式；示例优先于外部传入的“live”标签 |
| BRIEF-005 | A/M | 来源日期不同、带时区/毫秒时间 | 保留日期与时区语义；观测区间不被当作同步采样时间 |
| BRIEF-006 | A | 来源URL含查询、片段、userinfo或非HTTP协议 | 去除查询和片段，拒绝userinfo与非HTTP链接 |
| BRIEF-007 | A/M | 读取v1.0旧日报归档 | 缺少逐源信息时明确待核验；不崩溃、不自动认定实时，不补造历史出处 |
| BRIEF-008 | A/M | 备注→完整复盘→简报；切日期再返回 | 当前模块按日期保留临时备注，不串入其他日期；不写入数据库 |
| BRIEF-009 | A/M | 复制与下载Markdown | 数值、单位、来源、状态、时点、示例标识与人工备注完整；内容与页面对应 |
| BRIEF-010 | M | 简报打印/PDF、取消、再次打印 | 仅打印目标底稿，内容不裁切；打印后恢复；不改变其他模块页面设置 |
| BRIEF-011 | M | 长备注和多行来源打印 | 允许合理分页，不因追求一页而丢失正文或可信边界 |
| BRIEF-012 | M | 完整复盘的原有导出与打印 | 活跃现券、事件、研究工作流仍可查看；不混入未保存的临时研究笔记 |

## 3. 首次启动与预检

| ID | 类型 | 操作/场景 | 预期 |
| --- | --- | --- | --- |
| START-001 | A/M/R | macOS、Python3.11/3.12/3.13正式包 | 锁定依赖可安装，预构建界面可启动；记录每种环境结果 |
| START-002 | A/M | Finder环境PATH未包含Homebrew | 找到受支持Python，或明确告知安装/指定解释器 |
| START-003 | A/M | Python缺失或不受支持版本 | 在安装依赖前停止并显示恢复指引 |
| START-004 | A/M | 缺少依赖锁、预检脚本、预构建界面 | 指出发布文件问题；区分正式包重新下载与开发构建 |
| START-005 | A | 项目/数据目录不可写，自定义相对数据路径 | 指向正确检查位置并提示恢复；不创建/删除研究数据 |
| START-006 | A/M | 默认CA位置缺失、实际TLS安装失败 | 位置检查与真实连接错误分开；提示证书恢复，不关闭校验 |
| START-007 | A/M | 磁盘不足、权限失败、包不兼容、网络失败 | 对应分类与可执行下一步；不原样泄露pip错误正文 |
| START-008 | A/M | 失效`.venv`、锁文件变化、第二次启动 | 环境可重建或更新；正常环境复用；不改动数据库 |
| START-009 | M | 同版本运行、旧版占端口、无响应占端口 | 不重复启动，健康探测有超时，给出对应停止/重试提示 |
| START-010 | M | Control+C与独立停止器 | 正常释放端口；停止器核验应用身份，不盲目杀其他服务 |

## 5. 可复现CLI与发布隔离

| ID | 类型 | 操作/场景 | 预期 |
| --- | --- | --- | --- |
| CLI-001 | A/R | `python -I -S examples/fixed_income_brief.py`重复执行 | 默认标准库、固定合成输出一致，不联网、不读凭据/用户库 |

| REL-002 | R | 版本、依赖锁、发布清单、SBOM与校验值 | 对应同一版本和实际产物；源码包与正式包说明准确 |

| REL-004 | R/M | 内链、深链、演示/下载/反馈入口 | 本地链接存在；外部发布状态单独核验，不凭代码存在认定已上线 |
