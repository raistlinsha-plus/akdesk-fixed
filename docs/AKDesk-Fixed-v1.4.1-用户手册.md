# AKDesk Fixed v1.4.1 · 用户手册

更新：2026-11-08。适用于 v1.4.1 的 macOS 本地版。在线演示使用独立的合成数据。

## 1. 第一次使用

可以在本地「使用与反馈」中完成三分钟首任务：观察两只合成 ETF，核验共同日期和缺失项，写一句自己的判断，再下载底稿。想先看周期任务，则进入「股债金汇周复盘」→「先看固定合成周复盘」。合成页不是行情来源，不把样例数值填进真实页。

## 2. 安装、升级与启停

主要适配 Apple Silicon MacBook Air。macOS 12+ 是兼容目标，Python 3.11–3.13 为支持范围；首次安装锁定依赖需要网络与约 1 GB 空间。普通使用不需要 Node.js、Docker 或 Rust。

1. 先停止旧版服务并保留升级前备份、旧程序及其数据目录。从 [v1.4.1 Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/tag/v1.4.1) 下载安装 ZIP 和校验文件，核对 SHA-256 后完整解压到新目录。自动生成的 Source code ZIP 不是预构建安装包。已更新的主工程可直接启动。
2. 双击 `start-macos.command`。预检会检查目录、依赖前置条件和界面资源；服务就绪才打开 `http://127.0.0.1:8765`。macOS 阻止脚本时，可右键「打开」。
3. 停止用原终端 `Control+C` 或同一安装目录的 `stop-macos.command`。关闭网页不停止服务。指定了 `AKDESK_PORT` 时，启停使用同一配置；正式版不会接入另一个安装、版本、模式或数据目录的服务。

演示默认使用独立数据目录。正式版继续识别原工程的旧数据目录，或使用平台默认本机目录；若旧版数据在旧的解压目录中或手动指定过位置，升级时明确保留或指定原 `AKDESK_DATA_DIR`。不要为解决端口、缓存或依赖问题删除研究库。回退保留 v1.4.0 程序，必要时恢复对应的升级前备份。

## 3. 每日工作：看变化、核验、再记录

在「市场」看今日市场和市场变化。遇到不寻常的值，回资金、收益率曲线、现券或期货核验实际观测日与来源；未开盘不等于上游故障，抓取时间也不是观测时间。可以在每日复盘中整理一页固收简报，添加临时备注、下载或打印。需要持续追踪时，再主动关联已有研究项目。

在「股债金汇观察」选择黄金、指数或四个示例 ETF；点击具体标的再按需读取日线。指数或不复权 ETF 的价格变化不是含分红、费用的总回报。对于跨资产查询引用，保存的是标识、来源和个人文字，不是数值快照。

## 4. 每周工作：用同一套口径复盘

1. 打开「股债金汇周复盘」，选择过去 90 天内且早于今天的结束日；支持前一周、后一周和最近已过周五。点击「读取本周」，四项独立返回。
2. 每项取本期和前期相邻七天区间内各自最后一个有效观测。股、金、汇显示百分比，10年国债收益率显示 BP；1 个百分点 = 100 BP。日期不同不做组合回报、因果归因或总分。汇率正值表示每美元对应更多人民币，不是成交回报。
3. 遇到失败、旧缓存或区间缺失，可「仅重读此项」。股、金沿用既有日线和限流机制；债、汇仅查本地历史。债、汇没有本地观测时，点「到原模块核验」，再用顶部「返回周复盘」恢复所选日期与草稿，并按需单独重读。尚未读取不等于已确认缺数。
4. 写判断和下周待核验事项，预览或下载 Markdown。真实导出只含查询引用、所选区间与人工文字。草稿按周保留在当前标签页内存，重载、关闭前请先导出；不会自动成为项目笔记。

「每周研究复盘」用于项目活动、反证、待办和显式基线，不是上面的行情复盘。只是浏览不会自动推进项目基线。

## 5. 数据、AI、备份和排障

- 无数据：先看状态与日期；确认是否未开盘、尚未读取、本地没有历史、来源异常或 Key 未配置。可在「数据健康」查看降级，不要频繁重启绕过限流。
- 启动失败：按启动器预检提示检查版本、文件、权限、磁盘或证书。可运行 `python3 scripts/preflight.py --json`。发布包缺失按需页面时请重新完整解压，不要删除研究数据。
- FRED 和 AI 互相独立，均为自选功能；中国市场路径不要求二者的 Key。请在应用设置中管理凭据，不将密钥写进文档。人工粘贴内容仍须自己检查是否有权保存或发送。
- 应用不默认遥测。「使用与反馈」可主动预览脱敏诊断；不提交 API Key、数据库、原始日志、草稿或未公开业务资料。
