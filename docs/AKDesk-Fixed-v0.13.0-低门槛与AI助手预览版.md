# AKDesk Fixed v0.13.0「低门槛与 AI 助手预览版」

> 版本：v0.13.0  
> 日期：2026-07-23  
> SQLite schema：1201（无迁移）  
> AI 提供方：AIHubMix  
> 固定模型：`deepseek-v4-flash-think`

## 1. 版本目标

v0.13.0 在 v0.12.2 起步清单的基础上增加可选 AI 助手，让用户不必先学习完整模块体系或 Prompt 工程，就能围绕实际任务获得操作路径、市场信息整理和研究下一步建议。

AI 是只读辅助层，不是自动代理。它不会操作数据库、改写观点、创建研究资产、给出交易指令或替代用户判断。

## 2. 三类助手场景

### 2.1 产品向导

发送：

- 用户本次问题；
- 当前页面 ID；
- 产品模块地图、推荐研究闭环和能力边界。

适合询问“从哪里开始”“数据不可用怎样排查”“某个功能在哪里”。

### 2.2 市场观察

发送：

- 用户本次问题；
- 最多 8 条当前市场研究线索；
- 线索的来源、观测时间、可信状态、质量分和触发原因；
- 当前市场状态与数据使用提示。

不发送完整行情表、逐笔数据、本地历史库或演示数据伪装的结论。回答必须区分当前观察、可信边界和待验证问题。

### 2.3 研究教练

用户可以选择一个研究项目。发送：

- 项目标题、问题、假设、状态、置信度、期限、标签、当前结论与复盘日期；
- 最多 8 条证据的标题、类型、来源摘要和观察区间；
- 最多 12 条研究记录的类型、标题、状态和到期日。

不发送研究记录正文、证据 payload、附件、数据库文件或新闻正文。回答只整理已有信息、可能遗漏、下一步验证清单和反证问题。

## 3. 密钥与外部处理

用户使用自己的 AIHubMix API Key。页面“验证并保存”会用固定模型发起一次最小连接测试；成功后：

- macOS 上写入 Keychain 服务 `com.akdesk.fixed.aihubmix-api-key`；
- 不写入 SQLite、日志、浏览器缓存、前端构建或导出；
- API 状态只返回“是否配置”和“凭据来源”，不返回 Key 明文；
- 也可以通过 `AKDESK_AIHUBMIX_API_KEY` 环境变量提供。

AIHubMix 使用 OpenAI 兼容地址 `https://aihubmix.com/v1/chat/completions`。调用可能产生第三方费用。使用前应阅读：

- [AIHubMix Quick Start](https://docs.aihubmix.com/en/quick-start)
- [AIHubMix Terms of Service](https://docs.aihubmix.com/en/terms-and-privacy/Terms)
- [AIHubMix Privacy Policy](https://docs.aihubmix.com/en/terms-and-privacy/Privacy)
- [AIHubMix Data Privacy](https://docs.aihubmix.com/en/api/Data-Pravicy)

AIHubMix 声明默认不主动保存提示词和响应正文，但会记录用量、Token、延迟等元数据；底层模型提供方可能有自己的处理与保留策略。每次发送前，AKDesk 都会显示上下文类型并要求用户显式确认。

## 4. 本地安全边界

- 提示词、裁剪上下文和回答仅在当前请求中处理；
- 回答只保留在当前 React 组件内存，关闭抽屉后清除；
- 不写入 SQLite、日志、浏览器存储、项目、专题、证据或复盘；
- 只提取最终回答，不展示 `reasoning_content` 等内部思维过程；
- 单机同时只允许一个 AI 请求；
- 上下文最多 14,000 字符，响应最多 96 KB；
- 连接超时 10 秒，总请求超时 90 秒；
- 上游错误只映射为安全中文提示，不返回 Key 或上游响应正文。

## 5. 明确不做

本预览版不提供：

- 多轮会话和对话历史持久化；
- 自动保存 AI 回答；
- 自动建立或修改研究项目；
- 自动读取附件全文或新闻正文；
- 自动信用评级、风险评分、违约概率；
- 买卖建议、仓位建议、交易执行或收益承诺；
- 模型自由切换与第三方工具调用。

## 6. 升级兼容

- SQLite schema 保持 1201；
- 不新增数据库表；
- 不迁移、不重写项目、专题、证据、自选、信用观察或历史缓存；
- 未配置 AIHubMix Key 时，v0.12.2 的所有市场与投研功能照常使用；
- 删除 Key 只影响 AI 助手，不影响其他连接器和研究数据。
