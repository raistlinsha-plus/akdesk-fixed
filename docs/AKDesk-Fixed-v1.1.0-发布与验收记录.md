# AKDesk Fixed v1.1.0「GitHub 自助体验版」发布与验收记录

验收日期：2026-10-22。基线 v1.0.0，SQLite schema 保持 1600。本文件逐项记录实际证据；尚未完成的事项不计为通过。

## 交付范围

1. 无安装的静态示例：市场变化、曲线核验、一页简报，固定 2026-08-03 合成数据。
2. 本地日报共用简报模板，保留完整复盘、逐源时间与可信边界。
3. macOS 启动预检、帮助和主动预览的脱敏诊断。
4. 中英文入口、60 秒真实界面截图导览、独立 AKShare 案例、文档与 GitHub Pages 发布工作流。

没有增加数据源、资产类别、AI 场景、多人权限、默认遥测或数据库迁移。机构生产用途、完整 Windows/Linux 本地支持和授权实时行情仍不在范围内。

## Review 中发现并修复

- 缺失资金/曲线数据时的确定性方向标题。
- 旧归档缺失来源却被误认为真实数据的风险。
- 切换简报/完整复盘或日期时临时备注丢失。
- 全局打印方向影响其他报表，改为仅简报命名页面。
- 反馈链接可能包含路径残片，改为白名单标识；未知模式不假定为实时。
- 相对自定义数据目录在预检与实际启动之间的基准差异。
- 小屏重置按钮隐藏。
- 日期窗口测试随现实时间推移失效。
- 独立停止器探测无响应端口时没有超时，已改为有界探测且拒绝终止身份未核实的进程。
- 诊断默认模型使未检查来源看似trusted，已仅在导出层校准为不可研究；主动演示明确为demo_mode，不混同真实连接错误。
- Pages构建令牌缺少读取权限、Issue模板仍引用旧手册、不同反馈类型缺少对应预填字段。

## 已知边界与后续观察

- 在线演示只验证工作方式，不验证公开数据源当下可用性。
- 公开源可能限流、变更或缺少时间/字段；本次成功不构成连续性承诺。FRED/AI 需要用户自己的 Key，本次不使用私人凭据执行收费调用。
- 简报是精简视图；长备注和较多来源可自然分页，不以裁切强制“一张纸”。
- 本版没有完整英文业务界面，也没有默认访问追踪。GitHub 流量、下载与实际完成任务分别看待；按[路线图](../ROADMAP.md)观察四周后再定后续范围。
- 未向 AKShare 维护者发推广消息或提交收录 PR；本仓库案例就绪不代表已获外部收录。
