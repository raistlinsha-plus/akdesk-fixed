## 1. 使用前须知

AKDesk Fixed 是本地个人研究工具，不是交易终端。它适合查看公开数据、建立研究项目、保存证据和进行周期复盘，不适合作为下单、正式估值、会计入账、信用审批或风险限额的唯一系统。

使用时请区分四个概念：

1. **观测时间**：数据实际代表的市场、统计或自然年度；
2. **抓取时间**：本机取得该数据的时间；
3. **数据状态**：最新、缓存、过期、降级或演示；
4. **研究可用性**：综合来源、时间、质量和缓存后，数据是否适合进入研究流程。

市场休市不等于数据不可用。盘前、午休、盘后和非交易日时，应用可以显示最近可信快照，并明确标出市场阶段。

## 2. 系统要求

- macOS 12 或更高版本；
- Python 3.11、3.12 或 3.13；
- 首次安装依赖时需要网络；
- 使用 FRED 时需要用户自己的 32 位 API Key；
- World Bank 不需要 API Key；
- GDELT 不需要 API Key；
- 建议使用 Safari、Chrome 或其他现代浏览器；
- 建议保留至少 1 GB 可用空间。

如尚未安装合适的 Python，可使用 Homebrew：

```bash
brew install python@3.13
```

## 3. 启动与关闭

### 3.1 正常模式

在 Finder 中打开项目目录，双击：

```text
start-macos.command
```

首次启动会：

1. 检查 Python 版本；
2. 创建项目独立的 `.venv`；
3. 安装 AKShare、FastAPI、HTTP/2 和其他依赖；
4. 在缺少前端构建文件时构建前端；
5. 启动本地服务；
6. 打开浏览器。

应用地址：

```text
http://127.0.0.1:8765
```

服务只监听本机回环地址，不向局域网或公网开放。

### 3.2 演示模式

完全离线体验界面时，双击：

```text
start-macos-demo.command
```

演示数据只用于体验页面，不代表真实市场，不会触发正式提醒，也不能保存为可信研究证据。

### 3.3 关闭应用

关闭启动器所在的终端窗口，或在终端中按：

```text
Control + C
```

只关闭浏览器标签不会停止后端服务。

### 3.4 macOS 阻止启动器

首次运行时，可在 Finder 中右键启动器并选择“打开”。

如脚本没有执行权限，在项目目录运行：

```bash
chmod +x start-macos.command start-macos-demo.command
```

## 4. 首次配置

### 4.1 中国固收

中国固收公开行情不需要额外账号。进入资金、曲线、现券、期货、转债或发行页面时，应用会通过 AKShare 请求数据。

首次预热可能需要一段时间。单个公开源失败不会阻止其他模块使用。

### 4.2 FRED

“美国宏观与利率”“图表研究室”和“数据发布复盘”需要 FRED API Key。

配置步骤：

1. 登录 FRED 并申请个人 API Key；
2. 打开“全球宏观 → 美国宏观与利率”；
3. 输入完整的 32 位 Key；
4. 点击保存并验证；
5. 等待页面显示验证成功。

验证成功后：

- Key 保存到 macOS Keychain；
- Key 不写入 SQLite、日志或导出文件；
- FRED 观测值按需请求，不写入本地数据库；
- 研究项目只保存序列、来源、区间和变换引用；
- 用户主动导出的 CSV 可以包含当次请求取得的数值。

### 4.3 World Bank

“全球主权比较”使用 World Bank Indicators API v2，不需要注册账号或配置 Key。

首次请求成功后，国家、指标和年度观测会写入本地 SQLite，并在 7 天内复用。

### 4.4 GDELT

专题“外部事件雷达”使用 GDELT DOC 2.0，不需要注册或配置 API Key。

应用采用按需策略：

- 进入事件组件时才发起查询；
- 相同查询 12 小时内复用本地元数据缓存；
- 远端请求至少间隔 5 秒；
- 不抓取或保存新闻正文；
- 公共 API 限流时显示错误，存在缓存则明确降级复用。

GDELT 结果是待核验线索。必须打开原文确认主体、时间、事实和上下文后，再决定是否加入证据篮。

## 5. 界面与快捷操作

### 5.1 工作模式

首次打开 v0.14.0 时需要选择默认入口：

- 市场模式：默认进入“今日市场”，导航优先展示行情、自选和每日复盘；
- 投研模式：默认进入“研究首页”，导航优先展示项目、数据研究和每周复盘。

顶部“市场 / 投研”切换器可以随时改变当前模式。两个模式使用同一套数据和研究资料，不会隐藏功能或拆分数据库。

从两个首页切换模式时会进入对应首页；在曲线、现券、宏观等专业页面切换时，会保留当前页面和筛选状态。

点击切换器右侧的设置按钮，可以修改下次启动的默认入口。

按：

```text
Command + 1
```

可以返回当前模式首页。

### 5.2 左侧导航

**市场模式**

- 今日：今日市场、我的自选、每日复盘；
- 中国固收：资金面、收益率曲线、现券市场、国债期货、信用观察 R2、可转债、国债发行；
- 全球市场：外汇市场、美国宏观与利率、全球主权比较、图表研究室、数据发布复盘；
- 投研与工具：研究首页、专题投研、研究项目、每周复盘、固收计算器、数据健康。

**投研模式**

- 研究工作台：研究首页、专题投研、研究项目、我的自选、每周复盘；
- 数据研究：图表研究室、美国宏观与利率、全球主权比较、数据发布复盘；
- 市场观察：固收市场、外汇市场、资金面、收益率曲线、现券市场、国债期货、信用观察 R2、可转债；
- 复盘与工具：每日复盘、国债发行、固收计算器、数据健康。

### 5.3 全局搜索

点击左侧“搜索功能或标的”，或按：

```text
Command + K
```

未输入关键词时会显示六个常用任务：“今天市场怎么样”“开始一个研究”“整理一个专题”“为什么数据不可用”“跟踪信用债”和“做每周复盘”。这些入口使用本地固定映射，不会把问题发送给外部大模型。

输入关键词后可以搜索：

- 页面功能；
- 现券代码和名称；
- 国债期货；
- 可转债及正股；
- 外汇代码、货币对和中文名称；
- FRED 精选指标；
- World Bank 精选指标代码和名称；
- 专题标题、研究问题、标签和研究对象。

选择结果后会直接进入对应页面。

### 5.4 首页起步清单

今日市场与研究首页各有一张四步清单：

- 市场清单：数据状态、自选、专业市场模块、每日复盘；
- 投研清单：研究项目、专题、证据、到期复盘。

清单读取本地现有状态并自动标记完成项；数据源异常和到期复盘会显示为需要留意。点击每项操作可直接进入对应页面。清单可以收起，市场和投研模式分别记忆，之后可随时重新展开。

### 5.5 AI 研究助手

点击顶部“AI 助手”打开抽屉。首次使用时：

1. 输入本人 AIHubMix API Key；
2. 阅读费用与第三方处理说明并勾选确认；
3. 点击“验证并保存”；
4. 验证成功后，Key 只保存在 macOS Keychain。

助手提供三个场景：

- 产品向导：根据当前页面解释功能和操作路径；
- 市场观察：依据最多 8 条当前市场线索以及来源、观测时间、可信状态和质量分，整理待核验事项；
- 研究教练：根据所选项目的问题、假设、当前结论、证据标题和研究记录状态，提出下一步与反证问题。

每次发送前必须查看“发送前预览”并再次勾选确认。研究教练不会发送研究记录正文，所有场景都不会发送 API Key、SQLite 文件、附件正文、新闻正文或完整行情表。

回答只存在于当前打开的助手抽屉中，不会自动写入项目、专题、证据、日报或浏览器缓存。关闭抽屉后回答会被清除。模型不会自动操作产品，也不应被当作投资、信用评级或交易建议。

展开“预算与页面洞察”可以：

1. 设置每日调用次数上限和每日 token 预算；
2. 分别授权“今日市场、研究项目、信用观察”；
3. 为已授权模块选择“仅手动、数据变化后、每日首次打开”；
4. 查看今日用量、剩余额度、队列和当前任务状态。

三个模块默认全部关闭。开启任一模块并保存后，对应页面才会允许发送裁剪上下文。触发方式含义如下：

- 仅手动：只有点击“生成洞察”或“刷新洞察”才会调用；
- 数据变化后：页面上下文指纹发生变化且进入页面时自动排队；
- 每日首次打开：当天没有生成记录时，首次进入页面自动排队。

页面卡片会显示“未授权、尚未生成、生成中、已更新、待更新或生成失败”。“待更新”表示页面数据已变化，但旧摘要仍可查看；刷新完成前不会把旧摘要清空。失败后可直接重试，队列同一时间只执行一个 AI 任务。

三个页面的输出边界不同：

- 今日市场：变化线索、可信边界、下一步核验；
- 研究项目：当前证据、关键缺口、下一步验证，不替用户改写结论；
- 信用观察：新增信号、数据缺口、人工复核任务，不生成评级或违约概率。

展开“发送范围与本地保存”可在调用前核对发送内容类型。页面洞察只在本机缓存最终摘要、上下文指纹、模型和生成时间，不保存完整提示词、思维过程或上下文副本。点击“继续追问”会把固定的后续问题带入原有助手，仍需用户确认发送，追问回答仍不落库。

在“连接与密钥管理”中可以测试连接或删除 Key。环境变量提供的 Key 需要在启动环境中移除，不能从页面删除。

### 5.6 刷新当前页面

点击顶部刷新按钮，或按：

```text
Command + R
```

应用会请求当前页面需要的数据，而不是执行普通浏览器整页刷新。

在全球主权比较页，手动刷新只强制请求一次。之后切换国家、年份或显示方式仍会优先复用有效缓存。

### 5.7 提醒中心

点击顶部铃铛打开提醒中心。可以：

- 创建提醒；
- 试算当前值；
- 暂停或恢复；
- 设置冷却时间；
- 设置每日触发上限；
- 设置静默时段；
- 查看触发历史；
- 标记已读。

## 6. 推荐日常工作流

### 6.1 盘前检查

1. 在市场模式打开“今日市场”，或在投研模式打开“研究首页”；
2. 检查顶部市场状态；
3. 查看市场研究线索；
4. 打开“数据健康”确认关键源状态；
5. 查看待复盘项目和到期自选；
6. 如需要，进入“今日市场”查看最近可信快照。

盘前国债期货显示上一交易日收盘快照属于正常现象。应用不会把昨日 15:15 拼接成今天的未来时间。

### 6.2 盘中观察

1. 在“固收市场”查看资金、曲线、期货和现券；
2. 进入专业页面定位变化；
3. 将可信标的加入自选或创建提醒；
4. 在研究首页选择值得跟踪的市场线索；
5. 保存到研究项目，形成市场证据。

### 6.3 收盘复盘

1. 打开“每日复盘”；
2. 检查报告模式和综合可信度；
3. 查看资金、曲线、期货、现券和发行事件；
4. 导出 Markdown 或打印 PDF；
5. 更新研究项目的结论、状态和置信度；
6. 添加反证、任务或复盘记录。

### 6.4 周度研究复盘

1. 打开“每周复盘”；
2. 选择周结束日；
3. 查看活跃项目、本周更新、笔记、反证和任务；
4. 检查本周观点、下周待验证、下次复盘、到期项目和数据发布复盘；
5. 导出 Markdown；
6. 调整下周的项目状态与复盘日期。

### 6.5 专题研究

1. 打开“专题投研”；
2. 选择中国利率、中美利率、人民币汇率、全球通胀或空白模板；
3. 在专题设置中关联一个或多个研究项目；
4. 检查已保存的市场、FRED、World Bank 和项目摘要组件；
5. 从研究首页、图表研究室或主权比较页把材料加入证据篮；
6. 回到专题，选择证据并批量提交到目标项目；
7. 使用跨源时间线检查观点、证据和任务的演进；
8. 需要归档时导出专题 Markdown。

页面顶部的五步研究导航按“发现问题、建立项目、保存证据、更新观点、定期复盘”组织现有功能，并根据本地资料提示建议步骤。点击任一步可直接打开对应页面。

### 7.4 研究项目

研究项目是保存观点和证据的核心位置。

#### 创建项目

可以手工输入标题和问题，也可以使用模板：

- 空白研究；
- 利率方向；
- 宏观发布；
- 可转债事件；

- 主权基本面比较。

市场线索、现券、期货、转债、信用观察和主权比较页面也提供一键立项。

同一模板和同一研究对象重复立项时，应用会返回已有未归档项目。

选择项目后，顶部“研究闭环”按研究问题、初始假设、可信证据、反证、当前结论和下次复盘六项显示完成度，并提示第一项未完成动作。它用于提醒研究过程，不是项目质量评分。

#### 项目字段

项目支持：

- 标题；
- 研究问题；
- 初始假设；
- 状态；
- 主观置信度；
- 研究期限；
- 下次复盘日期；
- 标签；
- 当前结论与风险点。

标题、问题、状态、置信度和结论默认展示；假设、期限、复盘日期和标签位于“假设、期限、复盘与标签”展开区。

状态包括：

- 草稿；
- 跟踪中；
- 已形成观点；
- 待复盘；
- 已归档。

#### 研究记录

项目中可以添加：

- 研究笔记；
- 反证；
- 任务；
- 复盘。

任务和记录可设置到期日期，任务可以标记完成或重新打开。

#### 观点轨迹

系统自动记录：

- 项目创建；
- 字段更新；
- 状态变化；
- 置信度变化；
- 证据新增和删除；
- 研究记录变化。

#### 研究证据

目前主要包括：

- 中国固收市场快照；
- FRED 引用证据；
- World Bank 主权比较快照。

FRED 引用证据不包含观测值。重新打开时会请求当前官方版本，官方修订可能导致图表变化。

World Bank 证据保存当次比较的原始值、显示值、年份、国家元数据、指标口径、覆盖率、抓取时间、保存时间、来源、许可和署名。

#### 导入、导出与备份

单个项目支持：

- Markdown 导出；
- JSON 项目包导出；
- JSON 项目包导入。

整个研究数据库支持：

- 下载 SQLite 备份；
- 上传备份恢复；
- 恢复文件完整性校验；
- 恢复前自动生成安全副本。

页面同时显示后台自动备份是否运行、保留份数和最近备份时间。点击“立即安全备份”可在本机生成一份经过 SQLite 完整性验证的快照。

恢复备份前建议关闭其他浏览器标签，避免同时编辑项目。

项目 JSON 导出会包含关联研究对象。导入项目时会恢复对象关联，但不会自动创建或复制专题。

### 7.5 专题投研

专题投研用于把多个页面和多个项目组织成一个持续研究视图。

#### 创建专题

内置模板：

- 中国利率方向；
- 中美利率联动；
- 人民币汇率与中国利率；
- 全球通胀与实际利率；
- 空白专题。

创建后可以修改标题、研究问题、说明、状态和标签。

专题默认处于阅读状态，优先显示组件、时间线和证据篮。点击专题标题区的“编辑专题”才会打开低频设置；保存后自动返回阅读状态。尚无专题时，主区域会说明专题、项目和证据篮之间的关系，并可直接用当前模板创建。

专题数量较多时，可在左侧专题库按标题、研究对象或标签搜索，并按“持续跟踪、待专题复盘、已归档”筛选。结果数量会随输入即时更新。

#### 关联项目

在“专题设置”中勾选未归档研究项目并保存。一个专题可以关联多个项目，一个项目也可以关联多个研究对象。

#### 专题组件

首期组件：

- 当前市场脉搏；
- 中国国债期限结构；
- 人民币参考价；
- 美国名义与实际利率；
- 美国通胀；
- 主要经济体增长；
- 外部事件雷达；
- 关联项目摘要；
- 最近证据。

组件配置保存在 SQLite。展开“专题设置”中的组件，可以编辑标题及对应的数据源、序列、时间范围、变换或比较方式，点击“保存专题”后生效。FRED 组件只保存序列、区间和变换配置；组件接近可视区域时才请求当前官方版本，相同请求会自动合并。

市场脉搏、本地历史、FRED、World Bank 和 GDELT 组件右上角都有独立刷新按钮。单个组件失败时，检查错误提示后点击该按钮即可重试；其他组件和本地项目摘要不会被重新加载。刷新期间旧数据会继续保留，按钮显示加载状态。

GDELT 事件雷达可以编辑检索词、1–90 天范围、5–50 条返回数量，以及“最新优先 / 相关性优先”排序。建议使用明确主体名或短语。显示的标题、来源、来源国家、语言和本机时间只是检索线索；请先打开原文核验。

#### 跨源时间线

时间线显示：

- 市场快照；
- FRED 引用；
- World Bank 主权比较；
- GDELT 线索；
- 笔记、反证、任务和复盘；
- 发布复盘；
- 项目创建、导入和观点变化。

“记录时间”表示信息写入本地研究库的时间，“观察时间”表示数据或事件实际对应的时间。

时间线支持按标题/摘要/项目文字、记录类型和关联项目筛选。页面先稳定读取最近 100 条，并同时显示“已加载数量/完整总数”；点击“加载更早记录”继续读取下一页，记录新增时也不会使旧页重复。筛选作用于已加载范围，未加载完整时页面会明确提示。每次默认显示前 20 条匹配记录，点击“再显示”继续展开。

#### 证据篮

支持从以下页面加入证据篮：

- 研究首页的可信市场快照；
- 图表研究室的 FRED 引用；
- 全球主权比较的 World Bank 快照。
- 事件雷达中由用户选择的 GDELT 原文引用。

在专题页面中：

1. 按全部、当前专题或尚未归属筛选，也可以限制来源和起始日期；
2. 勾选一项或多项证据，或全选当前筛选结果；
3. 选择目标项目并点击“提交到项目”；
4. 系统将证据写入项目，并关联当前专题研究对象；
5. 已提交项从证据篮移除；不再需要的临时材料可批量清理。

FRED 证据仍只保存引用，不能通过证据篮保存观测值。

#### 项目摘要

“关联项目摘要”按固定规则整理问题、假设、结论、证据、反证、任务、结论变化和复盘日期。它不会生成投资建议，也不会修改项目内容。

#### 搜索和导出

使用 `Command + K` 可以搜索专题。专题可导出 Markdown，包含研究问题、组件、项目摘要、完整跨源时间线和数据边界；文件头会写明导出的时间线总数。

折线图下方提供“查看图表数据摘要”，可读取每条序列的首个有效值、最新值、观察日期和区间变化。没有有效历史时页面会说明如何积累或刷新数据，不再显示空白图表。

## 8. 中国固收市场

### 8.1 资金面

资金页展示：

- Shibor O/N；
- Shibor 1W；
- FR007；
- FDR007；
- LPR。

重点检查当前值、前值变化、数据日期和独立数据源状态。

FR、FDR 或 LPR 单独失败时，其他资金指标仍可使用。可在数据健康页对失败源单独重试。

### 8.2 收益率曲线

曲线页提供：

- 国债和政策金融债期限结构；
- 相对前值的 BP 变化；
- 10Y–1Y、10Y–5Y、30Y–10Y 利差；
- 30、90、365 天历史；
- 关键期限矩阵。

历史长度取决于本机积累的数据。较短本地历史不代表官方完整历史缺失。

### 8.3 现券市场

支持：

- 代码、名称和类型搜索；
- 债券类型筛选；
- 收益率范围；
- 最小绝对异动；
- 收益率、异动和成交量排序；
- 分页；
- 保存筛选视图；
- CSV 导出；
- 自选；
- 提醒；
- 一键立项。

缺少可信代码或被标记为异常的记录不能加入自选和提醒。标准格式的附息国债、国开、进出口行和农发行简称可能显示规则推导代码；这类代码明确标记“需核验”，核验前不能加入自选、提醒或研究项目。

### 8.4 国债期货

展示 TS、TF、T、TL 合约：

- 最新价；
- 涨跌幅；
- 成交量；
- 持仓量；
- 数据日期与状态。

源未提供明确交易日时，系统只推断到已经发生的最近交易时点，并降低可信等级。

### 8.5 信用观察 R2

信用观察 R2 只整理用户提供并核验的资料。页面分为单券、发行人和自定义组合三个层级。

日常打开时，先看到摘要、三级观察切换和单券结果；批量导入与新增/编辑表单默认收在“数据维护”中。需要维护资料时展开该区域，完成后可再次收起。风险与日程信号位于观察结果之后，避免遮挡主任务。

在单券长列表深处切换页签、输入搜索或改变观察状态时，页面会把新的结果区定位到粘性工具栏下方。键盘用户可在页签上使用左右或上下方向键切换，`Home` 回到单券，`End` 进入自定义组合。

#### 批量导入

1. 点击“选择 CSV / Excel”，或先下载标准模板；
2. 选择 `.csv`、`.xlsx` 或 `.xlsm` 文件；
3. 检查系统自动识别的字段映射；
4. 如有需要，在每个字段下重新选择文件列，然后点击“按当前映射重检”；
5. 检查逐行错误和质量提示；
6. 只有没有映射或格式错误时，才点击“确认导入”。

单次最多 500 行、10 MB。CSV 支持 UTF-8 和 GB18030。债券代码和债券名称是导入必填字段，其他缺失项不会被自动猜测。

同一债券包含多个收益率日期时会保存为多期历史。导入早于当前快照的历史不会把当前值回退到旧日期。

可选字段允许留空。例如“基准期限”列存在但单元格为空时会按缺失值保存，不会再导致整批格式错误；该行会保留在观察清单，并因门禁不完整显示“不计算”。

点击三级观察栏右侧“导出当前观察”，可以导出与标准模板同字段的 UTF-8 CSV。该文件只保存每只债券的当前单券主档并可重新导入。

点击“导出多期历史”，可以按债券代码、收益率观察日期和记录时间从早到晚导出全部本地信用快照。历史文件同样使用标准模板字段，适合在表格中复核一只债券的多期收益率、评级和基准变化。自定义组合、信号确认和研究项目关联不在 CSV 中，仍应通过“研究项目 → 备份研究库”完整保留。

#### 单券观察

单券可以手工新增，也可以编辑现有记录并保存新快照。系统检查：

- 债券代码和名称；
- 发行人；
- 评级和评级日期；
- 到期日和剩余期限；
- 债券收益率及日期；
- 国债基准期限、收益率及日期；
- 数据来源说明。

只有关键字段完整、评级日期有效、债券和基准同日且期限匹配时，才计算机械利差。

“不计算”不是程序故障，而是门禁未通过。页面会列出缺失字段和阻断原因。

通过门禁的多期记录会展示：

- 最新机械利差；
- 相邻可信观察的变化；
- 当前值在本地历史中的分位；
- 收益率、评级和来源时间线。

历史分位只基于该债券已经保存且通过门禁的观察，不使用其他债券，也不补造缺失日期。

列表首次显示 20 只，点击“再显示 20 只”继续展开。标题显示当前匹配数和观察总数，列表底部显示已显示数量。搜索或状态筛选仍作用于完整观察集；分页只控制页面渲染，不会截断当前观察或多期历史导出。

#### 发行人主档

系统按“主体归一名”聚合同一发行人的多只债券，并汇总债券数、评级记录、通过门槛数量、可比单券机械利差范围、样本数和下一事件。行业、地区、主体类型与归一名都来自用户录入。

系统不对不同期限、评级或其他属性的债券做简单平均。范围只描述当前通过门槛单券的机械值分布，不构成发行人整体信用利差或估值结论。

点击发行人卡片右上角的立项按钮，可以按主体归一名建立“信用债覆盖与利差观察”项目。系统会带入发行人、来源和当前观察日期；相同主体重复操作时打开已有未归档项目，不会重复创建。立项不会把发行人自动加入行情自选。

点击旁边的事件按钮，可以创建或打开该主体唯一的事件观察专题。专题默认查询主体归一名的近 30 天 GDELT 元数据。该动作不会自动建立信用结论；线索仍需打开原文、加入证据篮并提交到项目。

#### 自定义组合

在“自定义组合”页签填写组合名称、用途说明并勾选单券。可在成员区按代码、债券名称或主体搜索，勾选“仅看已选”复核当前成员；搜索不会清除已经勾选的债券。组合展示成员、主体数、通过门槛数量和可比单券机械利差范围；只用于本地观察聚合，不记录持仓，不计算收益，也不生成组合信用评分。

#### 日历与信号

系统汇总到期日、回售日、评级资料复核日和研究复盘日。相邻可信利差变化达到规则阈值或事件进入提示窗口时，会生成规则信号。

每条信号都显示债券、主体、观察日期、来源和质量状态。点击“人工确认”后，可以：

1. 填写核验动作、依据或后续待办；
2. 只确认当前信号，或选择一个未归档研究项目；
3. 点击“确认并保存”。

选择研究项目时，系统会新增一条已完成的“信用信号确认”复盘记录，保留信号正文、主体、债券、观察日期、来源和人工备注。重复确认不会重复写入记录。人工确认只表示已经核验提示，不代表形成投资结论。

### 8.6 可转债

支持：

- 代码、名称和正股搜索；
- 最高价格；
- 最高转股溢价率；
- 最高双低值；
- 最低 YTM；
- 字段排序；
- 保存筛选视图；
- CSV 导出；
- 自选、提醒和一键立项。

主比价源的个别记录缺字段时会标记“部分比价”；切换价格备用源时会标记“仅价格 / 部分可用”。这些记录允许观察和加入自选，但不允许直接一键立项；恢复完整比价字段后才开放研究立项。

遇到数据问题时，优先打开“数据健康”。

页面先显示 AKShare / AKTools、FRED、World Bank 与 GDELT 的统一连接器卡片，包括访问方式、凭据是否配置、本地保存策略、缓存记录数、许可、署名、请求频率和能力边界。它不会显示 API Key 明文。

下方每个具体数据适配器显示：

- 连接状态；
- 研究可用性；
- 数据时间；
- 可信等级；
- 缓存年龄；
- 下次检查或恢复时间；
- 质量评分；
- 异常隔离；
- 最近成功；
- 记录数；
- 请求耗时；
- 连续失败；
- 熔断状态。

### 单源重试

点击数据源旁的“重试”。重试只影响当前数据源。

World Bank 重试会请求两个国家的 GDP 实际增速作为连接检查。成功后健康状态更新为“健康 / 当前已验证”。

GDELT 重试会执行一条最小事件检索。公共 API 限流时会提示稍后再试，不会快速循环请求。

### 清空缓存

“清空缓存”会清理：

- 中国行情缓存；
- World Bank 国家、指标和观测缓存；
- GDELT 查询与事件元数据缓存。

不会删除：

- 研究项目；
- 已保存证据；
- 研究记录；
- 自选；
- 提醒；
- 触发历史；
- 日报和周报所需的研究资料；
- FRED Keychain 凭据。

FRED 观测值本来就不会持久化。

## 14. 常见问题

### 14.1 已经过交易时间，为什么显示缓存或最近快照

这是正常现象。交易阶段和数据可用性是两个概念。盘后仍可使用最近真实快照，但页面不会把它标成实时行情。

### 14.2 多个中国行情模块显示不可用

1. 打开数据健康；
2. 查看是未检查、降级还是不可用；
3. 查看是否有真实缓存；
4. 对关键源单独重试；
5. 检查网络、代理和公开接口状态；
6. 等待熔断恢复时间。

### 14.3 World Bank 首次加载失败

v0.8.0 使用 HTTP/2，并采用直连优先、系统代理回退。

如仍失败：

1. 打开数据健康；
2. 找到“World Bank 主权数据”；
3. 点击重试；
4. 检查本机代理软件是否正常；
5. 尝试暂时关闭异常代理规则；
6. 稍后再试。

已有缓存时，页面会继续显示缓存；缓存超过 7 天后会标为过期。

### 14.4 World Bank 数据为什么有空白

空白通常表示该经济体、指标和年份在 WDI 中没有值。系统不会使用相邻年份填充。

可查看覆盖率、最新共同年份和各经济体覆盖点数。

### 14.5 主权排名为什么和常识中的“好坏”不同

排名只按指标数值由高到低排列，不做方向解释。

例如：

- 债务占 GDP 更高通常不代表更好；
- 经常账户余额更高的解释也依赖经济结构；
- 人口增速更高不等于资产回报更高。

### 14.6 FRED Key 验证失败

- 确认 Key 为完整 32 位字符串；
- 401 或 403 通常表示凭据无效；
- 429 表示请求过于频繁；
- 检查网络能否访问 FRED；
- 连续失败后等待熔断恢复；
- 验证失败不会覆盖原有有效凭据。

### 14.7 信用观察显示“不计算”

查看页面列出的缺失字段和阻断原因。只有评级、日期、期限、债券收益率和同日基准全部合格时才试算。

不要为了得到数值而使用未经核验的字段。

### 14.8 信用文件无法确认导入

先检查字段映射中是否已指定“债券代码”和“债券名称”，再点击“按当前映射重检”。页面显示任何格式错误时都会阻止整批写入，避免半批成功。

日期建议使用 `YYYY-MM-DD`、`YYYY/MM/DD` 或 Excel 日期单元格；收益率填写百分数数值，例如 `2.35` 表示 `2.35%`。CSV 乱码时请另存为 UTF-8 或 GB18030。

如果只是可选列存在但单元格为空，请先确认应用版本为 v0.11.0.1 或更高；该版本会把空白“基准期限”识别为缺失值。必填的债券代码、债券名称仍不可留空。

### 14.9 自选没有持续刷新宏观数据

这是设计行为。FRED 观测值按需请求，不在后台预抓取或持久化。点击自选中的详情入口进入宏观页面查看。

### 14.10 GDELT 显示限流或没有结果

GDELT 是公共研究 API，可能返回频率限制。应用已经让远端请求至少间隔 5 秒，并对相同查询缓存 12 小时。

- 有缓存时会继续显示，并标记为缓存或过期；
- 没有缓存时请等待后再刷新，不要连续点击；
- 没有结果不代表没有事件，可尝试明确英文主体名、完整短语或调整到 30 天；
- 同名主体和宽泛词会产生噪声，必须打开原文确认。

### 14.11 端口 8765 被占用

关闭旧版启动窗口。若仍占用，可在“活动监视器”结束对应 Python 进程，再重新启动。

### 14.12 首次启动较慢

首次需要创建虚拟环境并安装依赖，通常需要数分钟。之后启动会明显更快。

### 14.13 恢复备份失败

系统会拒绝：

- 空文件；
- 超过大小限制的文件；
- 不是 SQLite 的文件；
- 完整性检查失败的数据库；
- schema 不兼容的备份。

恢复失败不会覆盖当前数据库。
