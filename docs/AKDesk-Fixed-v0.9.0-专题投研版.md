# AKDesk Fixed v0.9.0「专题投研版」

## 版本目标

v0.9.0 将 AKDesk Fixed 从“多个行情和研究页面”推进为“围绕研究主题组织数据、项目和证据”的个人投研工作台。

本版不新增外部数据源，重点连接已有能力：

- 中国固收与人民币汇率；
- FRED 美国宏观和利率；
- World Bank 主权结构数据；
- 研究项目、笔记、反证、任务与复盘；
- 本地可信历史和研究证据。

## 专题投研工作台

投研模式“研究工作台”和市场模式“投研与工具”新增“专题投研”。

专题不是新的行情数据库，也不替代研究项目：

- 专题负责组织一个持续研究视图；
- 研究对象负责定义专题围绕什么展开；
- 研究项目负责记录问题、假设、观点、证据和任务；
- 证据篮负责跨页面临时收集材料；
- 时间线负责把多个项目和来源的研究活动放到同一顺序中。

## 统一研究对象

v0.9.0 新增六类研究对象：

- 利率主题；
- 宏观主题；
- 国家或经济体；
- 发行人；
- 证券；
- 数据发布事件。

专题与研究项目通过研究对象关联。专题内提交的证据也会保留对应对象关系，为后续国家页、发行人页和证券研究页提供稳定基础。

首期内置五个专题模板：

| 模板 | 主要组件 |
| --- | --- |
| 中国利率方向 | 市场脉搏、中国国债期限结构、项目摘要、最近证据 |
| 中美利率联动 | 中国 10Y、美债名义利率、实际利率、通胀预期、项目摘要 |
| 人民币汇率与利率 | 人民币参考价、中国 10Y、美国 10Y、项目摘要 |
| 全球通胀与实际利率 | 美国 CPI、实际利率、通胀预期、World Bank 跨国通胀 |
| 空白专题 | 项目摘要、最近证据，可继续添加组件 |

## 保存专题视图

专题组件配置写入本地 SQLite，而不是只保存在当前浏览器会话。

首期支持：

- 当前市场脉搏；
- 本地市场历史；
- FRED 多序列图表；
- World Bank 主权比较；
- 关联项目结构化摘要；
- 最近研究证据。

用户可以：

- 从模板创建专题；
- 修改标题、研究问题、说明、状态和标签；
- 关联或移除研究项目；
- 添加或移除专题组件；
- 将专题导出为 Markdown。

FRED 组件只保存序列、区间和变换配置。打开专题时按用户请求获取当前官方版本，不在专题表中保存 FRED 观测值。

## 跨源研究时间线

专题时间线聚合关联项目中的：

- 中国市场快照；
- FRED 引用证据；
- World Bank 主权比较证据；
- 研究笔记；
- 反证；
- 任务与复盘；
- 数据发布复盘；
- 项目创建、导入和观点字段变化。

每条记录同时显示：

- 事件类型；
- 所属项目；
- 本地记录时间；
- 可用时显示来源观测时间。

时间线不会把不同频率的数据强行拼接成一条伪连续行情曲线，它表示研究活动和证据进入系统的顺序。

## 证据篮

用户可以先在不同页面收集证据，再在专题工作台统一归档。

首期接入：

- 研究首页的可信中国固收市场快照；
- 图表研究室的 FRED 引用证据；
- 全球主权比较的 World Bank 快照。

证据篮支持：

- 多项选择；
- 查看来源、页面和收集时间；
- 删除不需要的临时证据；
- 一次性提交到指定研究项目；
- 提交时关联当前专题与研究对象。

FRED 的许可边界在证据篮中继续生效：只允许保存引用配置，不允许通过证据篮绕过校验落盘观测值。

## 规则化项目摘要

专题中的“关联项目摘要”使用固定规则整理：

- 当前问题；
- 当前假设；
- 当前结论；
- 最近支持证据；
- 主要反证；
- 未完成任务；
- 最近结论变化；
- 下一次复盘；
- 尚未补齐的研究字段。

摘要不调用生成式 AI，不自动判断投资方向，也不改变用户原始研究记录。

## 搜索、导出与研究首页

- 全局搜索可以直接搜索专题标题、研究问题、标签和研究对象；
- 搜索结果打开对应专题；
- 研究首页新增专题数量和证据篮数量；
- 研究首页提供专题投研快捷入口；
- 专题 Markdown 导出包含研究问题、组件配置、项目摘要、时间线和数据边界；
- 项目 JSON 导出增加关联研究对象，导入后恢复对象关联。

## 数据与兼容性

SQLite schema 从 `800` 升级为 `900`，新增：

- `research_objects`；
- `research_topics`；
- `research_topic_projects`；
- `research_project_objects`；
- `research_evidence_objects`；
- `research_evidence_basket`。

升级过程：

- 保留既有项目、证据、自选、提醒、FRED 设置引用和 World Bank 缓存；
- 不改变 FRED 观测值不落盘的规则；
- 数据库备份包含全部专题和证据篮；
- v0.8.2 数据库首次由 v0.9.0 打开时自动幂等迁移。

## 适用场景

适合：

- 持续跟踪中国利率方向；
- 研究中美利率和实际利率联动；
- 观察人民币汇率与中国债券市场；
- 把 FRED、World Bank 和中国市场证据归入同一研究问题；
- 周期性复盘专题观点和未完成任务。

不适合：

- 自动生成交易建议；
- 自动完成因果判断；
- 多人协作或云端同步；
- 高频数据拼接；
- 用公开数据替代机构生产终端。

## 可信边界

- 专题组件可同时展示不同来源，但各来源继续独立标记时间、缓存和可信状态；
- FRED 观测值仍只在请求中处理，专题和项目保存引用；
- World Bank 继续按官方许可持久缓存并保留署名；
- 市场快照只接受非演示、非异常且质量合格的数据；
- 规则化摘要只整理用户已经保存的字段，不生成自动投资结论。
