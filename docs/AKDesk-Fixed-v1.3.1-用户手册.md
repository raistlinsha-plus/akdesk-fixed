# AKDesk Fixed v1.3.1 用户手册

更新：2026-11-07。本文为当前版本入口；未变化的高级模块细节可参照[v1.0完整手册](./AKDesk-Fixed-v1.0.0-用户手册.md)，数据边界以当前[DATA_USAGE](../DATA_USAGE.md)为准，不沿用历史文档中较宽松的数值保存说明。

## 1. 先体验，再安装

打开[在线体验](https://raistlinsha-plus.github.io/akdesk-fixed/#/cross-assets)：不需要账户、安装、行情 Key 或 AI Key。页面使用固定 2026-08-03 合成资料，不连接本地后端和行情服务，不写入研究库。

第一次建议完成：选择指数或黄金 → 载入日线 → 打开“整理跨资产观察底稿” → 写一句观察 → 下载合成底稿。也可继续使用原有“市场变化 → 曲线核验 → 一页简报”路径。

## 2. 本地安装、启动与停止

主要适配 Apple Silicon MacBook Air，macOS 12+为兼容目标；需要 Python 3.11–3.13、首次联网和约1GB空间。本轮不是所有 macOS 小版本或全新电脑冷安装认证。

1. 从[正式 Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/latest)下载 `AKDesk-Fixed-v1.3.1.zip` 和校验文件，核对 SHA-256，完整解压。自动生成的 Source code 包不等同于正式发布包。
2. 双击 `start-macos.command`，按预检提示准备 Python 和依赖。普通使用无需 Node.js、Docker 或 Rust。
3. 在启动终端按 Control+C，或双击 `stop-macos.command` 停止。只关闭网页不停止服务。同版本已运行时会复用服务；端口冲突应按提示处理，不要结束不明进程。

macOS 阻止脚本时可右键“打开”；执行权限丢失可在解压目录运行 `chmod +x start-macos.command start-macos-demo.command stop-macos.command`。安装失败先看启动器分类提示与“使用与反馈”的诊断预览，不要公开 Key、数据库或原始错误中的个人路径。

## 3. 升级与回退

升级前停止旧服务，通过应用备份功能保留升级前备份，并另外保留旧程序目录。新版本启动会校准已识别的新增公开行情引用，清除不允许的数值和观测字段；不会修改源备份文件。恢复时先在工作副本校准再启用。

新增 index/gold/etf 自选类型可能不被旧程序理解。不能把新版本写过的研究库直接交给旧版使用；回退应恢复升级前备份，并使用对应旧版程序。SQLite schema 编号未因本次文本类型扩展而改变，不代表跨版本回退得到保证。

## 4. 股债金汇观察

在市场或投研模式进入“股债金汇观察”。首屏读取上证指数、沪深300、中证500、创业板指以及上金所 Au99.99。指数是市场价格指标；Au99.99 是交易所黄金现货，不是金店零售金价、黄金期货或黄金ETF。

指数/黄金页面每5分钟最多刷新一次，后台标签页暂停轮询。服务报价缓存5分钟、日线缓存6小时；缓存只在进程内，重启后丢失。上游失败保留状态与可用旧缓存，缺失显示“—”，不补零。来源没有给出可核验观测时点时显示未知，不能因为“刚抓取”就认为是当前报价。

ETF 区域需要主动点击载入，只读取所选代码日线。提供四个类别示例：518880黄金、510300宽基、510880红利、511010国债；不是优选名单。它们不自动随页面定时刷新，不提供盘中买卖价、净值折溢价或跟踪误差。16:30前忽略当日日线；16:30后仍可能因上游未更新而只看到旧日期。

读取失败请稍后重试。限流触发冷却时，不会切换接口或代码绕过；ETF与既有东方财富通道共享冷却，其他来源不受这次东方财富冷却直接影响。

## 5. 日线、变化和比较

点击报价卡选中资产，再按“按需载入／重读日线”。展示范围为近1/3/12个月的近似观测条数，不是严格交易日历区间；1/5/20期变化按有效观测计算。指数和 ETF 显示价格变化，不是含分红再投资和费用的总收益。

共同日期比较只提供同类资产，取双方都有有效值的日期，以首个共同日期归一到100。不前向填充、不补交易日、不把走势相关解释为因果；共同日期少于2条不绘图。黄金夜盘日期不能简单套用股票日历。

## 6. 自选、研究保存和底稿

本地模式可加入自选，再由自选回到对应资产。选择已有研究项目，在“保存查询引用”中写自己的备注、预览并明确确认；请求重试不会重复创建同一条记录，冲突会提示。保存的是资产标识、来源链接等查询引用，不含新行情价格、历史序列或观测快照。

“整理跨资产观察底稿”是临时编辑区，不自动保存。真实模式下载只包含查询引用和人工备注；合成模式可导出明确标记的合成数值。人工备注可主动转为项目笔记；请勿手工粘贴无权保存的数据。新增行情不会自动追加到旧日报归档，原有固收简报导出规则不变。

本页的“资金面／收益率曲线／国债期货／人民币与外汇”是导航到原模块，不会把不同日期、不同市场的数值自动合并成同一时点的全资产报告。在线独立演示不提供这些正式模块的本地写入能力。

## 7. 保留的研究路径

- 每日：市场变化筛选 → 回原模块核验来源与时点 → 合格信号关联已有项目 → 添加自己的简报备注。
- 每周：项目复盘查看与上次明确基线的差异 → 检查反证和任务 → 确认新的复盘基线；只浏览不会偷偷推进基线。
- 信用：发行人及事件线索 → 人工验证 → 证据与任务。不要把检索结果直接当成评级或违约判断。
- 海外：FRED按请求展示，World Bank结构比较，GDELT事件线索；各自观察频率、许可与保存边界不同。

## 8. AI、隐私、备份与反馈

AI是独立可选功能，用户自行提供服务商 API；不要将密钥放在文档、Issue或截图。新增公开行情数值、FRED内容不送入AI，查询引用也带有禁止AI处理标记。人工文字无法保证自动识别来源限制，发送前须检查。

研究数据在本机，应用没有默认使用遥测。反馈链接只预填版本、页面和模式，不携带项目、底稿、日线或个人路径；打开后仍需自己检查并提交。备份只通过应用既有功能管理，导出前核对内容是否适合分享。

遇到问题先记录“想做的任务、操作、预期/实际、版本、模式”，再附经过检查的诊断摘要。无需上传数据库或非公开研究。完整规则见[DATA_USAGE](../DATA_USAGE.md)。
