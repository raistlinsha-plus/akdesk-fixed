# v1.3.1 开发与 Review 记录

日期：2026-11-07。前序里程碑：[v1.3.0记录](./AKDesk-Fixed-v1.3.0-开发与Review记录.md)。本记录区分自动验证、公开源探测和未完成的人工验收，不把网络失败写成通过。

## 交付范围

在 v1.3.0 黄金和四指数基础上增加四个按需ETF示例、独立静态合成体验和主动反馈入口。后端白名单阻止任意代码/URL调用；ETF只请求所选日线，不调用全市场ETF快照。新增数据保持内存/no-store、引用保存、禁止数值导出与AI处理。既有研究库schema维持1600。

## Review 发现与修复

推送后的发布前复核还发现开发工具链minimatch 10.2.6告警：[GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)。它不在生产依赖中；对typescript-estree的传递依赖单独固定11.0.1，不将ESLint仍使用的3.x统一跨主版本替换。此变更重新验证lint、测试、构建与完整依赖审计。

远端首次运行的后端任务因旧配置 `macos-14-arm64-us-default` 不受支持而取消，尚未执行测试；不是测试通过。按[GitHub当前支持列表](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)改为macos-15，并将前端审计扩大到开发依赖的moderate门槛。最终远端结果以Release附带运行链接为准。

| 问题 | 修复及回归覆盖 |
| --- | --- |
| ETF慢响应可能把用户切回旧选择 | 先选择、后加载；返回只合并数据，不抢当前选择；前端迟到响应回归 |
| 指数/黄金轮询可能丢弃已载入ETF | 合并保留已加载ETF，不主动重拉全部ETF |
| 自选缓存读取可能隐式重发上游请求 | peek只读内存，使用原抓取时间；过TTL标旧而不取数 |
| ETF与既有东方财富请求未共享冷却 | 双向共享来源冷却；结构化HTTP429也停试，不记录私密错误 |
| 导入/恢复的引用可能夹带数值或AI许可 | 创建、导入、启动、恢复工作副本均规范化白名单引用；AI检查payload禁止标记；源备份不变 |
| 同时请求可能重复开工作进程 | 来源锁单飞与最多2个新增工作进程；18秒上游超时、失败600秒冷却 |
| 极端数值和冲突日期可能污染图表 | 有限正数过滤、未来日期排除、冲突重复日剔除、比例溢出检查 |
| 盘中ETF日线可能被误认为收盘 | 16:30前排除当日；不复权、无净值/总回报的边界明确展示 |
| 独立演示没有正式应用样式变量 | 补演示局部样式与独立体验测试；不从后端请求资料 |
| 首页包体随研究页面扩大 | 研究项目页面延迟载入；构建主包约530KB、图表独立约541KB（压缩前），仍不是零成本 |

## 剩余边界与建议

没有全市场股票、个股F10、分红再投资、组合估值或交易功能；新底稿是引用和文字，不是新增行情数值研究档案。免费源字段、时效、连续性和授权仍需持续核验。优先收集外部用户是否完成并再次使用同一任务，再决定扩充资产或桌面安装形态。下一轮应补实机视觉、键盘/读屏、长时间运行和外部冷安装验证，不把这些当作本次已完成事项。
