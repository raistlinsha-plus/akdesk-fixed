# AKDesk Fixed v0.12.2「低门槛体验版」

> 版本：v0.12.2  
> 日期：2026-07-23  
> SQLite schema：1201（无迁移）

## 1. 版本目标

v0.12.2 不扩充数据源和研究模型，重点解决“功能已经很多，但第一次打开不知道先做什么”的问题。新体验使用现有数据状态生成明确的下一步，让市场用户先完成数据检查、自选和日度复盘，让投研用户先完成项目、专题、证据和周期复盘。

本版本不接入外部大模型。全局搜索中的自然语言式任务使用本地固定意图映射，不发送用户输入，也不会自动生成研究结论。

## 2. 新增能力

### 2.1 市场与投研动态清单

今日市场新增四项待办：

1. 确认数据可用状态；
2. 建立自己的观察清单；
3. 进入一个专业市场模块；
4. 形成今日复盘。

研究首页新增四项待办：

1. 提出一个可验证的问题；
2. 建立长期观察专题；
3. 保存第一份研究证据；
4. 处理到期复盘。

清单会读取当前真实状态。数据源已返回、自选已建立、项目或专题已存在、证据已保存时会自动标记完成；异常数据源和到期项目会显示为需要处理。两种清单分别记忆收起状态，偏好只保存在当前浏览器。

### 2.2 自然语言式任务入口

按 `Command + K` 打开全局搜索，未输入关键词时可直接选择：

- 今天市场怎么样；
- 开始一个研究；
- 整理一个专题；
- 为什么数据不可用；
- 跟踪信用债；
- 做每周复盘。

输入关键词后仍可搜索功能、证券、宏观指标和专题。

### 2.3 示例专题与关系引导

专题工作台明确解释四类研究资产：

- 专题：长期观察一个研究对象；
- 项目：回答一个可验证问题；
- 证据：保存带来源和时点的数据；
- 复盘：定期检查观点和下一步。

空专题库可一键创建“中国利率示例专题”。如果本机已有同一研究对象的专题，入口会直接打开现有专题，不重复创建。

### 2.4 渐进式表单与错误恢复

- 研究项目优先展示模板立项，自定义空白项目和库维护操作按需展开；
- 信用观察优先展示代码、名称、发行人、期限、评级、收益率、基准和来源等核心字段，主体属性、回售与复盘设置放入高级区；
- 统一错误状态提供重试建议和数据健康入口。

## 3. 兼容性与数据安全

- SQLite schema 保持 1201；
- 不新增表，不迁移、不批量改写研究数据；
- 项目、专题、证据篮、自选、信用观察、提醒和备份与 v0.12.1.1 完全兼容；
- 起步清单的收起状态只保存在浏览器 `localStorage`；
- 示例专题必须由用户点击创建，不会在升级或启动时自动写入数据库。

## 4. 使用建议

新用户可先选择更符合当天目的的入口：

- 只想快速了解行情：选择市场模式，按清单从数据状态和收益率曲线开始；
- 想形成持续研究记录：选择投研模式，先用模板建立项目，再创建示例专题并保存第一份证据。

熟悉产品后可以收起清单，既有专业页面和操作路径不受影响。
