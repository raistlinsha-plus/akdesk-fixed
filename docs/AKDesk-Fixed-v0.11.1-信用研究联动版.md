# AKDesk Fixed v0.11.1「信用研究联动版」

> 发布日期：2026-07-18  
> 数据库 schema：1100（无新增迁移）  
> 适用环境：macOS 12+，Apple Silicon MacBook Air，1440×900 及以上视口

## 1. 版本目标

v0.11.1 把 v0.11.0 的信用观察能力接入既有研究工作流，让“看到主体和信号”能够继续变成“建立研究问题、记录核验动作、进入周期复盘”，同时补齐多期信用资料的可携带导出。

本版不增加自动评级、违约概率、持仓或交易能力，也不改变既有信用利差的严格计算门禁。

## 2. 新增能力

### 2.1 发行人一键研究立项

发行人主档卡片增加研究项目入口。点击后，系统按主体归一名建立“信用债覆盖与利差观察”项目，并带入：

- 发行人名称与标识；
- 信用观察 R2 来源；
- 当前工作区观察日期；
- 覆盖、利差、事件和资料完整性的初始研究问题；
- `信用观察`、`覆盖率`、`issuer` 标签。

相同主体和模板已有未归档项目时，系统直接关联已有项目，不重复创建。发行人研究对象只用于立项，不会被静默加入行情自选。

### 2.2 信号确认沉淀为复盘

人工确认规则信号时，可以填写核验备注，并选择一个未归档研究项目。选择项目后，系统生成一条已完成的复盘记录，保存：

- 信号标题和正文；
- 发行人和债券；
- 观察日期；
- 数据来源或质量说明；
- 用户填写的核验备注。

项目选择是可选的。用户仍可只确认信号而不写入研究项目。已经确认的信号不会因为重复请求再次生成项目记录，人工确认也不代表投资结论。

### 2.3 多期信用历史导出

信用观察工具栏现在提供两种 CSV：

| 导出 | 内容 | 适用场景 |
| --- | --- | --- |
| 导出当前观察 | 每只债券当前主档一行 | 更新模板、当前覆盖盘点 |
| 导出多期历史 | 全部本地信用快照 | 多期变化复核、表格归档 |

多期文件按债券代码、收益率观察日期和记录时间从早到晚排列，字段与标准导入模板一致。CSV 不包含自定义组合、信号确认和项目关联；完整研究资产应继续使用研究库备份。

## 3. 推荐工作流

1. 在信用观察导入或维护已核验的单券资料；
2. 切换到“发行人”，从主体卡片建立覆盖项目；
3. 查看单券历史、主体范围、事件日历和规则信号；
4. 对信号填写核验备注，并选择相应发行人或其他研究项目；
5. 在研究项目中补充证据、反证、结论和下次复盘日期；
6. 定期导出多期历史，并使用研究库备份保存完整关联。

## 4. 可信边界

- 发行人归一名、评级、收益率、基准和来源均来自用户维护或用户确认的导入资料；
- 规则信号只基于本地字段、事件日期和机械利差变化，不判断信用资质；
- 发行人和组合仍只展示通过门槛单券的范围与样本数，不计算跨券简单平均；
- 信号写入项目是人工复盘记录，不是系统投资建议；
- 信用 CSV 只包含信用观察字段，不替代 SQLite 研究库备份。

## 5. 升级与回退

v0.11.1 沿用 schema 1100，不执行新迁移，也不重写已有信用观察、历史、组合、信号或研究项目。升级前仍建议在“研究项目”页立即备份，或关闭服务后复制 `data/` 目录。

如需回退到 v0.11.0.1，可先停止服务，再恢复升级前的 SQLite 备份。不要在服务运行时直接替换数据库文件。
