# AKDesk Fixed v0.8.1「双入口体验版」

## 版本目标

v0.8.1 将产品从单一“投研首页”入口调整为一个产品、两个工作模式：

- 市场模式：优先回答“今天市场发生了什么”；
- 投研模式：优先回答“今天有哪些研究需要推进”。

两个模式共享同一套数据、自选、提醒、研究项目、研究证据和本地 SQLite，不拆分安装包、权限或数据库。

## 首次使用

首次打开 v0.8.1 时，应用会要求选择默认入口。

### 市场模式

适合每日多次快速查看行情的用户，默认进入“今日市场”。

导航顺序为：

1. 今日：今日市场、我的自选、每日复盘；
2. 中国固收：资金面、收益率曲线、现券、国债期货、信用观察、可转债、国债发行；
3. 全球市场：美国宏观与利率、全球主权比较、图表研究室、数据发布复盘；
4. 投研与工具：研究首页、研究项目、每周复盘、固收计算器、数据健康。

### 投研模式

适合围绕项目、证据和复盘开展持续研究的用户，默认进入“研究首页”。

导航顺序为：

1. 研究工作台：研究首页、研究项目、我的自选、每周复盘；
2. 数据研究：图表研究室、美国宏观与利率、全球主权比较、数据发布复盘；
3. 市场观察：固收市场、资金面、收益率曲线、现券、国债期货、信用观察、可转债；
4. 复盘与工具：每日复盘、国债发行、固收计算器、数据健康。

## 模式切换

顶部工具栏新增“市场 / 投研”常驻切换器。

- 从“今日市场”切换到投研模式时，进入“研究首页”；
- 从“研究首页”切换到市场模式时，进入“今日市场”；
- 在曲线、现券、宏观等专业页面切换模式时，保留当前页面和筛选状态；
- 所有功能在两种模式中都可访问，不会因为模式选择被隐藏；
- `Command + 1` 打开当前模式首页；
- `Command + K` 继续搜索全部模式中的功能和标的。

## 入口设置

点击顶部模式切换器右侧的设置按钮，可以：

- 查看当前模式；
- 设置下次启动时的默认入口；
- 重新查看首次入口说明。

当前模式在本次浏览器会话中保留；默认入口保存在浏览器本地。入口设置不写入研究数据库，也不会进入项目备份。

## 首页职责

v0.8.1 进一步明确两个首页的职责。

### 今日市场

展示资金、收益率曲线、国债期货、活跃现券和重要事件，强调市场状态、变化和数据可信度。

### 研究首页

展示进行中项目、待复盘事项、自选、市场研究线索、证据保存入口和数据研究准备度，强调观点、证据和研究任务。

## 数据与兼容性

- 不新增数据库表；
- SQLite schema 继续为 800；
- 既有研究项目、证据、自选、提醒和缓存不迁移、不重建；
- 既有 `#/页面?q=标的` 深链继续有效；
- 正常模式和演示模式都支持双入口；
- 仍只监听 `127.0.0.1:8765`。

## 当前边界

v0.8.1 只调整产品入口和信息架构，没有在两个模式之间建立不同的功能权限，也没有新增外汇行情。

外汇与跨资产市场能力计划在后续“市场增强版”中单独实施，避免将入口重构与新数据源风险混在同一个版本。
