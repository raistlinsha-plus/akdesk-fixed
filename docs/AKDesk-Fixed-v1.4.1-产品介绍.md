# AKDesk Fixed v1.4.1 · 产品介绍

更新：2026-11-08。对应 v1.4.1；安装包与校验文件见 [GitHub Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/tag/v1.4.1)。

AKDesk 是一款本地优先的固收与宏观研究工作台。它把「市场发生了什么、能从哪里核验、我怎么看、下次查什么」串成一套可重复的工作。股、金、汇扩展让人更容易上手，固收、信用与持续研究仍是核心。

## 给谁用

主要用户是固收、宏观与信用研究人员，也适合希望用公开数据做独立研究的人。对保险资管业务人员，典型场景是盘前或盘后观察、周度公开资料复盘、跟踪信用线索、形成个人研究底稿。任何机构正式使用都应先核验原始数据授权、网络和信息安全要求。

对于不了解 FICC（固定收益、外汇和大宗商品）的科技同事，可以先看两个产出：有来源和时间的一页固收简报，以及区分四类资产口径的周复盘底稿。工程重点不是让 AI 给出交易建议，而是能在数据不齐时把可确认和待核验的信息分开。

## 模块与场景

| 模块 | 典型问题 | 能做什么 |
| --- | --- | --- |
| 今日市场、市场变化 | 今天哪里变化明显，值得回原模块看？ | 筛选资金、曲线等变化，按来源、时点和可信状态核验 |
| 资金面、收益率曲线、现券、期货、转债、国债发行 | 资金松紧、不同期限利率和供给有什么变化？ | 查看短期融资成本、期限结构、报价与事件；债券收益率变化不是持有回报 |
| 股债金汇观察 | 想看黄金、指数或一只 ETF 的日线 | 提供 Au99.99、四个指数和四个按需 ETF 示例，支持同类共同日期比较 |
| 股债金汇周复盘 | 一周结束后，四类市场各发生了什么？ | 分别查看沪深300、10年期国债收益率、Au99.99 和美元兑人民币参考价；每项独立核验、补读和导出查询底稿 |
| 信用观察 R2、事件线索 | 哪些发行人或事件需要继续跟进？ | 汇集线索、人工核验、关联证据与任务；事件命中不等于信用结论 |
| 外汇、美国宏观、全球主权、图表研究 | 海外利率、汇率和经济结构怎么看？ | 按不同频率与单位比较，保留来源、日期、缺口和许可边界 |
| 自选、项目、专题、每周研究复盘 | 观点为什么变了？还有哪些反证？ | 将个人观察、证据、任务和复盘基线串起来；项目周报不同于市场周复盘 |
| 每日复盘、一页简报、可选 AI | 怎样减少重复整理？ | 生成有出处的简报；用户自备 API 并确认后，AI 辅助整理允许处理的上下文 |
| 数据健康、使用与反馈、备份 | 为什么没有数据？如何安全升级？ | 区分未开盘、缺失、旧缓存和来源故障；预览脱敏诊断，管理本地备份 |

## 数据与架构

- 中国固收和部分外汇由 Python AKShare 接入；指数、黄金和 ETF 分别复用新浪、上金所和东方财富的既有路径。AKDesk 不要求单独启动 AKTools 服务。
- FRED 为可选的美国宏观数据 API，用户自备 Key；World Bank API v2 用于主权结构，GDELT 用于公开事件元数据。未加入新的行情源。
- React／TypeScript／Vite 提供界面，Python／FastAPI 运行本地服务，SQLite 保存研究数据。预构建界面面向 Apple Silicon MacBook Air；使用者不必安装 Node.js 或 Docker。
- 真实周复盘的导出只有查询引用、用户所选区间和人工文字，不包含行情观测日、数值或派生变化。FRED 和受限行情内容不进入 AI。具体许可与实现边界见[数据使用规则](../DATA_USAGE.md)。

本工具不是 Wind、Qeubee 或 DM 的授权行情或交易替代品，也不适合作为正式估值、监管报送或风控限额的唯一依据。建议先试固定合成样例，再决定是否用真实数据做每周任务。操作见[用户手册](./AKDesk-Fixed-v1.4.1-用户手册.md)。
