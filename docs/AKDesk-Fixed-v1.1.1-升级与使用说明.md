# AKDesk Fixed v1.1.1 升级与使用说明

本版为“数据使用边界与上游适配版”，发布日期2026-11-03，规则核验始于2026-11-02。它是 v1.1.0 的针对性补丁，不新增资产或数据源。与旧手册在本页涉及的 FRED 导出、保存、AI、复盘版本标记上有冲突时，以本页和 [DATA_USAGE](../DATA_USAGE.md) 为准。

## 如何升级

1. 用旧版本的停止脚本或原启动终端正常停止旧服务，再解压完整 v1.1.1 正式包。不要覆盖正在运行的目录。
2. 双击新包 `start-macos.command`，等待安装锁定的 AKShare 1.20.22 和原有依赖。Python 仍为3.11–3.13，MacBook Air 本地使用方式不变。
3. 默认沿用原有稳定数据目录；schema仍为1600，不搬移用户资料。请勿把个人数据库、Key或备份上传到 GitHub。

本版没有检查或操作你的实际 Key、研究库和个人文件。启动时产品既有的 FRED 校准流程会进一步将旧结构化引用收敛为查询参数；恢复旧备份后也会校准恢复的工作副本，不修改源备份。独立笔记、项目字段和证据标题保留，但其中手写/粘贴的受限内容需自行核查。

## 场景变化

- **可转债数据提示限流**：等待，或查看明确标注的新浪备用价格层；缺少比价字段时不补零。主源至少冷却5分钟，备用成功和强刷不会解除。不要频繁重启或更换代理绕过限制，5分钟也不保证恢复。
- **图表研究室导出**：改为“查询引用”Markdown，仅含用户选择的序列、年份/变换参数及应用生成的链接，不再下载 FRED 数值 CSV。
- **保存 FRED 研究证据**：只记查询引用，不保存官方响应中的数值、单位、注释、来源机构、更新时间和观测区间。重新打开引用会重新请求数据，不能当作历史快照。
- **发布复盘**：手工预期和自己的备注仍可保存；实际值和当前官方 vintage 仅本次展示。“标记已复盘”只记录本地时间，不保存 API vintage，因此不再自动判断官方版本是否改变。
- **AI 助手/页面洞察**：明确标记为 FRED 来源的证据、专题组件、发布复盘与元数据被排除，其他来源仍按授权范围处理。旧策略的 AI 摘要不再回显或续用；这不等于系统能识别未标来源的所有手工文本。请不要自行粘贴受限内容。
- **市场导出**：现券和转债 CSV 增加来源、链接、观测/抓取时点、状态及使用边界；简报复制/Markdown/打印也保留使用提醒。导出不等于可以任意公开分享或商用。
- **数据健康/使用与反馈**：可直接查看各源条款和规则核验日期。技术连接、质量门通过与使用授权是三个不同概念。

## 必须了解的限制

AKShare 和 AKDesk 的代码继续采用 MIT，不转授行情数据权利。机构业务使用需核验原始数据源授权；本版不是合规认证。FRED 自备 Key 不豁免条款。World Bank 默认开放许可存在指标例外，GDELT 不授予原新闻正文/图片版权。

本版不自动删除旧CSV、截图、源备份或其他个人文件，也不宣称这些文件全部符合现行规则。核验主源、实现和剩余风险见[数据使用规则](../DATA_USAGE.md)；通用安装、界面模块和反馈方式仍可参考[v1.1用户手册](./AKDesk-Fixed-v1.1.0-用户手册.md)。
