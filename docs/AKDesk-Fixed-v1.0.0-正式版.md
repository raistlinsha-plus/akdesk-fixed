# AKDesk Fixed v1.0.0「首个正式版」

> 发布日期：2026-07-31  
> 业务基线：v0.18.0「低门槛交付版」  
> 发布候选：v1.0.0-rc.1「发布工程候选版」  
> 数据库 schema：1600  
> 状态：正式版

## 1. 正式版结论

AKDesk Fixed 已具备面向个人研究者、在 Apple Silicon MacBook Air 本地运行的 v1.0.0 交付条件。

v1.0.0 没有在发布前继续叠加行情源、资产类别或 AI 场景，而是把已经形成的市场观察、固收投研、信用观察、全球数据和 BYOK AI 工作流做成可重复安装、可升级、可回退、可校验的产品包。

本版本适合个人研究、原型验证、业务场景演示和非生产级投研辅助；不替代 Wind、Qeubee、DM 等机构终端，不用于交易执行、正式估值、会计核算、自动评级或多人协同生产。

## 2. 从 rc.1 到正式版

候选版兼容矩阵发现 `numpy==2.5.1` 不支持 Python 3.11。正式封版前将其校准为 `numpy==2.4.6`，并重新验证 Python 3.11、3.12、3.13。

除该发布阻断修复外，正式版只包含：

- 版本号和发布元数据收口；
- 用户手册、产品介绍和测试基线更新；
- 正式发布包及 SHA-256 校验值；
- rc.1 到 v1.0.0 的同数据目录升级验证。

业务数据库 schema 仍为 1600，不新增迁移，不改变用户研究资料结构。

## 4. 正式发布物

运行：

```bash
.venv/bin/python scripts/release.py
```

会生成：

- `release/AKDesk-Fixed-v1.0.0.zip`：正式分发包；
- `release/SHA256SUMS`：归档校验值；
- 包内 `RELEASE_MANIFEST.json`：逐文件体积、权限和 SHA-256；
- `SBOM.cdx.json`：CycloneDX 1.5 软件物料清单；
- `THIRD_PARTY_NOTICES.md`：第三方生产依赖及许可证声明。

发布脚本会重新解压 ZIP 并验证清单、启动器权限、敏感凭据、用户数据排除和归档体积。

## 5. 安装与数据位置

正式包不包含 Python。推荐 macOS 12 或更高版本，以及 Python 3.11–3.13。

解压后双击：

```text
start-macos.command
```

全新安装的用户数据默认位于：

```text
~/Library/Application Support/AKDesk Fixed/
```

因此升级时可以把新版本解压到新目录，研究库仍沿用稳定数据目录。旧版项目如果自身 `data/` 已存在数据库或备份，会继续使用旧路径，不做静默搬移。

实际路径可在“数据健康”页面的服务信息中查看。

## 6. 升级与回退

推荐升级步骤：

1. 在旧版本“研究项目”页面创建备份；
2. 双击旧目录的 `stop-macos.command`；
3. 保留旧程序目录；
4. 解压 v1.0.0 到新目录；
5. 双击新目录的 `start-macos.command`；
6. 在“数据健康”确认版本、数据路径和连接状态；
7. 打开一个既有研究项目验证内容。

需要回退时，先停止 v1.0.0，再打开旧版本目录。不要在服务运行时直接替换 SQLite、WAL 或 SHM 文件。

## 7. 安全与数据边界

- FRED 和 AIHubMix API Key 由用户自行提供，验证后保存在 macOS Keychain；
- Key 不写入 SQLite、日志、前端缓存、导出文件或发布包；
- FRED 观测值按请求获取且不落盘；
- World Bank 数据按来源要求署名并持久缓存；
- GDELT 只缓存事件元数据，事实判断仍须打开原文核验；
- AI 对话不落库，页面洞察只缓存最终摘要与生成元数据；
- AI 不自动修改研究项目，不自动生成交易指令、仓位、评级或违约概率。

## 8. 已知边界

- 当前交付物仍是本地源码运行包，不是签名和公证的 `.app`；
- 首次安装依赖需要网络；
- AKShare 及公开数据源不提供机构级 SLA；
- 公开行情存在延迟、字段变化、反爬和节假日口径差异；
- 单机 SQLite 不是多人协作、权限分层和审计留痕平台；
- 产品结论只供研究参考，不构成投资建议。

## 9. v1.0 后的建议

正式版后的第一优先级不是继续扩大模块数量，而是：

1. 增加签名、公证和自动更新，进一步降低安装门槛；
2. 建立更长时间的稳态和真实网络故障观测；
3. 为机构试点增加可选的数据导入、权限和审计适配层；
4. 继续用“场景内嵌 AI”增强解释和复盘，但保持用户确认与引用边界；
5. 只有在维护成本、许可和稳定性可控时，再引入新的付费或外部数据源。
