# AKDesk Fixed v0.9.1「专题可用性增强版」

> 发布日期：2026-07-17  
> 升级性质：专题工作流与市场数据质量增强  
> 数据库 schema：900（无迁移）

## 1. 版本目标

v0.9.1 不增加新的大型数据域，重点把 v0.9.0 的专题投研能力从“功能完整”推进到“日常高频可用”：减少专题打开时的请求放大，允许用户维护保存的组件配置，让证据篮可管理，并把现券、可转债的字段质量边界直接落实到操作权限。

## 2. 专题聚合工作区

新增 `GET /api/v1/research/topics/{topic_id}/workspace`，一次返回：

- 专题和统一研究对象；
- 关联项目；
- 跨源研究时间线；
- 所有关联项目的规则化摘要；
- 工作区生成时间。

前端不再发起“专题详情＋时间线＋每个项目一条摘要”的 N+1 请求。专题关联项目越多，收益越明显。

## 3. 组件懒加载与请求去重

市场脉搏、本地历史、FRED 和 World Bank 组件在距离可视区域约 240 px 时才开始请求。尚未滚动到的组件只显示占位状态，不会提前占用网络和外部 API 配额。

相同路径的读取具有两层复用：

1. 请求仍在进行时，多个组件共享同一个 Promise；
2. 请求成功后短时复用结果，避免切换专题或重复组件立即重抓。

FRED 观测值仍只在请求和前端内存中处理，短时内存复用不会写入 SQLite、研究证据或浏览器持久存储。

## 4. 专题组件编辑

在“专题设置 → 保存的专题组件”中展开组件即可编辑：

| 组件 | 可编辑内容 |
| --- | --- |
| 本地历史 | 标题、数据源、指标字段、序列、历史天数、单位 |
| FRED 图表 | 标题、1–8 个序列、1–30 年范围、原值/变化/同比/标准化/Z-Score |
| World Bank 比较 | 标题、2–8 个经济体、指标、起止年度、水平/变化/排名/Z-Score |
| 市场脉搏、项目摘要、最近证据 | 标题 |

保存时后端按组件类型再次校验，不接受未知本地来源、非法 FRED 序列、超长时间范围或无效三位经济体代码。配置继续保存在既有专题 JSON 字段中，因此不需要数据库迁移。

## 5. 证据篮管理

证据篮新增：

- 全部、当前专题、尚未归属三种归属筛选；
- FRED、World Bank、市场与其他来源筛选；
- 起始日期筛选；
- 全选当前筛选结果；
- 最多 100 项批量清理。

批量清理是事务操作；只有证据篮项目被删除，不会删除已经提交的项目证据。来源研究对象在不再被专题、项目、证据或其他篮中项目引用时才安全清理。

## 6. 现券代码可信识别

AKShare 的中国外汇交易中心现券成交表通常只提供债券简称，不提供代码。v0.9.1 不把简称直接冒充代码，只对以下严格标准格式做保守推导：

- `YY附息国债NN`；
- `YY国开NN`；
- `YY进出NN`；
- `YY农发NN`。

推导结果会显示“标准简称规则推导，需核验”，并降低数据质量分。核验前不能直接加入自选、设置提醒或创建研究项目。无法使用严格规则识别的信用债、存单和其他现券继续显示“代码未提供”。

## 7. 可转债数据层级

每条可转债现在标记为：

- **完整比价**：至少具有价格、转股价值、溢价率和双低字段；
- **部分比价**：来自比价源，但个别核心字段缺失；
- **仅价格**：备用源只提供代码、名称、价格和涨跌幅。

仅价格记录会进入部分可用状态，可以观察价格并加入自选，但不会开放一键研究立项；溢价率、双低和 YTM 为空时不参与对应筛选与排序。CSV 增加“数据层级”列，避免导出后丢失边界。

## 8. 升级说明

停止旧版服务后双击 `start-macos.command`。启动器会校验 v0.9.1。

本版 schema 仍为 900，不新增表、不重写专题组件，也不迁移现有数据。专题、组件、项目、证据、自选、提醒、市场历史、World Bank 缓存和 FRED Keychain 凭据全部保留。
