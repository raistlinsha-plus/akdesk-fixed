# AKDesk Fixed v1.4.0 · 股债金汇周复盘

这是面向个人学习和研究的本地工具。用一个页面回答：过去一周，股、债、金、汇各自发生了什么？哪些可以确认，哪些还要回到原模块核验？

## 怎么开始

1. 停止旧服务，解压新版到新目录，或启动已经更新的主工程。双击 `start-macos.command`；服务就绪后会打开浏览器。
2. 在市场模式「今日」或投研模式「研究工作台」打开 **股债金汇周复盘**。先看固定合成样例，或选择周结束日并点击「读取本周」。默认取北京时间已过去的最近一个周五；可选择过去 90 天内、早于今天的日期。
3. 每项先看状态和实际观测日期，再看变化。债、汇缺本地历史时，可以到收益率曲线、外汇市场补充数据，再返回重读。
4. 写下「我的判断与下周待核验事项」，预览或下载 Markdown。真实模式导出查询引用、所选区间和人工备注，不含数值、派生变化或实际观测日期；文本不自动保存。合成样例可带合成变化导出。

## 四条序列怎么看

| 观察项 | 数据从哪来 | 显示什么 |
| --- | --- | --- |
| 股 · 沪深300 | 既有新浪日线 / AKShare | 指数价格变化 %，不是总回报 |
| 债 · 10年国债收益率 | 既有本地中债曲线历史 | 收益率变化 BP，不是债券价格回报 |
| 金 · Au99.99 | 既有上金所日线 / AKShare | 现货价格变化 %，不是黄金 ETF 回报 |
| 汇 · 美元兑人民币参考中间价 | 既有本地人民币参考价历史 | 元/美元报价变化 %；正值表示每美元对应更多人民币 |

以所选结束日及其前 6 天为本期，紧邻的前 7 天为前期。每项取两个区间各自最后一个有效观测。若有节假日或数据缺失，四项日期可能不同；任一区间无有效点就显示「—」，不跨区间取旧值，不补零。来源失败或旧缓存单独标记，不等同于市场休市。页面不计算组合回报或归因。

「每周研究复盘」继续用于项目、反证、任务和观点更新；「股债金汇周复盘」看的是市场，两者互不覆盖。

## 升级与启停

- 默认服务地址为 `http://127.0.0.1:8765`。同安装、同模式、同数据目录才会复用；有冲突时到原启动窗口按 Control+C，或用对应版本停止器。
- 新版默认演示数据目录与正式版分开。不迁移旧库：同主工程的原数据继续使用；若旧版使用解压目录里的 `data` 或自定义路径，先备份并继续明确指定原 `AKDESK_DATA_DIR`，不要删除旧目录。
- `AKDESK_PORT` 可从终端指定，启动和停止须用相同值。关闭浏览器不等于停止。
- 没有新增交易、外部 API、数据授权、自动遥测或 AI 能力。见[数据使用规则](../DATA_USAGE.md)。
