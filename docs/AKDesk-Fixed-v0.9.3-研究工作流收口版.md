# AKDesk Fixed v0.9.3「研究工作流收口版」

> 交付方式：作为 v0.10.0 合并升级的第二阶段一并交付  
> 数据库兼容：SQLite schema 900，不迁移、不改写既有研究数据

## 版本目标

v0.9.3 不再增加新的研究对象，而是把现有的专题、项目、证据、结论和复盘串成更清楚的日常路径，让初次使用者知道从哪里开始，让长期使用者更快回到下一项研究动作。

## 推荐研究路径

投研首页现在显示五步闭环：

1. 发现问题：从市场信号、宏观指标或专题中识别待验证问题；
2. 建立项目：写下问题和初始假设；
3. 保存证据：把市场快照、FRED 引用或 World Bank 快照沉淀到项目；
4. 更新观点：记录结论、置信度、反证和风险点；
5. 定期复盘：按复盘日期检查观点是否仍然成立。

系统依据本地项目、证据、结论和到期状态高亮建议步骤；这只是工作流提示，不代替研究判断。

## 研究项目体验

每个项目展示六项闭环完成度，并给出一个可执行的下一步。编辑器默认突出高频字段：标题、研究问题、状态、主观置信度和当前结论；初始假设、研究期限、复盘日期与标签放在可展开区域，减少第一次立项的输入负担。

## 专题与复盘

- 专题页面默认进入阅读状态，把专题设置改为按需打开，避免低频配置长期占据主流程；
- 无专题状态解释“专题长期观察、项目验证问题、证据篮暂存资料”三者关系；
- 每周复盘新增本周观点、下周待验证和下次复盘；默认使用上海当前日期作为周结束日，日期范围始终可见；
- Markdown 周报同步包含观点、任务和复盘日期，方便个人归档。

## 数据边界

完成度、步骤提示和周报只汇总本机已有研究记录。系统不会根据市场数据自动写入结论，也不会将 FRED 请求级观测值持久化为离线数据库。
