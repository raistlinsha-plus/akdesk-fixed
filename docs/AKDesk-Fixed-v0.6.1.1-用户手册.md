# AKDesk Fixed v0.6.1.1 用户手册

> 适用版本：v0.6.1.1「可信修复版」  
> 适用系统：macOS 12 或更高版本  
> 默认地址：`http://127.0.0.1:8765`

## 1. 使用前须知

AKDesk Fixed 是本地个人研究工具，不是交易终端。它适合查看公开行情、组织研究证据、记录观点和复盘，不适合作为下单、正式估值、会计入账或风控审批的唯一系统。

首次使用建议先理解三个概念：

1. **观测时间**：原始数据代表的市场或统计时点；
2. **抓取时间**：本机从数据源取得数据的时间；
3. **研究可用性**：综合连接、缓存、质量和可信等级后，数据是否适合进入研究流程。

市场休市不等于数据不可用。盘前、午休、盘后或非交易日时，应用会显示最近可信快照及相应市场状态。

## 2. 系统要求

- macOS 12 或更高版本；
- Python 3.11、3.12 或 3.13；
- 首次安装 Python 依赖时需要网络；
- 正常使用 FRED 时需要用户自己的 FRED API Key；
- 建议使用 Safari、Chrome 或其他现代浏览器；
- 建议至少保留 1 GB 可用磁盘空间用于虚拟环境、依赖和本地数据。

如果尚未安装合适的 Python，可在安装 Homebrew 后执行：

```bash
brew install python@3.13
```

## 3. 启动与关闭

### 3.1 正常模式

在 Finder 中打开项目目录，双击：

```text
start-macos.command
```

首次启动会：

1. 检查 Python 版本；
2. 创建项目独立的 `.venv`；
3. 安装后端依赖；
4. 在缺少前端构建文件时执行前端构建；
5. 启动本地服务并打开浏览器。

正常地址：

```text
http://127.0.0.1:8765
```

应用只监听本机回环地址，不对局域网或公网开放。

### 3.2 演示模式

完全离线体验界面时，双击：

```text
start-macos-demo.command
```

演示模式的数据只用于体验页面，不代表真实市场，也不会成为正式研究证据或触发提醒。

### 3.3 关闭应用

关闭启动器所在的终端窗口，或在终端中按 `Control+C`。仅关闭浏览器标签不会停止后端服务。

### 3.4 macOS 阻止脚本运行

首次被 macOS 阻止时，可以在 Finder 中右键启动器，选择“打开”。如脚本没有执行权限，在项目目录运行：

```bash
chmod +x start-macos.command start-macos-demo.command
```

## 4. 首次配置 FRED

中国固收行情不需要 FRED Key。只有“美国宏观与利率”“图表研究室”和 FRED 发布日历需要配置。

配置步骤：

1. 登录 FRED 并申请个人 API Key；
2. 打开侧栏“全球宏观 → 美国宏观与利率”；
3. 在 FRED 配置区域输入 32 位 Key；
4. 点击“保存并验证”；
5. 等待页面显示连接验证成功。

验证成功后：

- Key 保存在 macOS Keychain；
- Key 不会写入 SQLite、日志、浏览器缓存或导出文件；
- FRED 观测值按需请求，不写入本地数据库；
- 用户主动导出的 CSV 会包含当次请求取得的数据和来源说明。

如果页面显示“已配置，待验证”，点击“验证连接”即可。移除凭据会删除 Keychain 中的凭据，但不会删除研究项目、自选或中国市场数据。

## 5. 界面与快捷操作

### 5.1 左侧导航

导航分为四组：

- 工作台：投研首页、固收市场、我的自选、研究项目；
- 市场：资金面、收益率曲线、现券市场、国债期货、信用观察 Beta、可转债；
- 全球宏观：美国宏观与利率、图表研究室；
- 研究：每日复盘、国债发行、固收计算器、数据健康。

### 5.2 全局搜索

点击左侧“搜索功能或标的”，或按：

```text
Command + K
```

可搜索功能、现券代码或名称、国债期货、可转债及 FRED 精选指标。选择结果后会直接进入对应页面。

### 5.3 刷新当前页面

点击顶部刷新按钮，或按：

```text
Command + R
```

应用会拦截浏览器刷新快捷键并请求当前页面数据。已有缓存时，页面通常先返回缓存，再由后台更新。

### 5.4 提醒中心

点击顶部铃铛打开提醒中心。可以创建、试算、暂停、恢复和删除提醒，并查看触发历史与未读数量。

## 6. 推荐的日常工作流

### 6.1 盘前检查

1. 打开“投研首页”；
2. 确认顶部显示“主要市场未开盘”，而不是把盘前误认为已收盘；
3. 查看市场研究线索和数据可信状态；
4. 打开“数据健康”，确认关键源是研究可用或受限可用；
5. 查看已有研究项目的复盘日期和自选备注。

盘前期货若只有上一交易日 15:15 的数据属于正常现象。应用不会把这个时点拼接成当天未来时间。

### 6.2 盘中观察

1. 在“固收市场”查看资金、曲线、期货和现券；
2. 进入专业页面检查详细数据；
3. 对可信标的加入自选或设置提醒；
4. 在投研首页选择值得跟踪的线索；
5. 保存到已有研究项目，形成中国市场快照证据。

### 6.3 收盘复盘

1. 打开“每日复盘”；
2. 检查报告模式、综合可信度和数据说明；
3. 查看资金、曲线、期货、现券异动和发行事件；
4. 导出 Markdown 或打印为 PDF；
5. 更新研究项目的结论、状态、置信度和下次复盘日期。

### 6.4 宏观专题研究

1. 在“美国宏观与利率”搜索指标；
2. 查看指标详情、单位、频率、来源和更新时间；
3. 点击进入“图表研究室”；
4. 添加最多 6 条序列，选择区间和变换；
5. 导出 CSV，或把序列引用保存到研究项目；
6. 在项目中记录当前结论与风险点。

## 7. 投研首页使用说明

投研首页是推荐的起点。

### 查看研究概览

页面会显示进行中项目、待复盘事项、自选数量和 FRED 准备状态。点击对应区域可进入详细模块。

### 查看市场研究线索

线索来自资金、10Y 国债、期限利差、国债期货和可信现券异动。每条线索包括：

- 变化摘要；
- 来源；
- 观测时间；
- 质量分；
- 显著程度；
- 是否允许保存为证据。

演示数据、质量分过低、不可用数据、异常隔离现券和缺失可信代码的现券不能保存为正式市场快照。

### 保存市场快照

1. 至少创建一个未归档研究项目；
2. 勾选允许保存的市场线索；
3. 选择目标研究项目；
4. 可填写一段研究备注；
5. 点击“保存市场证据”；
6. 保存成功后进入研究项目查看。

中国市场快照会保存当时的信号值、来源、观测时间、抓取时间、市场状态和质量信息。

## 8. 固收市场与专业行情页

### 8.1 固收市场

固收市场是一屏总览。点击卡片或模块入口可进入资金、曲线、期货、现券和发行事件页面。

页面底部的来源信息应与数值一起阅读。看到缓存、过期、部分可用或异常隔离标签时，不要只根据数值下结论。

### 8.2 资金面

资金页展示 Shibor、FR、FDR 和 LPR。重点关注：

- 当前值；
- 相比前值的 BP 变化；
- 数据日期；
- 独立数据源状态。

FR 或 FDR 单独失败时，其他资金指标仍可正常使用。进入数据健康页可对失败源单独重试。

### 8.3 收益率曲线

曲线页提供：

- 最新期限结构；
- 相对前值的 BP 变化；
- 10Y–1Y、10Y–5Y、30Y–10Y 等利差；
- 30、90、365 天历史范围。

历史覆盖天数取决于本地已积累的可信数据，不应把较短本地历史误认为官方完整历史库。

### 8.4 现券市场

可以使用以下筛选：

- 代码、名称或类型搜索；
- 债券类型；
- 最低和最高收益率；
- 最小绝对异动 BP；
- 收益率、异动或成交量排序。

常用操作：

- 输入视图名称并保存当前筛选；
- 载入、覆盖或删除浏览器本地保存的视图；
- 导出当前筛选结果为 CSV；
- 点击星标加入或移出自选；
- 对可信标的创建提醒。

如果债券代码缺失或记录被标记为异常，加入自选和提醒会被阻止。

### 8.5 国债期货

期货页展示 TS、TF、T、TL 合约的价格、涨跌幅、成交量和持仓量。

盘前看到上一交易日 15:15 的快照属于正常情况。若源未提供交易日，页面会标记日期为推断且可信度为部分可用。应用拒绝任何晚于当前时间的行情观测。

### 8.6 可转债

可以按以下条件筛选：

- 代码、名称或正股；
- 最高价格；
- 最高转股溢价率；
- 最高双低值；
- 最低到期收益率；
- 指定字段排序。

支持保存筛选视图、CSV 导出、自选和提醒。主数据源失败并切换到价格备用源时，溢价率、双低和 YTM 可能为空，页面会明确提示。

### 8.7 国债发行

展示近期国债发行与事件日期，用于安排研究日历。公开发行数据可能按日更新，不应理解为交易级实时数据。

### 8.8 信用观察 Beta

当前页面仅用于说明信用数据准备状态。主体归一化、评级日期、剩余期限、基准曲线和信用利差模型尚未达到正式发布门槛。

请勿使用该页面进行信用评级、违约概率或正式投资判断。

## 9. 美国宏观与图表研究

### 9.1 搜索与查看指标

在“美国宏观与利率”中：

1. 使用搜索框输入 FRED 代码或指标名称；
2. 使用主题筛选缩小范围；
3. 选择指标查看详情；
4. 检查单位、频率、季调、来源机构和最后更新时间；
5. 点击刷新按钮重新请求 FRED 官方数据。

### 9.2 图表研究室

操作步骤：

1. 从下拉框添加序列，最多 6 条；
2. 选择研究区间，范围为 1–50 年；
3. 选择变换：原值、单期变化、官方同比、归一化或 Z-Score；
4. 阅读图表下方来源、vintage 和变换说明；
5. 点击“CSV”导出当次结果；
6. 选择研究项目并点击“保存引用证据”。

保存的是序列代码、来源、区间和变换引用，不是 FRED 数值副本。项目中的“以当前官方版本重新打开”会重新请求当前数据，官方修订可能导致图表与当时不同。

### 9.3 FRED 发布日历

发布日历显示计划发布日期，不等于该指标实际观测日期或最终发布时间。查看数据时应同时检查序列本身的最后更新时间。

## 10. 研究项目

### 10.1 创建项目

1. 打开“研究项目”；
2. 输入研究标题；
3. 输入希望验证的问题；
4. 点击“创建项目”。

建议使用可验证的问题作为标题或研究问题，例如“未来 1–3 个月长端利率是否继续上行”，避免只写“利率研究”。

### 10.2 编辑项目

项目支持：

- 标题；
- 研究问题；
- 初始假设；
- 状态：草稿、跟踪中、已形成观点、待复盘、已归档；
- 主观置信度 0–100；
- 研究期限；
- 下次复盘日期；
- 标签；
- 当前结论与风险点。

修改后点击“保存项目”。状态、置信度和其他字段变更会进入观点轨迹。

### 10.3 添加证据

证据有两条主要路径：

1. 在投研首页保存中国市场快照；
2. 在图表研究室保存 FRED 引用证据。

展开证据可以查看来源、观察区间、保存方式、研究备注和市场信号。删除证据前会要求确认，并在观点轨迹中留下移除事件。

### 10.4 观点轨迹

观点轨迹自动记录：

- 项目创建时的初始状态和置信度；
- 项目字段更新；
- 状态与置信度前后值；
- 证据新增和移除。

长文本只记录发生变更的字段，不复制全部正文，以控制本地数据库体积。

### 10.5 删除与归档

- 暂时不再研究但希望保留记录：将状态改为“已归档”；
- 完全删除：点击项目删除按钮并确认。

删除项目会同时删除其研究证据，且无法在应用内撤销。执行前建议备份 `data/` 目录。

## 11. 我的自选

### 11.1 加入自选

可以从现券、国债期货、可转债和美国宏观指标页面点击星标加入自选。

### 11.2 管理研究信息

在“我的自选”中可以：

- 按分组筛选；
- 置顶；
- 设置研究状态；
- 设置下次复盘日期；
- 编辑标签和研究备注；
- 移除自选。

备注和标签在输入框失去焦点后自动保存。当前自选页主要用于管理研究上下文，不展示完整实时行情；查看最新价格、收益率和可信状态时，请返回对应市场页面。

### 11.3 宏观与证券的区别

FRED 指标可以加入自选并参与研究管理，但不会进入证券行情阈值提醒。证券提醒仅支持现券、国债期货和可转债。

## 12. 提醒中心

### 创建提醒

1. 先把可信证券加入自选；
2. 点击顶部铃铛；
3. 选择标的和指标；
4. 设置比较符、阈值、冷却时间、每日触发上限和静默时段；
5. 点击试算，检查当前值是否满足；
6. 点击“创建提醒”。

提醒在条件首次满足或重新穿越阈值时触发，不会在条件持续满足时无上限重复通知。

### 管理提醒

- 暂停或恢复规则；
- 查看最近判断值与评估时间；
- 删除规则；
- 查看触发历史；
- 将未读记录标为已读。

演示数据、过期缓存、异常隔离记录和不可信标的不会触发正式提醒。

## 13. 每日复盘

每日复盘自动汇总：

- 资金面与平均变化；
- 收益率曲线与关键利差；
- 国债期货；
- 现券异动与活跃券；
- 近期和待发生发行事件；
- 数据可信度与异常隔离；
- 进行中项目、待复盘项目和自选摘要。

报告会按本地日期归档到 SQLite。可以：

- 选择历史日期离线回看；
- 返回今日复盘；
- 导出 Markdown；
- 使用浏览器打印功能保存为 PDF。

综合可信度是数据完整性提示，不是市场方向评分或投资评级。

## 14. 固收计算器

根据页面表单输入债券面值、票息、价格或收益率、到期日、付息频率和计息规则，提交后可查看：

- 应计利息；
- 全价；
- 到期收益率；
- 麦考利久期；
- 修正久期；
- 凸性；
- DV01；
- 利率变动情景价格；
- 现金流明细。

计算结果适合学习和情景研究，不替代正式估值系统。使用前应确认债券条款、税收、提前赎回、含权结构和市场惯例是否适用。

## 15. 数据状态说明

### 15.1 市场状态

| 状态 | 含义 |
| --- | --- |
| 未开盘 | 当前交易日尚未进入该市场首个交易时段 |
| 交易中 | 当前时间处于至少一个交易时段 |
| 午间休市 | 当前交易日处于两个交易时段之间 |
| 已收盘 | 当前交易日的交易时段已经结束 |
| 非交易日 | 周末或交易日历确认的非交易日 |
| 日频数据 | 按日或按发布周期更新，不使用盘中状态 |

### 15.2 连接状态

| 状态 | 含义 |
| --- | --- |
| 健康 | 本次实时请求成功 |
| 缓存可用 | 有真实本地缓存，但本次尚未完成实时验证 |
| 降级 | 实时更新失败，正在使用最近真实缓存或过期缓存 |
| 不可用 | 没有可用真实数据，可能只显示演示内容 |
| 未检查 | 当前进程尚未请求该数据源 |

### 15.3 研究可用性

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 研究可用 | 连接和可信度达到正式研究门槛 | 可进入日常研究流程 |
| 受限可用 | 数据真实但来自缓存、部分字段缺失或日期经过合理推断 | 使用时阅读警告并交叉验证 |
| 不可用于研究 | 演示、无真实数据、异常过多或可信度不足 | 仅用于排查，不形成正式结论 |
| 待检查 | 当前进程尚未完成连接或可信判断 | 刷新或进入模块触发检查 |

### 15.4 可信等级

- 可信：主要字段、时间和质量达到门槛；
- 部分可用：存在明确缺口，但仍可在限制条件下研究；
- 含异常隔离：部分记录触发质量规则，不应直接进入研究；
- 不可用：演示或真实数据不足。

## 16. 数据健康中心

遇到数据问题时优先打开“数据健康”。

### 查看单个数据源

每个数据源显示：

- 连接状态；
- 研究可用性；
- 数据时间；
- 可信等级；
- 缓存年龄；
- 下次检查或恢复探测时间；
- 质量评分和质量问题；
- 异常隔离数量；
- 连续失败次数和熔断状态。

### 单源重试

点击数据源旁的“重试”。重试只影响当前适配器，不会删除其他数据或研究内容。

### 清空缓存

“清空缓存”会删除中国市场行情缓存，但不会删除：

- 研究项目与证据；
- 自选；
- 提醒和触发历史；
- 日报归档；
- FRED Keychain 凭据。

清空后各模块需要重新请求数据，公开接口较慢或失败时可能暂时显示不可用。

## 17. 数据备份与恢复

当前版本没有图形化的整库备份按钮。建议定期手工备份。

### 17.1 备份

1. 关闭 AKDesk Fixed；
2. 在项目目录复制整个 `data/` 文件夹；
3. 将副本保存到日期命名的备份目录。

例如：

```bash
cp -R data "data-backup-$(date +%Y%m%d-%H%M%S)"
```

备份内容包括研究项目、证据、中国市场快照、自选、提醒、日报和行情缓存。FRED Key 保存在 macOS Keychain，不包含在该目录中。

浏览器中的筛选视图保存在浏览器本地存储，也不包含在 `data/` 备份中。

### 17.2 恢复

1. 关闭应用；
2. 先备份当前 `data/`；
3. 用历史备份替换项目目录中的 `data/`；
4. 重新启动应用；
5. 打开数据健康中心检查各数据源。

不要在应用运行过程中替换 SQLite 文件。

## 18. 常见问题与故障排查

### 18.1 页面显示“未开盘”或“已收盘”，是不是没有数据

不一定。市场状态只说明当前交易阶段。页面仍可能显示最近真实快照。检查模块底部的观测时间、数据状态和可信等级。

### 18.2 多个模块显示数据不可用

1. 打开数据健康中心；
2. 判断是未检查、不可用还是受限可用；
3. 查看错误信息和是否存在真实缓存；
4. 对关键源执行单源重试；
5. 检查网络和公开数据源状态；
6. 不要把演示数据作为真实行情使用。

### 18.3 期货在早晨显示昨天 15:15

这是正常的盘前最近快照。v0.6.1.1 不会把缺少交易日的 15:15 拼接成当天未来时间。页面会显示“未开盘”和部分可用提示。

### 18.4 FR/FDR 出现证书错误

v0.6.1.1 已给隔离进程配置可信 CA bundle，并保持 TLS 校验。如果升级后仍出现问题：

1. 确认应用版本是 v0.6.1.1；
2. 关闭并重新启动应用；
3. 在数据健康中心分别重试 FR 和 FDR；
4. 确认公司代理或安全软件没有替换 HTTPS 证书；
5. 必要时重新安装项目依赖。

不要通过关闭证书验证解决问题。

### 18.5 FRED Key 验证失败

- 检查 Key 是否为完整 32 位字符串；
- 确认网络可以访问 FRED；
- 401/403 通常表示 Key 无效；
- 429 表示请求过于频繁，等待后再试；
- 连续失败后会暂时熔断，数据健康页会显示恢复探测时间。

验证失败时，新 Key 不会覆盖原有有效凭据。

### 18.6 端口 8765 被占用

启动器会提示端口已被其他版本或无响应进程占用。先关闭旧版启动窗口；如仍存在，可在“活动监视器”结束对应 Python 进程后重新启动。

### 18.7 首次启动很慢

首次需要创建虚拟环境并安装 AKShare、FastAPI、pandas 等依赖，通常需要数分钟。之后启动会明显更快。

### 18.8 自选卡片没有显示最新价格

当前自选页用于管理分组、标签、研究状态、备注和复盘日期，尚未集成完整行情卡片。请通过全局搜索或对应市场页面查看最新行情和可信状态。

### 18.9 信用观察为什么没有正式指标

公开信用数据的主体、评级日期、剩余期限和基准曲线尚未达到可信计算门槛。当前页面是 Beta 数据验证入口，不是功能故障。

### 18.10 World Bank 数据在哪里

当前版本尚未接入 World Bank Indicators API。该能力属于后续独立版本，不在 v0.6.1.1 范围内。

## 19. 数据文件说明

| `data/akdesk-fixed.db` | 研究项目、证据、自选、提醒、日报、搜索索引和可信历史 | 否 |

## 20. 隐私、安全与合规边界

- 服务默认只监听本机 `127.0.0.1`；
- FRED Key 保存至 macOS Keychain；
- FRED 观测值不写入 SQLite；
- 中国市场快照和研究资料保存在本地；
- macOS 通知只用于用户创建的本地提醒；
- 应遵守 AKShare 对应原始数据源、FRED 及序列原始提供者的条款；
- 不应向他人重新分发受限制的数据集；
- 本软件不构成投资建议。
