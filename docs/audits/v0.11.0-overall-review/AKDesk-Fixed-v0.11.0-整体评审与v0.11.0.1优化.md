# AKDesk Fixed v0.11.0 整体评审与 v0.11.0.1 优化

> 评审日期：2026-07-18  
> 评审环境：macOS、1440×900、独立临时 SQLite、`AKDESK_DEMO=1` 受控界面数据  
> 优化版本：v0.11.0.1「信用可信与工作流修复版」  
> 数据库：schema 1100，不新增迁移、不改写正式研究数据

## 1. 结论

v0.11.0 的市场/投研双入口、研究项目、信用历史、组合、信号、数据健康和 schema 900→1100 迁移闭环成立，没有发现 P0 阻断问题。评审确认三项需要在补丁版立即处理的问题：空白可选枚举列阻断导入、信用页首屏被维护表单占用、跨异质债券显示简单平均机械利差。

上述问题已经在 v0.11.0.1 修复；同时增加当前信用观察 CSV 导出、页签语义和上海自然日口径。完整自动回归为后端 116 项、前端 52 项。

## 3. 主要发现与处置

| 优先级 | 发现 | 影响 | 处置 |
| --- | --- | --- | --- |
| P1 | CSV/Excel 中“基准期限”列存在但单元格为空时，解析成空字符串并触发枚举校验错误 | 缺基准本应允许入库并显示“不计算”，实际会阻断整批确认导入 | 空白可选枚举归一为 `null`；增加函数与 HTTP 回归 |
| P1 | 信用页先展示信号、导入和 19 字段表单，1440×900 首屏看不到单券结果 | 高频观察任务被低频维护任务遮挡 | 数据维护默认收起；三级观察、筛选和单券结果前置；信号后置 |
| P1 | 发行人和组合展示不同期限、评级债券的简单平均机械利差 | 容易形成伪精确的主体或组合结论 | 改为通过门槛单券的最小值–最大值范围与样本数 |
| P2 | 信用数据缺少轻量可移植出口 | 用户只能依赖整库备份带走当前主档 | 增加与标准导入模板同字段的 UTF-8 CSV 导出；完整历史仍走整库备份 |
| P2 | 信用三级切换仅为视觉按钮组，辅助技术无法稳定识别选中页签 | 键盘和读屏定位成本较高 | 增加 `tablist`、`tab`、`tabpanel`、`aria-selected` 和关联 ID |
| P2 | 信号确认按钮同名，搜索框只有占位符 | 多条信号下可访问名称不唯一 | 确认按钮带信号标题；搜索框增加明确名称 |
| P2 | 信用事件“今天”依赖运行机器本地时区 | 非中国时区运行可能提前或延后一日 | 统一使用 Asia/Shanghai 自然日 |
| P3 | 直接访问 `/credit` 不会恢复信用页，页面状态由单页应用内部维护 | 浏览器书签、分享和刷新后的页面恢复有限 | 本补丁不扩大架构范围；建议后续引入 URL 可恢复路由 |
| P3 | 测试栈提示 Starlette `TestClient` 的 httpx 兼容层弃用警告 | 当前不影响运行，未来依赖升级可能需要迁移 | 记录为技术债；依赖稳定后迁移到新测试传输层 |

## 4. 核心流程健康度

1. **市场 / 投研入口切换：通过。** 两个入口共享同一数据和研究资产，导航顺序和首页职责清晰；非交易日状态与演示数据边界可见。
2. **信用日常观察：通过（已优化）。** 摘要、三级切换、搜索、状态筛选和单券结果进入首屏；阻断原因、历史期数和机械试算口径可见。
3. **信用数据维护：通过（已优化）。** 数据维护可展开/收起，CSV/Excel 预览、映射、逐行错误、新增和编辑仍完整保留。
4. **发行人与组合口径：通过（已优化）。** 只显示通过门槛单券的机械利差范围与样本数，不再展示跨券平均。
5. **研究项目闭环：通过。** 问题、状态、置信度、结论、任务、观点轨迹和证据均可追溯；完成度会提示缺少反证或失效条件。
6. **数据健康：通过。** 连接状态和研究可用性分开呈现，演示/降级数据不会被标成可信研究证据；运行资源可见。

## 5. 验证结果

- 后端：`116 passed`；Ruff 通过；唯一警告为测试依赖兼容层弃用提示。
- 前端：`52 passed`；ESLint、TypeScript 和生产构建通过；npm 官方安全审计 0 个已知漏洞。
- 信用空白可选列 HTTP 预览：1 行有效、0 错误。
- 信用当前观察导出：UTF-8 CSV，3 行（表头 + 2 个当前单券），字段与标准模板一致。
- 视觉：1440×900 优化前后截图已保存并逐张检查；优化后首屏可直接完成主要观察任务。
- 文档：检查 99 个本地 Markdown 链接，0 个缺失；产品介绍、用户手册、README 和更新记录已同步。
- 数据：正式库 `quick_check=ok`、schema 1100；补丁无新迁移、无正式库数据改写。切换前安全副本为 `data/backups/before-v0.11.0.1-20260718.db`。
