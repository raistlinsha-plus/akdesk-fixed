# v0.18.0 市场变化中心视觉重构复核

日期：2026-07-28

## 结论

本轮在不改变数据源、可信门禁、筛选逻辑、已读快照和模块跳转规则的前提下，重构了市场变化中心的信息层级与阅读路径。页面由“大摘要 + 分散指标 + 双列卡片”调整为“紧凑决策摘要 + 单行筛选工具栏 + 全宽可核验信号流”，在 1440×900 的 MacBook Air 主视口下可以连续阅读三条核心变化，不再出现第三张卡片落单和视觉重心分散的问题。

## 主要调整

- 首屏摘要整合市场状态、核心结论、可信可行动数量、上次查看后变化、质量门槛、更新时间和快照资格。
- 筛选区域压缩为一条工作栏，集中展示可见数量、可信门禁、质量阈值、优先级、恢复默认和标记已读。
- 变化项改为带序号的全宽信号流，左侧呈现结论与触发原因，右侧独立呈现来源、时点、质量和可信状态。
- 原“查看原始模块”改为“去资金面核验”“去收益率曲线核验”等目标明确的动作。
- `trusted` 等内部枚举改为中文用户文案；继续使用现有设计令牌与 Lucide 图标。
- 增加 1180、760、560 px 响应式收口，避免窄屏横向溢出。
