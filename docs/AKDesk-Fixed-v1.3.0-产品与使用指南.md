# AKDesk v1.3.0 股债金汇观察版

日期：2026-11-06。开发里程碑，正式发布状态以 GitHub Release/Actions 为准。

## 为谁解决什么问题

为希望在 Mac 上做跨资产观察的个人研究者提供低门槛入口；资管业务人员可用于研究流程评估，不是机构授权行情、生产交易、正式估值或风控依据。原固收、信用、宏观、研究项目和周期复盘继续保留。

## 从哪里开始

市场/投研导航选择“股债金汇观察”，或从今日市场进入。首批是上证指数、沪深300、中证500、创业板指及上金所黄金 Au99.99。页面按需请求报价，最多每5分钟复用/更新一次；隐藏标签页暂停周期读取。这里没有股票全市场扫描、盘口或交易下单。

点选资产，再明确载入日线；展示近22/60/250条观测，近1/3/12个月只是大致范围。指数可按共同日期比较、基期100；不填充缺失日、不把指数价格变化称为总回报，不与盘中报价拼接算收益。黄金现货不是金店、期货或ETF价格，不能互相充当备用。来源不提供时点时，不以抓取时间补作观测时间；延时未知就是未知。

## 自选、研究与底稿

报价卡可加入统一自选。自选页只读取已经载入的报价缓存，不在后台自动请求；打开资产页后可重新核验。

“保存查询引用到项目”采用预览、选择已有项目、再次确认的流程；只保存规范资产标识、来源链接和自己的备注，不保存行情数值、观测日期或历史数组。查询引用不是价格证据或冻结历史版本，重新查询可能变化。同一请求可去重重试；刷新后结果不明，先检查原项目。

“整理跨资产观察底稿”用于记录自己的观察、分歧和下一步。通过上方入口回到原资金、曲线、国债期货和外汇模块核验。新行情不写入旧日报归档。真实模式下载为查询引用与人工备注；不会悄悄输出新行情数值。原固收简报沿用原出口与数据规则。不要在人工备注中粘贴受限数据、密钥或非公开研究。

## 开源免费不等于数据授权

继续使用 AKShare 1.20.22 的公开接口，不引入强制付费源或Key。黄金来自上金所公开页面，指数来自新浪，非交易所授权直连。新增数值仅在进程内临时复用，HTTP no-store，不进入SQLite、研究证据或AI。查询引用在模型验证、保存和导入时按白名单规范；未确认的数值导出/AI能力默认关闭。

使用依据：[AKShare用途说明](https://akshare.akfamily.xyz/introduction.html)、[黄金文档](https://akshare.akfamily.xyz/data/spot/spot.html)、[指数文档](https://akshare.akfamily.xyz/data/index/index.html)。访问、缓存、导出及机构用途仍需逐源核验；这些技术限制不是授权证明。

## 安装升级

先备份并正常停止旧服务，完整解压对应版本正式包，再运行 start-macos.command。Python 3.11–3.13，普通用户无需Node；仍适合Apple Silicon MacBook Air。schema保持1600，新增自选类型使用已有文本列，不自动迁移用户目录。旧软件不保证认识新资产类型，不建议拿新增类型后的库直接降级运行；应使用升级前备份。

FRED保存/导出/AI边界不放宽。详见[数据规则](../DATA_USAGE.md)及[本版review](./AKDesk-Fixed-v1.3.0-开发与Review记录.md)。
