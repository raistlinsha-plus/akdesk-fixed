# AKDesk Fixed v0.6.0.1「可信校准版」

## 版本结论

v0.6.0.1 是 v0.6.0 的发布闸门版本，不扩展 World Bank 或信用观察。它集中修复数据口径、FRED 使用边界、研究证据、凭据安全、运行状态和 macOS 启动问题。

## FRED 数据边界

截至 2026-07-14，[FRED 当前完整条款](https://fred.stlouisfed.org/legal/terms/)允许个人非商业用途下载或打印副本，但一般禁止条款及 API 专属条款均明确限制通过 API 存储、缓存、归档或写入数据库。条款没有把该限制限定为“向第三方分发”。

因此本版本采用以下边界：

1. FRED 观测值仅在当前 HTTP 请求中处理，不写入 SQLite，不做后台预抓取；
2. 用户主动 CSV 导出属于显式下载，文件包含来源、vintage、变换和非背书声明；
3. 研究项目只保存序列、来源、时间范围和变换引用，不保存观测值；
4. 旧版 FRED 缓存会自动删除，旧冻结证据会自动去除数值并迁移为引用证据；
5. 如未来取得 FRED 书面许可，或改接并确认 Treasury、BLS、BEA 等原始来源许可，可单独设计本地历史仓库。

## 数据可信修复

- 所有变换保留原观察日期，缺失值继续以 `null` 表示；
- 单期变化跨缺失边界时保持为空，不跨空值计算；
- 同比由 FRED 官方 `units=pc1` 计算；
- 多序列时间轴保留每个序列的缺失位置；
- 图表与 CSV 提供 `realtime_start`、`realtime_end`、抓取时间、实际来源机构、原始来源链接和变换来源；
- FRED 发布日历按明确日期窗口分页获取。

## 运行与安全修复

- Key 先验证后保存；错误 Key 自动恢复原凭据；
- Keychain 写入使用标准输入且脱离启动器终端，不进入进程参数；
- FRED 请求增加 401/429/5xx 分类、退避和熔断；
- 健康状态显示真实的线程池网络请求、连接验证状态和无持久缓存；
- 启动器识别 v0.6.0.1，并诊断占用 8765 但无响应的进程；
- 投研首页按 Asia/Shanghai 判断复盘日期。

## 验证结果

- 后端：59 passed；
- 前端：9 passed；
- TypeScript 与 Vite 生产构建通过；
- Python 编译、依赖一致性、macOS 启动脚本语法通过；
- 真实 FRED Key 联调通过 DGS10 原值、官方同比、DGS10/DFII10 双序列、逐点 vintage、实际来源、发布日历和错误 Key 回滚；
- 真实请求后 SQLite 中 FRED 宏观观测值仍为 0。

本版本仍仅供个人研究，不构成投资建议，也不替代用户对具体数据系列原始版权与许可条件的核验。
