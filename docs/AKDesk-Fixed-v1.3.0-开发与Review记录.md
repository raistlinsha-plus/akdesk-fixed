# AKDesk v1.3.0 开发与 Review 记录

日期：2026-11-06；本地里程碑，未以此页宣称公网正式发布。

## 实现

独立按需公开源服务、白名单资产与符号、可终止子进程、18秒上游超时、同源串行/同请求复用、5分钟报价/6小时日线进程内缓存、错误冷却10分钟。无立即重试、轮换源或绕过限流，无新数值磁盘缓存。行情API no-store；健康区和连接目录纳入新源状态。

新增黄金与四指数页面、统一自选、按需日线、共同日期基期比较、无数值查询引用/备注底稿及项目保存。新页按需加载；不启动常驻全市场扫描。schema1600，查询回执沿用原子幂等事务。

## Review 及修复

- 源缺少时点时保留缺失，不以抓取日期补齐。
- 日线过滤未来、非有限值、非正数及同日冲突记录；不补零或填充日期。
- 自选只装饰已缓存报价，不能触发抓取；类型与资产ID一致性在服务端核验。
- 查询引用不接收客户端价格/日期；模型级白名单同时约束通用证据创建及导入。
- 补齐AI边界：证据payload显式禁止AI时，Pydantic记录和摘要均遵守，而非只在前端隐藏。
- 标记复盘、重复确认、归档/删除后重试、FRED隔离等旧回归继续通过。
- 历史切换用代次隔离旧响应；离开页不接受旧历史结果。

## 实测

- Python3.11 / 3.12 / 3.13：各309项后端测试通过；Ruff通过，3.11/3.12 pip check通过。
- 前端39文件、144项通过；ESLint、CSS变量、TypeScript、生产构建通过。
- 真实公开源单轮、低频探测：4个指数和1个黄金报价返回；上证与Au99.99日线各规范为800条。两类报价均未提供可验证观测时点，按limited/延时未知处理。这不是稳定性SLA或授权证明，不归档本轮数值。
- 浏览器自动验收连接连续超时，未取得本轮原生视觉/交互通过结论；自动组件测试不替代浏览器实测。将在最终候选版再次尝试。

## 剩余边界

不提供国际黄金、个股、ETF、全资产收益排名或自动因果判断。原固收/外汇模块以入口连接，未把新行情存入旧日报。基期图只比较同类资产和共同日期；价格变化不是含费用/分红的组合绩效。来源条款尚未授予机构使用和数值再分发，因此仅查询引用可持久化/导出。主JS chunk仍有原有体积提示，后续候选版继续评估拆包。
