# AKDesk Fixed v1.3.1 产品介绍

更新：2026-11-07。面向评估产品的业务人员，也帮助不熟悉 FICC 的科技同事理解项目成果。

## 一句话介绍

AKDesk 是运行在本机的固收与宏观研究工作台：先看市场变化，再核验数据出处，把自己的判断、证据和待验证任务组织成持续可复盘的研究。v1.3 加入黄金、四个指数和四个按需 ETF 示例，降低第一次理解产品的门槛，但不转型为股票交易终端。

代码 MIT 开源；免费访问接口不等于获得行情授权。它不能替代 Wind、Qeubee 或 DM 的授权行情、机构数据完整性、交易流程与服务保障。

## 面向谁、解决什么任务

主要面向固收、宏观、信用研究人员与个人研究者。保险资管业务人员可将它作为公开资料观察、研究方法验证和个人底稿工具；机构内正式使用应先完成数据授权、网络、信息安全和内部制度评估。

科技同事可以从三个问题理解它：今天市场发生了什么；这个判断依据什么；一周后观点为什么改变。金融领域是验证场景，核心工程成果是数据边界、可恢复的本地工作流、明确的人机确认和可重复测试，而不是“AI 自动选资产”。

## 模块、场景与作用

| 模块 | 使用场景 | 作用与金融概念 |
| --- | --- | --- |
| 今日市场、市场变化 | 早间或盘后快速定位变化 | 聚合资金、利率和期货信号；资金利率是短期融资成本，收益率曲线反映不同期限的利率 |
| 资金面、收益率曲线 | 判断短端资金与长端利率是否同步变化 | 查看期限结构和利差；利差是两个可比利率之间的差，不自动等于投资机会 |
| 现券、国债期货、转债、国债发行 | 核验具体产品和供给事件 | 现券是债券本身；期货是标准化合约；转债兼具债性和转股权；发行日历用于观察供给 |
| 股债金汇观察（新增） | 用熟悉的指数和黄金进入跨市场研究 | 四个指数、Au99.99 黄金现货与四个按需 ETF 示例；连接原有资金、曲线、期货、外汇模块，不把它们伪装成同一时点的统一行情 |
| 外汇、美国宏观与利率、主权比较 | 比较汇率、海外利率和中长期经济结构 | 汇率是货币之间的兑换关系；宏观数据多为月/季/年频，与盘中行情不同 |
| 信用观察 R2、事件线索 | 跟踪发行人和需要人工复核的事件 | 组织信用线索、证据和任务；新闻命中不自动等于违约或评级结论 |
| 自选、图表研究、数据发布复盘 | 维护个人观察范围、检验历史变化 | 对照时间、单位与缺失状态；不能用抓取时间替代观测时间 |
| 项目、专题、证据篮、每周复盘 | 持续跟踪一个观点及其反证 | 把人工笔记、合格证据、任务和明确复盘基线连接起来，解释研究变化 |
| 一页简报、每日复盘 | 产出有出处的工作底稿 | 支持备注、下载、复制与打印；新跨资产数值不自动写入旧日报或数值导出 |
| 可选 AI 助手与页面总结 | 整理允许处理的上下文、提出待核验问题 | 用户自备 API；明确发送边界，不默认发送整个研究库。FRED 与新增公开行情数值不进入 AI |
| 数据健康、使用与反馈、备份 | 来源失败、安装异常或升级前检查 | 展示真实/缓存/缺失/演示等状态；主动预览脱敏诊断，备份与恢复本地研究 |

## v1.3.0 → v1.3.1 的变化

v1.3.0 建立小范围黄金、指数观察与查询引用工作流。v1.3.1 增加黄金 ETF 518880、沪深300 ETF 510300、红利 ETF 510880、5年国债 ETF 511010 四个观察示例，不是排名或推荐；每次只读取点选 ETF 的日线，不扫描全市场。

日线可按需加载，支持 1/5/20 个观测期价格变化及共同日期基期100比较。不复权价格变化不是含分红、费用的总回报；本版不提供净值折溢价、跟踪误差、成分股、估值或个股行情。北京时间16:30前不采用当日 ETF 日线，这是产品的保守规则，不是对上游数据已最终定稿的保证。

## 行情和技术说明

| 来源 | 当前用途 | 关键限制 |
| --- | --- | --- |
| Python AKShare | 中国固收、外汇及新增指数/黄金/ETF访问层 | 开源的是访问工具，不是所有源数据；新增指数接新浪、黄金接上金所页面、ETF日线接东方财富 |
| FRED API | 美国宏观和利率 | 自备 Key；按请求展示，研究保存查询引用，不做数值导出或 AI 处理 |
| World Bank API v2 | 跨经济体结构指标 | 无 Key；标注来源与变换，许可存在指标/数据集例外 |
| GDELT DOC 2.0 | 外部事件元数据与检索线索 | 不抓取新闻正文，不替代人工信用判断 |

新增行情数值只留在服务进程内存，接口标记 no-store；保存研究和导出时只保留资产查询引用与用户自己的备注。系统不能识别用户手工粘贴的每一个受限数值，仍需自行检查文字内容。演示使用固定 2026-08-03 合成资料，可导出合成样例，不应当作真实行情。

前端为 React、TypeScript、Vite，后端为 Python、FastAPI，本地研究持久化使用 SQLite，macOS 凭据使用 Keychain。普通用户使用预构建界面，不必安装 Node.js 或 Docker；主要适配 Apple Silicon MacBook Air，支持 Python 3.11–3.13。新增上游工作进程有超时、并发限制、内存缓存和限流冷却，没有增加常驻行情云服务。

## 如何判断是否值得使用

先打开[在线合成体验](https://raistlinsha-plus.github.io/akdesk-fixed/#/cross-assets)，选择一个熟悉的产品、加载日线、写一句自己的观察并导出底稿。若这个过程有价值，再安装本地版，尝试将查询引用关联已有研究项目。

产品目标是减少公开资料整理和研究搬运，不是提供交易指令、估值认证、会计核算或监管报送依据。操作见[用户手册](./AKDesk-Fixed-v1.3.1-用户手册.md)，边界见[数据规则](../DATA_USAGE.md)。
