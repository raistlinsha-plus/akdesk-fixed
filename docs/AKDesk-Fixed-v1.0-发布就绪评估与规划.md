# AKDesk Fixed v1.0 发布就绪评估与规划

> 评估日期：2026-07-28  
> 当前基线：v0.18.0「低门槛交付版」  
> 建议：下一步进入 `v1.0.0-rc.1`，完成发布工程后再封板 `v1.0.0`

> 2026-07-31 更新：rc.1 发布工程、Python 3.11–3.13 兼容矩阵、历史迁移、全新安装、300 秒稳态、关键页面和正式发布包门禁均已通过，v1.0.0 已封版。最终结果见 [v1.0.0 正式版说明](./AKDesk-Fixed-v1.0.0-正式版.md)。

## 结论

可以把下一阶段定义为 v1.0。

这里的 v1.0 应承诺的是“一款可信、可安装、可恢复、可长期运行的个人本地宏观固收行情与投研工作台”，不是机构交易终端、正式估值系统、多人协作平台或全品类实时行情软件。

当前功能面已经足够。继续用 0.19、0.20 增加数据源和页面，反而会延后真正的 1.0：用户对 1.0 的核心预期是安装可重复、数据不丢、故障可解释、升级可恢复，而不是再多一个模块。

## v1.0 产品边界

### 正式承诺

- 在 Apple Silicon MacBook Air 上以本地单用户方式运行；
- 覆盖中国固收市场观察、外汇参考、宏观与主权数据、研究项目、专题、信用观察和周期复盘；
- 对实时、缓存、过期、降级、演示和不可研究状态做清楚区分；
- 用户研究资产保存在本地，可备份、校验、恢复和跨版本迁移；
- FRED 与 AIHubMix 使用用户自己的 Key，凭据保存在 macOS Keychain；
- AI 默认关闭、按场景授权、调用前可见发送边界，不自动改写研究结论；
- 外部数据源失败时保留可解释的缓存或空状态，不把失败伪装成实时成功。

### 不承诺

- 交易下单、交易级实时行情或交易执行价格；
- 正式估值、信用评级、违约概率、会计入账或风险限额；
- 多人协作、组织权限、云同步或机构级审计；
- 任何自动投资建议或收益保证；
- 对第三方公开接口的持续可用性承诺。

## 版本拆分

### v1.0.0-rc.1「发布工程版」

目标：把当前能运行的开发目录变成可重复交付的产品候选包。

必须完成：

1. 增加精确的 Python 生产依赖锁定文件，保留源 requirements 作为可读约束；
2. 增加一键发布脚本，只打包后端源码、生产前端、启动器、许可证和用户文档；
3. 发布包必须排除 `.venv`、`node_modules`、npm 缓存、测试缓存、用户数据库、市场缓存、历史备份和本机密钥；
4. 增加发布包自检：版本一致、前端存在、脚本可执行、无凭据、无用户数据、Markdown 链接有效；
5. 增加 `THIRD_PARTY_NOTICES.md` 和机器可读依赖清单 / SBOM；
6. 把 schema 701 / 800 / 900 / 1100 / 1201 / 1301 → 1600 的迁移矩阵与备份恢复纳入自动门禁；
7. 在全新 macOS 用户账户完成首次启动、重复启动、停止、升级和卸载数据保留验证；
8. 消除 Starlette `TestClient` 的上游弃用警告，保持测试输出无未解释 warning。

建议验收：

- 压缩后的源码交付包不包含开发依赖和用户数据，体积目标不超过 25 MB；
- Python 3.11、3.12、3.13 至少各完成一次干净虚拟环境安装；
- 首次启动失败能够给出可执行的中文恢复指引；
- 同一端口已有旧版或无响应进程时，不会覆盖或误开其他服务。

### v1.0.0-rc.2「长稳与故障演练版」

目标：证明产品不仅能启动，也能在真实上游波动下长期保持可解释和可恢复。

必须完成：

1. 8 小时交互长稳和 24 小时后台长稳，记录 RSS、线程、文件句柄、缓存增长与备份结果；
2. 对 AKShare、FRED、World Bank、GDELT 和 AIHubMix 分别演练 DNS 失败、连接超时、429、401 / Key 无效、空结果和格式变化；
3. 验证实时 → 有效缓存 → 过期缓存 → 演示 / 空状态的降级顺序及研究门禁；
4. 执行一次真实备份、破坏副本、拒绝错误恢复、成功恢复和恢复后全量回归；
5. 验证 AI 助手超时、预算耗尽、重启后待验证、页面洞察缓存和清除；
6. 完成键盘全流程、VoiceOver 冒烟、200% 缩放和 1280×800 / 1440×900 两档视觉回归；
7. 冻结候选版后只允许修复阻断和高优先级问题，不再加入新功能。

### v1.0.0「个人本地正式版」

目标：把通过两轮候选版门禁的同一份代码封板，不再改变产品范围。

正式版发布条件：

- rc.1 与 rc.2 所有硬门禁通过；
- 0 个已知 P0 / P1，P2 必须有明确处理或接受理由；
- 全新 Mac 安装与历史升级各至少成功一次；
- 发布包、校验值、版本说明、用户手册、产品介绍、许可证和第三方声明齐全；
- 数据库备份恢复演练通过；
- 24 小时长稳无资源持续增长或后台任务失控；
- 外部数据和 AI 的失败均能在界面中被解释和恢复。

如果面向非技术用户公开分发，还应增加签名和公证的 macOS `.app`。如果 v1.0 只在本人或熟悉 Python 的少量用户之间使用，现有双击启动器可以作为 rc 阶段交付方式，但不应宣称完全免安装。

## 暂缓到 v1.1 以后

以下内容有价值，但不应进入 v1.0 封板范围：

- 新增 Alpha Vantage、TradingEconomics 或更多新闻数据源；
- 增加更多模型供应商、Agent 或自动研究编排；
- 多用户、云同步、协作评论与权限；
- 新的资产类别和交易功能；
- 大规模视觉重构；
- 复杂的插件市场或脚本扩展。

v1.0 只允许为完成安装、可信、恢复、长稳、可访问性和合规门禁而修改现有功能。
