# AKDesk Fixed v0.8.0「主权比较版」

> 适用版本：v0.8.0  
> 发布定位：在中国固收与美国宏观之外，增加可追溯的跨国主权基本面比较

## 1. 版本目标

v0.8.0 新增 World Bank 主权比较能力，把低频跨国数据纳入既有“发现问题—形成比较—保存证据—持续复盘”的投研闭环。

本版不尝试生成主权评级、违约概率或投资结论，而是提供一套口径透明、年份严格对齐、缺失值可见的基础比较工具。

## 2. 全球主权比较

入口位于左侧“全球宏观”分组下的“全球主权比较”。

首期支持 10 个经济体：

- 中国、美国、日本、德国；
- 英国、法国、印度、巴西；
- 南非、印度尼西亚。

单次可选择 2–8 个经济体，并设置 1960 年至当前年份之间、最长 51 年的比较区间。

## 3. 精选指标

| 主题 | 指标 |
| --- | --- |
| 增长与通胀 | GDP 实际增速、居民消费价格通胀 |
| 财政与债务 | 中央政府债务占 GDP、财政净借贷占 GDP |
| 外部平衡 | 经常账户余额占 GDP、外汇储备可覆盖进口月数、外债存量占 GNI |
| 收入与结构 | 人均 GNI、工业增加值占 GDP、人口增速 |

页面同时展示 WDI 指标代码、官方英文名称、单位、口径说明、数据更新时间和原始机构，避免只看中文简称而误解定义。

## 4. 比较方式

支持四种显示方式：

1. 水平值：显示 World Bank 返回的原始年度值。
2. 单年变化：当前年度水平值减去上一年度水平值。
3. 横截面数值排名：在同一年度、当前已选经济体内按数值由高到低排列。
4. 横截面 Z-Score：在同一年度、当前已选经济体内标准化，用于识别相对位置。

排名仅表示指标数值顺序。例如债务占 GDP 排名更高不代表质量更好，人口增速更高也不直接代表资产回报更高。

## 5. 对齐与缺失规则

- 所有经济体严格按同一自然年度对齐；
- 缺失值保留为空，不向前填充、不向后填充；
- 不使用某国较新的年份与另一国较旧的年份进行伪横截面对比；
- “最新共同年份”要求所有已选经济体在该年都有数据；
- “最新可用年份”要求至少两个已选经济体在该年有数据；
- 页面展示整体覆盖率和各经济体覆盖点数。

## 6. 缓存与离线使用

World Bank WDI 数据与 FRED 的存储边界不同：

- World Bank WDI 按 CC BY 4.0 提供，应用会把用户请求成功的国家、指标和年份结果写入本地 SQLite；
- 缓存 7 天内直接复用，降低重复请求并改善 MacBook Air 上的响应速度；
- 缺失结果也会记录为空值占位，使系统能够判断一次请求是否完整覆盖指定区间；
- 刷新失败但本地有历史结果时，页面明确标记“过期缓存”并降低可信度；
- FRED 观测值仍只在当前请求中处理，不写入 SQLite。

## 7. 研究工作流

主权比较页支持：

- 一键创建“主权基本面比较”研究项目；
- 把当前比较保存到指定研究项目；
- 保存原始值、显示值、国家元数据、年份、覆盖率、指标口径、来源、抓取时间、许可和署名；
- 在研究项目中查看已保存的主权比较证据；
- 导出带 UTF-8 BOM 的 CSV，文件尾部保留指标、来源、许可、署名与使用说明。

过期缓存不能保存为新的正式研究证据，需先完成官方刷新。

## 8. 数据健康

World Bank 作为独立数据源出现在“数据健康”页，具有：

- 最近成功时间、观察年份、缓存点数和缓存年龄；
- HTTP/2 连接，并采用直连优先、系统代理回退，以规避部分 macOS 代理工具对 World Bank TLS 连接的重置；
- 官方连接重试；
- 网络错误与服务端错误重试；
- 连续三次失败后的短期熔断；
- 独立缓存统计和清理。

清空缓存会删除 World Bank 国家、指标和观测缓存，但不会删除已经保存到研究项目的主权比较证据。

## 9. 数据来源与许可

数据源为 World Bank Indicators API v2，精选指标来自 World Development Indicators。

- API 不要求 API Key；
- WDI 当前许可为 Creative Commons Attribution 4.0；
- 应用使用署名：`World Bank, World Development Indicators`；
- 指标页面、CSV 和研究证据均保留来源与许可信息。

数据可能被原始机构修订，且不同指标的发布时间和覆盖范围不同。使用者应结合指标口径、更新时间和缺失情况进行判断。

## 10. 升级与兼容

SQLite schema 从 `701` 升级到 `800`，新增：

- `world_bank_countries`
- `world_bank_indicators`
- `world_bank_observations`

首次启动自动执行幂等迁移，不删除既有研究项目、证据、自选、提醒、发布复盘、信用观察、日报或中国市场历史。

## 11. 本版边界

v0.8.0 暂不包含：

- 任意国家与任意 WDI 指标的开放搜索；
- 多指标综合主权评分；
- 主权评级、违约概率或买卖建议；
- World Bank 季度/月度数据库的统一频率转换；
- IMF、OECD、BIS 等其他国际数据源；
- 自动生成国家研究报告。

后续版本可在当前可信比较和证据模型上，逐步增加主权观察清单、多指标看板、事件注释和跨源研究。
