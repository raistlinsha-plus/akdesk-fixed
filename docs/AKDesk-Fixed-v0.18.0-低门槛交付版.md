# AKDesk Fixed v0.18.0「低门槛交付版」

## 目标

让新用户先选择任务，而不是先理解产品架构。

## 四类入口

| 使用场景 | 默认落地页 | 适合 |
| --- | --- | --- |
| 每日看市场 | 市场变化中心 | 盘前、盘中、收盘后快速核验 |
| 利率与宏观研究 | 研究首页 | 专题、项目、宏观与复盘 |
| 信用观察 | 信用观察 R2 | 单券、主体、组合与复核 |
| 全球跨市场 | 外汇市场 | 外汇、FRED、World Bank 与发布复盘 |

场景只改变默认落地页和导航优先级。所有入口共享同一套数据、自选、提醒、项目、专题和本地数据库。

## 封板结果

- 后端 142 项、前端 70 项测试通过；
- SQLite schema 1600，正式库 `quick_check` 正常、外键零异常；
- Ruff、ESLint、TypeScript、生产构建、Python 依赖和 npm 生产依赖审计通过；
- 1440×900 核心流程视觉审查完成。

2026-07-28 的最终发布就绪复核进一步确认：

- 15 份现有 SQLite 备份全部有效；
- schema 701、800、900、1100、1201、1301 的真实历史备份副本均可迁移到 1600；
- 市场、研究、AI、数据健康和四类入口没有发现新的阻断性功能缺陷；
- 下一步可以进入 `v1.0.0-rc.1`，但应先完成依赖锁定、干净发布包、全新 Mac 安装、长稳与故障演练，而不是直接把当前构建改名为正式版。
