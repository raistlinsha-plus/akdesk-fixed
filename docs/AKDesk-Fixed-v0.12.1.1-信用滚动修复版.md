# AKDesk Fixed v0.12.1.1「信用滚动修复版」

> 版本：v0.12.1.1  
> 目标：修复信用观察 R2 的长列表滚动、筛选定位与大规模交互问题  
> SQLite schema：1201（无迁移）

## 版本定位

v0.12.1.1 是信用观察 R2 的可信交互收口版本，不新增信用数据源、评级模型或投资结论。它针对 v0.12.1 整体评审发现的滚动错位、粘性偏移、完整长列表渲染和组合成员操作问题进行修复，使 500 只单券的本地观察库在 MacBook Air 上仍保持可定位、可筛选和可键盘操作。

## 核心修复

### 1. 页签与筛选后的滚动复位

在单券长列表深处执行以下操作时，主内容会在 React 完成渲染后重新定位：

- 切换单券、发行人或自定义组合；
- 输入或清空信用搜索；
- 改变观察状态筛选。

定位以粘性工具栏的真实底边为基准，当前面板会出现在工具栏下方 12 px，不再因为内容高度突然缩短而被浏览器压到页面底部。

### 2. 粘性工具栏校准

信用工具栏现在以 `.content` 主滚动容器为坐标系，`top` 从重复计算顶部栏的 50 px 调整为 0。深滚动时工具栏位于主内容顶部内边距处，不再留下内容穿过的空档。

主内容、侧栏导航和组合成员选择区增加稳定滚动槽与细滚动条样式，帮助用户识别当前滚动归属。

### 3. 单券分段显示

单券观察采用前端分段显示：

- 首次显示 20 只；
- 每次“再显示”20 只；
- 搜索、状态筛选或切换页签后恢复到首批 20 只；
- 显示“已显示 / 当前匹配”数量和剩余数量。

该调整不改变后端数据、导入上限、导出完整性或筛选口径。当前观察与多期历史导出仍覆盖完整本地数据。

### 4. 自定义组合成员工具

组合编辑器新增：

- 按债券代码、名称或主体筛选成员；
- “仅看已选”开关；
- 已选数、当前匹配数和总数提示；
- 位于表单底部的粘性保存操作区。

成员勾选状态不会因搜索而丢失；“仅看已选”适合在大组合中复核已加入的债券。

### 5. 页签键盘模型

三级页签采用单一可聚焦入口：

- `ArrowLeft` / `ArrowUp`：切到上一页签；
- `ArrowRight` / `ArrowDown`：切到下一页签；
- `Home`：切到单券；
- `End`：切到自定义组合。

切换后焦点、`aria-selected` 和 `tabIndex` 同步更新。

## 数据与兼容边界

- 本版本没有数据库迁移，也不会重写信用历史、组合、信号确认或研究项目；
- 单券分段只影响页面渲染，搜索在完整本地观察集上执行；
- 组合成员候选仍来自完整信用观察集；
- 信用观察继续坚持人工核验字段和严格机械利差门禁，不生成内部评级、违约概率、自动舆情分数或投资建议。
