# AKDesk Fixed v1.1.0 产品介绍

文档日期：2026-10-22。版本主题：GitHub 自助体验版。本文介绍已实现功能；在线演示、正式包的发布情况和验收结论由仓库发布记录说明。

AKDesk Fixed 是一款免费、开源、本地优先的固收与宏观研究工作台。v1.1 用一条容易理解的路径介绍产品：**看一组市场变化，回到曲线核验，再带走一份有出处的一页简报。**

本版保留全部 v1.0 功能，重点降低首次理解、安装和反馈的门槛。完整模块说明见 [v1.0 产品介绍](./AKDesk-Fixed-v1.0.0-产品介绍.md)，新操作见 [v1.1 用户手册](./AKDesk-Fixed-v1.1.0-用户手册.md)。

## 谁可以先试用

- 对债券、利率和宏观数据感兴趣，希望用公开数据形成个人研究底稿的用户。
- 已接触 AKShare/Python，想观察如何把数据接口组织成可使用产品的金融开发者。
- 希望评估本地市场观察、证据和复盘流程的业务与科技人员。

保险资管等机构的业务人员可以评估个人研究辅助场景，但产品的机构适用性仍需真实工作流验证。仓库 Star、Clone 或下载量不能说明业务人员已经使用或持续使用。

## 从第一次访问到本地使用

| 阶段 | 用户动作 | 产品提供的帮助 |
| --- | --- | --- |
| 先看价值 | 打开静态演示或示例成品 | 不先安装软件就能理解最终产出 |
| 观察变化 | 查看资金、曲线、期货样例 | 展开计算依据，理解来源、时点和单位 |
| 回到数据 | 对照收益率曲线与前值 | 核验期限利差和 BP 变化 |
| 形成底稿 | 添加临时备注并导出 | 复制/下载 Markdown，或打印/PDF |
| 开始真实使用 | 安装 Mac 本地版 | 启动预检、针对性恢复指引，进入完整工作台 |
| 说明问题 | 预览后自愿分享诊断摘要 | 用版本和错误分类辅助反馈，避免分享私人数据 |

静态演示固定为 **2026-08-03 的手工合成场景**，不代表当日或当前行情。它无需登录或 API Key，不请求行情服务，不保存研究项目。可先查看 [固定样例简报](./media/v1.1.0/示例-固收简报.md)；在线入口与部署状态见 [README](../README.md)。

## v1.1 新增了什么

### 一页固收简报

把资金变动、10Y 国债与期限利差、国债期货、数据缺口、出处和时间放进精简视图。完整每日复盘仍保留活跃现券、发行事件和研究工作流，用户可按任务切换。

简报明确区分示例、真实与混合来源；旧归档若没有逐源元数据，会显示“来源信息不完整”。缺失值保持为空，关键值缺失时不生成方向判断。临时备注可随简报导出，但不会自动写入研究项目或数据库。

### 启动预检与恢复

本地版主要适配 Apple Silicon MacBook Air，要求 macOS 12+、Python 3.11–3.13。启动器检查 Python、发布文件、目录权限、空间和证书位置，对失效环境及依赖安装失败给出下一步。预检是本地检查，不代表行情源已连接成功。

正式 ZIP 包含预构建界面，普通使用无需 Node.js、Docker 或 Rust。GitHub 自动“Source code”包适合源码查看与开发；它与带发布清单、校验值和权限检查的正式 ZIP 不同。

### 使用与反馈

新增页面把“市场变化 → 曲线核验 → 简报”放在同一操作指引中，并提供功能问题、数据异常和使用场景反馈入口。用户可主动生成、预览、复制或下载脱敏诊断摘要，再自行决定是否分享。

摘要只使用白名单环境和适配器字段；不包括 Key、个人绝对路径、原始错误、数据库或研究正文，不读取 Keychain，不自动上传，也不会额外连接数据源。

### 可复现 AKShare 案例

[独立 CLI](../examples/README.md) 默认仅用 Python 标准库和固定合成数据生成 Markdown；可选真实模式复用项目的资金、曲线和期货适配器，顺序隔离请求、限制超时，失败模块保持缺失。它不加载完整应用、研究数据库、FRED 或 AI。开发者可通过 [案例说明](./examples/AKShare-一页固收简报.md) 理解数据到成品的过程。

## 完整工作台仍有哪些能力

| 能力组 | 保留的模块 | 典型作用 |
| --- | --- | --- |
| 市场观察 | 今日市场、市场变化、资金、曲线、现券、国债期货、转债、发行、外汇 | 建立市场背景，定位需要核验的变化 |
| 研究管理 | 统一自选、证据篮、研究项目、专题、跨源时间线、每日/每周复盘 | 保存问题、证据、观点变化和下一步 |
| 信用观察 | 单券、发行人、组合、导入校验、事件与人工确认信号 | 把人工核验数据组织成持续跟踪清单 |
| 全球研究 | FRED、World Bank、GDELT、图表研究室、数据发布复盘 | 扩展宏观、主权结构和外部事件研究 |
| 可选 AI | 用户自带 Key 的问答、页面摘要和研究行动草稿 | 辅助理解上下文与整理待核验任务 |
| 本地保障 | 数据健康、缓存降级、隔离进程、提醒、备份与恢复 | 让数据状态可解释，保留个人研究资产 |

中国市场数据主要通过 AKShare 接入；FRED、World Bank、GDELT 与 AI 仍分别遵循既有凭据、授权、署名和数据边界。只体验中国市场路径无需 FRED 或 AI Key。更多金融概念、模块与使用场景见 [v1.0 产品介绍](./AKDesk-Fixed-v1.0.0-产品介绍.md)。
