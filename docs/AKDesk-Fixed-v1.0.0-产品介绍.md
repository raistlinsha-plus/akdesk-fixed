# AKDesk Fixed v1.0.0 产品介绍

## 1. 这是什么

AKDesk Fixed 是一款运行在个人 Mac 上的宏观固收行情与投研工作台。

它面向保险集团下资管子公司的固收、宏观、信用和组合研究人员，把公开行情、外部宏观数据、研究项目、证据、复盘和用户自带 Key 的 AI 能力组织在同一个本地产品中。

它不是要复制 Wind、Qeubee 或 DM 的全部能力，而是验证一条更轻量的路径：

> 让研究人员从“今天发生了什么”，自然走到“这对我的研究意味着什么、依据是什么、下次如何验证”。

## 2. 典型用户

- 固收投资经理和投资经理助理；
- 宏观与利率研究员；
- 信用研究员；
- 组合管理和投后观察人员；
- 需要验证新投研场景的业务与科技同事。

正式生产交易员、估值核算、风险计量、合规归档和多人协同不是 v1.0 的目标用户场景。

## 3. 两种入口，一套数据

产品保留“市场”和“投研”两个工作入口，并提供四类首次使用场景：

- 每日看市场：从市场变化、资金、曲线、现券、期货和外汇开始；
- 利率与宏观研究：从研究首页、FRED、专题和图表开始；
- 信用观察：直接进入主体、单券、组合、信号和复核日程；
- 全球跨市场：从外汇、美国宏观、World Bank 和图表研究开始。

这些入口只改变默认落地页和导航顺序，不拆分数据库，也不会隐藏其他模块。

## 4. 一次完整使用历程

1. 打开“市场变化”，先看相较上一收盘和上次查看后的变化；
2. 回到资金面、收益率曲线、现券或国债期货核对原始数据；
3. 把常看的标的加入统一自选，设置只对可信实时数据生效的提醒；
4. 从行情、宏观或信用对象创建研究项目；
5. 保存证据、反证、任务、观点变化和下一复盘日；
6. 使用图表研究室进行序列变换和跨市场对比；
7. 通过每日复盘和每周复盘把零散观察沉淀为研究节奏；
8. 在明确授权后，让 AI 对当前可见、经过裁剪的上下文做总结或提出核验任务。

## 5. 功能模块与使用场景

| 模块 | 主要内容 | 典型场景 |
| --- | --- | --- |
| 今日市场 | 资金、曲线、现券、期货、事件和跨市场摘要 | 每天开机后快速建立市场背景 |
| 市场变化 | 上一收盘以来及上次查看后的变化，附来源、时点、质量和可信状态 | 从“全市场浏览”转为“先看变化” |
| 我的自选 | 债券、期货、外汇、宏观等统一清单 | 跟踪自己真正关心的对象 |
| 每日复盘 | 自动汇总当日固收市场与可信状态 | 收盘后形成可回看的日度记录 |
| 资金面 | Shibor、回购和资金松紧观察 | 判断短端流动性环境 |
| 收益率曲线 | 国债收益率期限结构、变化和利差 | 久期、曲线形态和期限利差研究 |
| 现券市场 | 活跃债券价格、收益率和变动 | 找到具体券的市场表现并核验 |
| 国债期货 | TS、TF、T、TL 等合约观察 | 观察利率方向、基差和套保线索 |
| 信用观察 R2 | 单券、主体、组合、字段覆盖、规则信号和日程 | 将人工核验字段组织成可追踪信用观察 |
| 可转债 | 价格、转股价值、溢价率和双低等字段 | 公开数据下的转债筛选和观察 |
| 国债发行 | 待发行与近期发行事件 | 安排一级市场和流动性日历 |
| 外汇市场 | 人民币日频参考价和全球外币对快照 | 观察人民币与全球风险因子 |
| 美国宏观与利率 | FRED 指标目录、观测、vintage 与发布复盘 | 美国通胀、就业、政策和美债研究 |
| 全球主权比较 | World Bank 跨经济体结构数据 | 比较增长、财政、人口和金融结构 |
| 图表研究室 | 多序列、频率转换、差值、同比和标准化 | 建立可复用的跨市场研究图表 |
| 数据发布复盘 | 记录预期、官方值、偏差和市场窗口 | 复盘宏观数据发布如何影响市场 |
| 研究首页 | 项目、任务、数据和市场简报 | 管理个人研究节奏 |
| 专题投研 | 把多个项目和数据组件组织成专题 | 中美利率、人民币利率、信用主题等跨源研究 |
| 研究项目 | 问题、假设、证据、反证、任务、结论和时间线 | 形成可追踪的观点演进 |
| 每周复盘 | 到期项目、活动、反证、任务和下周验证 | 固定每周梳理研究资产 |
| 固收计算器 | 现金流、到期收益率、久期和凸性 | 手工校验债券基本计算 |
| 数据健康 | 连接、缓存、熔断、错误、运行时和实际数据目录 | 判断“数据不可用”是休市、网络还是源异常 |
| AI 助手与页面洞察 | 产品向导、市场观察、研究教练及页面内嵌总结 | 用用户自带 Key 辅助解释、发现缺口和生成待确认任务 |

## 6. 行情与外部数据

### AKShare

AKShare 是中国公开市场数据的主要接入层，覆盖资金、收益率曲线、现券、国债期货、发行事件、可转债和部分外汇数据。

这些数据适合个人研究和场景验证，但不具备机构数据终端的 SLA。AKDesk 会显示来源、观测时间、抓取时间、缓存状态、质量分和可信级别，避免把演示或过期数据伪装成实时行情。

### FRED

FRED 提供美国宏观与利率时间序列。用户使用自己的 API Key，观测值按请求获取，不写入 SQLite。主动导出时会保留来源、变换和 vintage 信息。

### World Bank

World Bank WDI 用于跨经济体结构比较。产品持久缓存所需公开数据，并在页面和导出中保留来源与许可说明。

### GDELT

GDELT 用于发现外部事件线索。AKDesk 只缓存事件元数据，不缓存全文，也不会把媒体报道自动当作已确认事实。

## 7. 涉及的金融产品与概念

- 国债和政策性金融债：观察无风险或准无风险利率曲线；
- 信用债：围绕主体、评级、收益率、基准和利差进行人工核验；
- 国债期货：用于观察利率方向和套保相关线索；
- 可转债：兼具债性与股性，常用转股价值、溢价率和双低指标；
- 货币市场工具：Shibor、回购利率反映短期资金价格；
- 外汇：人民币参考价和主要货币对提供跨市场背景；
- 宏观时间序列：通胀、就业、增长和政策利率用于解释利率环境。

## 8. AI 如何进入实际场景

AI 不是只有一个聊天框。

在 AKDesk 中，AI 可以：

- 在今日市场页面总结变化线索和可信边界；
- 在研究项目中整理当前证据、关键缺口和下一步验证；
- 在信用观察中提示新增信号、缺失字段和人工复核任务；
- 在专题中归纳共同变化、来源分歧和证据缺口；
- 在研究行动助手中生成待用户确认的任务、反证和复盘草稿。

用户必须自行提供 AIHubMix API Key。所有场景默认关闭，发送前展示范围；AI 不直接修改业务数据，建议只有在用户选择并确认后才能写入研究记录。

## 9. 与机构终端的关系

AKDesk 的优势：

- 本地运行、数据和 Key 边界清晰；
- 从行情到项目、证据和复盘的个人闭环更连贯；
- 公开数据和 BYOK 模式成本低，便于快速验证新场景；
- 产品结构、可信状态和 AI 权限可以按业务需要继续演进。

AKDesk 的不足：

- 行情覆盖、稳定性、历史深度和时效性远弱于机构终端；
- 没有交易、估值、组合风险、权限、审计和多人协同体系；
- 公开源字段可能变化，仍需要业务人员核验；
- 本地源码包的安装体验不如签名桌面应用。

在保险资管中，更适合作为：

- 研究员个人辅助工作台；
- 新投研流程和 AI 场景的低成本原型；
- 科技与业务共同讨论需求的可运行样品；
- 不涉及生产交易和正式数据分发的创新试点。

## 10. v1.0 的产品边界

AKDesk Fixed 提供观察、组织、核验和复盘能力，不提供：

- 买卖建议、自动交易或收益承诺；
- 正式估值、会计和监管报表；
- 自动评级、违约概率和内部评级替代；
- 未经许可的数据再分发；
- 对公开源数据准确性和持续可用性的保证。
