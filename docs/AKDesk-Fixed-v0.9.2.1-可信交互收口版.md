# AKDesk Fixed v0.9.2.1「可信交互收口版」

> 发布定位：v0.9.2 的可信度、错误恢复与工程质量收口  
> SQLite schema：900（无迁移）  
> 适用环境：macOS 12+，Apple Silicon MacBook Air 优先

## 1. 版本目标

v0.9.2.1 不增加新的市场或宏观数据源，集中修复完整评审中发现的潜在误导：长时间线和导出范围不透明、零数据图表看起来像加载故障、界面资源失败缺少恢复入口、图表语义和辅助文字可读性不足，以及前端缺少静态质量门和组件回归。

## 2. 时间线完整性

- 专题工作区首屏读取最近 100 条时间线，同时返回完整总数、是否还有更早记录和稳定游标；
- “加载更早记录”使用时间与记录 ID 组成的游标，不因顶部新增记录而重复旧页；
- 文字、类型和项目筛选明确作用于已加载范围，加载完整后显示完整状态；
- 原有 `/research/topics/{id}/timeline` 列表响应保持兼容，需要分页元数据时使用 `paged=true`；
- Markdown 导出读取全部时间线，并在文件头写明“完整历史”记录数。

底层研究记录没有迁移或改写，schema 继续保持 900。

## 3. 空状态与错误恢复

- 本地历史没有日期或全部为空值时，展示“尚未积累可绘制的本地历史”，说明应先获取可信市场数据或刷新组件；
- 所有折线图在没有有效数值时显示明确空状态；
- 应用根节点增加错误边界。图表动态资源或页面渲染失败时，明确说明本地数据未被删除，并提供重新加载入口；
- 组件级数据请求失败仍保留 v0.9.2 的局部重试，不扩大为整页刷新。

## 4. 图表与无障碍

- 侧栏当前页面通过 `aria-current="page"` 暴露给辅助技术；
- 折线图说明包含观察区间、时间点数量、各序列最新值和相对首值方向；
- 图表下方可展开数据摘要表，查看首值、最新值、对应日期和区间变化；
- 提高弱化文字颜色、辅助字号和数据健康元信息的可读性，同时保留紧凑布局。

## 5. 工程质量门

前端新增：

```bash
cd frontend
npm run lint
npm test
npm run build
# 或一次执行
npm run check
```

后端新增：

```bash
cd backend
../.venv/bin/ruff check app tests
../.venv/bin/python -m pytest -q
```

新增回归覆盖错误边界、图表摘要、零值判断、时间线分页合并、稳定游标、分页 API 和 226 条时间线完整导出。

发布验收结果：后端 108 项、前端 42 项测试全部通过；ESLint、Ruff、TypeScript 与生产构建通过，npm 全依赖审计为 0 漏洞，Python 依赖无冲突，27 份 Markdown 无断链，真实主库与行情缓存完整性正常。

## 6. 升级方式

停止旧版服务后双击 `start-macos.command`。启动器会校验 v0.9.2.1。版本不会迁移数据库，不会删除或重写专题、项目、证据、时间线、自选、提醒、World Bank 缓存或 FRED Keychain 凭据。

## 7. 已知边界

- 时间线筛选在浏览器已加载范围内执行；页面会明确显示范围，可继续加载到完整历史；
- 图表摘要是机械计算，不生成投资结论；
- FRED 观测值仍按请求处理、不写入 SQLite；
- 本版不包含报告编辑器、组合持仓、多人协作或交易执行。
