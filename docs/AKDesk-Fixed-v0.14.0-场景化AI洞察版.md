# AKDesk Fixed v0.14.0「场景化 AI 洞察版」

> 发布日期：2026-07-27  
> 适用环境：macOS 12+，Apple Silicon MacBook Air 优先  
> 前置版本：v0.13.1「AI 运行底座版」

## 1. 版本目标

v0.14.0 不再把 AI 只放在对话抽屉里，而是把受控、可复核的短摘要放到用户正在工作的页面中。版本优先覆盖三个高频场景：

- 今日市场：压缩变化线索、可信边界和下一步核验；
- 研究项目：检查当前证据、关键缺口和下一步验证；
- 信用观察：汇总规则信号、数据缺口和人工复核任务。

AI 仍是可选辅助层。不开启页面授权时，所有行情、项目、信用观察和研究流程保持原样。

## 2. 新增能力

### 2.1 三类内嵌洞察卡片

三张卡片沿用现有页面视觉语言，展示授权状态、触发方式、生成状态、最终摘要、模型、生成时间和今日剩余额度。摘要不会修改页面数据或研究结论。

研究项目洞察按项目分别缓存；市场和信用观察各使用一个当前页面缓存。信用洞察系统提示明确禁止生成评级、违约概率和投资结论。

### 2.2 独立授权与触发方式

三个模块默认全部关闭。用户在 AI 助手的“预算与页面洞察”中逐一开启，并选择：

- 仅手动；
- 数据变化后；
- 每日首次打开。

“管理权限”或“设置”会直接打开对应运行设置。自动触发沿用用户已经保存的模块授权，不绕过权限开关。

### 2.3 稳定指纹与待更新状态

后端把裁剪后的页面上下文规范化并计算 SHA-256 指纹。请求构造时间不参与指纹，避免同一页面仅因刷新时刻变化而持续误报过期。

页面数据变化后，已有摘要保留并标为“待更新”；更新完成前继续显示旧摘要，避免生成期间出现空白。

### 2.4 单并发任务队列

页面洞察使用一个本机工作线程，队列最多容纳 10 个任务。同一页面不会重复排队。浏览器会在任务排队或运行期间持续轮询，任务结束后自动停止。

如果上游成功返回了 token 用量但没有可展示的最终回答，实际用量仍会记入当日预算，并安全重试一次；不会展示或缓存模型内部思维过程。

### 2.5 继续追问

生成完成后可点击“继续追问”。应用只把一个固定的场景后续问题带入原有助手，并展示该场景的发送前预览；用户仍需显式确认。追问回答继续保持请求级、不落库。

## 3. 数据与隐私边界

SQLite `ai_insights` 只保存：

- 上下文类型与业务键；
- 上下文指纹；
- 最终摘要；
- 发送范围的短说明；
- provider、模型、生成时间和状态。

不保存：

- AIHubMix API Key；
- 完整提示词；
- 模型思维过程；
- 页面上下文副本；
- 附件正文或新闻正文；
- 对话问题或追问历史。

API Key 仍只保存在 macOS Keychain，或由启动环境变量提供。每日用量表只记录次数和 token 汇总。

## 4. 兼容性与迁移

- 应用版本：`0.14.0`；
- SQLite schema：保持 `1301`；
- 不新增数据库迁移，不重写现有研究数据；
- v0.13.1 的 AI 预算、授权和缓存表直接复用；
- 正式库升级前的安全备份继续位于 `data/backups/before-v0.13.1-20260727.db`。

## 6. 已知边界

- 页面洞察不是事实确认，仍需回到来源与原始数据复核；
- 自动触发只在页面打开且条件满足时排队，不是后台定时任务；
- 单队列优先保证个人 Mac 的可控资源占用，不追求并行吞吐；
- 当前只覆盖今日市场、单个研究项目和信用观察总览；
- 不保存多轮对话历史，不自动写入项目、证据、专题或复盘；
- AIHubMix 上游可用性、计费和模型行为受第三方服务约束。
