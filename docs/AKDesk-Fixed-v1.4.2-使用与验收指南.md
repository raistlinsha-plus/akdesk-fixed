# AKDesk Fixed v1.4.2 · 首次使用收口版

目标：访客先看成品，在线做一份合成周复盘，再在 Mac 上用同一流程做自己的底稿。面向个人市场观察与研究准备，不替代机构数据、正式估值或交易。

## 在线做一份

1. 打开[合成周复盘](https://raistlinsha-plus.github.io/akdesk-fixed/#/cross-asset-week)。不用安装、登录或填 Key。在线站点若暂不可达，可以先查看[合成 Markdown 成品](./examples/AKDesk-v1.4.2-股债金汇周复盘样例.md)。
2. 选择 2026-07-31 或 2026-07-24，点「读取本周」。前者可练习辨认汇率的前期缺项；黄金的有效观测日与其他项不同。未同步的观测不用于计算组合回报。
3. 写一句自己的判断，或写下哪项需要再核验。「下载合成周复盘」与预览里的数值都标注为合成，不代表实际行情。

## 在 Mac 上继续

从 [Releases](https://github.com/raistlinsha-plus/akdesk-fixed/releases/latest) 确认已公开版本，并下载附件中的安装 ZIP 和 `SHA256SUMS`，不是 GitHub 自动生成的 Source code ZIP。在下载目录执行 `shasum -a 256 -c SHA256SUMS`，完整解压后双击 `start-macos.command`。需要 Apple Silicon Mac、兼容的 Python 3.11–3.13；首次安装依赖须联网。不要求 Node.js、FRED Key 或 AI Key。升级先停旧版并备份。

- 无入口偏好的浏览器访问本地首页会直接打开周复盘；原有默认入口和直接链接不改。可用「设置默认入口」恢复到自己习惯的场景。
- 选周并主动点「读取本周」。股、金从既有日线来源按需查询；债、汇只读已有本地历史。冷启动时本地历史可能为空，点「到原模块核验」，补充可用历史后回来只重读那一项。没返回、超时、缺项和没有变化是不同状态。
- 至少一项读取返回后，即使该项也没有有效值，仍可写待核验事项、导出查询引用。真实底稿不附行情值、派生变化或观测日；不把演示数值填入真实结果。备注仍只留在当前标签页的应用内存，重载或关闭会清空。
- 用原窗口的 Control+C 或同安装目录的 `stop-macos.command` 停止。自定义端口时，启停使用同一端口。[完整功能手册](./AKDesk-Fixed-v1.4.1-用户手册.md) · [数据使用边界](../DATA_USAGE.md)
- 首次安装报证书错误时，按解释器提供的证书安装指引修复，不关闭 TLS 校验。报连接中断或软件源缺包时，先检查网络与软件源再重试，不删数据、不自行改锁定版本。分享错误类别即可，不要粘贴原始安装日志。

## 验收清单

- 静态站：概览主按钮与分享链接打开同一合成任务；选周后主动读取、显示缺项、写判断并下载；旧 ETF 和固收简报可达；不连接行情或本地后台。
- 本地：新浏览器直接进入周复盘；旧默认偏好和深链仍有效；不自动请求四条序列。部分读取不会阻断导出，真实结果不会使用合成数据。
- 交付：生产界面及静态站构建通过，ZIP 可校验、解压和启停；分别记录冷安装环境、客户端与真实上游返回，不能用演示结果代替。
- 发布后：用匿名访问核对 GitHub 首屏、Pages、ZIP 和哈希文件。至少再验证一台未安装过 AKDesk 的 Mac 或不同网络；本机不代表外部用户环境。
