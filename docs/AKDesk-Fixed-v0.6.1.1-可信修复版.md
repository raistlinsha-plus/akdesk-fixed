# AKDesk Fixed v0.6.1.1「可信修复版」

## 1. 版本定位

v0.6.1.1 不扩充产品边界，集中修复 v0.6.1 整体评审发现的可信度问题。目标是保证用户看到的市场状态、行情观测时间、数据健康和项目观点轨迹具有一致且可审计的语义。

## 2. 可信时间

- 中国市场状态区分未开盘、交易中、午间休市、已收盘和非交易日；日频源继续显示日频数据。
- 国债期货源提供交易日时使用源交易日；只提供时分秒时，使用交易日历确定最近已经发生的市场时点。
- 明确的未来交易日或未来时间会在进入缓存前被拒绝，写入研究历史前再校验一次。
- 升级时自动清理旧版已经写入的未来日期和 09:30 前误记为当日的期货历史点。清理是幂等的，不影响正常历史、自选、提醒、研究项目或证据。

## 3. 健康与研究可用性

数据源现在有两组互不替代的判断：

1. 连接状态：健康、缓存可用、降级、不可用、未检查；
2. 研究状态：研究可用、受限可用、不可用于研究、待检查。

例如，现券接口即使请求成功，若代码缺失、观测时间不可信或异常记录过多，也不会被计入“研究可用”。演示数据与无真实缓存的不可用数据不显示可信观测时间。熔断源的下一次检查显示恢复探测时间。

## 4. macOS 数据源信任链

隔离行情进程和扩展进程显式继承 certifi 的可信 CA bundle，覆盖 Python 在部分 macOS 安装方式下无法找到系统证书链的问题。实现没有关闭证书验证，也没有允许不安全 HTTPS 请求。FR、FDR 仍保持相互隔离，单源失败不会拖累 Shibor、LPR 或其他行情。

## 5. 研究项目修复

- 项目创建事件显示“初始置信度”和“初始状态”。
- 只有结构完整的项目更新事件才显示前后值，不再出现 `undefined → undefined`。
- 1280 像素级 MacBook Air 视口采用单栏项目详情，减少正文压缩；项目列表限高并可独立滚动。

## 6. 数据兼容

- 不改变 FRED 请求期处理和观测值不落库边界。
- 不删除研究项目、研究证据、自选、提醒或日报。
- 市场历史校准仅处理能够明确判定为未来或盘前误写的国债期货记录。
- `/api/v1/info` 的 `market_history_calibration` 返回本次启动删除的两类记录数，便于核验。

## 7. 验收结果

- 后端自动化测试：68 项通过；
- 前端自动化测试：16 项通过；
- 前端生产构建通过；
- Python 依赖完整性检查通过；
- npm 生产依赖审计通过；
- 正常模式与演示模式均不把演示时间伪装为真实观测时间。

## 8. 后续版本

下一阶段建议进入 v0.6.2「研究生产力版」：重点完善自选行情状态、一键立项、研究模板、时间线式研究日志、反证、项目导入导出与本地备份恢复。信用观察和 World Bank 继续保持独立版本，不与可信修复混合发布。
