# AKDesk Fixed v1.2.0：每日研究工作流版

日期：2026-11-05。本版把“看变化、记研究、再验证”连接起来，不新增行情源、模型或投资判断。此前本地交付的 v1.1.2 合成案例一并纳入本次发布。发布与部署状态以 [Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/tag/v1.2.0)和[验收记录](./AKDesk-Fixed-v1.2.0-发布与验收记录.md)为准。

## 一、从市场变化关联已有研究

在市场变化中先检查来源、观测与抓取时点，再通过“关联研究项目”选择一个已有、未归档项目。打开预览、核对所选信号与个人补充，明确确认后才保存；打开面板或切换项目不会自动写入。

本版只将当前选中的合格市场信号与人工备注写入，不搬运整份市场表或日报。服务器从当前缓存重建对应信号并核验来源资格与抓取时点，不信任客户端传来的数值，也不会在点击保存时自动向源抓取。快捷入口只接受可信、可行动、非演示、观测不早于近7天且来源缓存未过期的信号；“部分可用”不通过此入口。演示、过期、可疑、非可行动、无观测时点的变化不通过此快捷入口保存；需要解释这些异常时，可自行在项目中记录人工核验笔记，不能把它们包装成可信行情证据。7天只是人工复核提示窗口，不是实时性或授权承诺。

保存期间不得切换目标或连点提交。网络中断可在同一预览下重试，同一请求只生成一组记录；更改内容后需要重新预览。若时点或资格已改变，会提示刷新，不自动改用另一份行情。成功后可打开目标项目，继续记录反证、任务和复盘日。

## 二、把简报临时备注主动转成笔记

每日复盘“一页简报”中的人工备注仍默认临时保存，不因打字、复制或打印而进入 SQLite。本版可选择“将人工备注保存为研究笔记”，预览项目和确切的个人文字，再确认保存。

只保存人工填写的备注与报告日期引用，不复制日报数值、来源响应、FRED 内容或整份简报。备注不会被自动清空，保存失败仍可编辑或重试。来源日期不同的备注不可串到另一日的目标；正文请自行核查，系统无法识别全部未标来源的受限粘贴内容。不要把 FRED 响应、密钥或私人文件正文放进此快捷通道。

保存笔记不等于保存市场证据，也不表示软件认可观点或其数据授权。合成案例区继续独立运行，不借此向真实研究库自动创建项目或任务。

## 三、项目复盘：与上次确认相比发生了什么

在研究项目中查看“这次复盘，先看什么变化”面板。首次使用没有历史基线时，明确显示尚未建立基线，不把所有旧内容误称为新增。

面板按规则整理新增或变化的记录、证据、移除情况、待完成任务及证据状态。展开项目中的具体记录核对后，再预览并明确确认“已复盘”。这会保存本地复盘基线，而不是自动修改结论、评级、置信度或任务完成状态。

如果确认期间项目字段、记录、证据或关联对象/专题链接有变化，原预览会失效，需刷新后重新检查，避免把没有看过的变化标为已复盘。关联对象/专题的正文和单纯活动日志不纳入差异比较；只比较链接本身。仅浏览面板不保存基线；基线变化比较不调用 AI 或重新请求 FRED。

### 证据状态的含义

- **FRED 查询引用**：只是重新查询的参数，不是已冻结的官方数据版本；不能据此判断官方数据是否修订，也不自动缓存/获取观测值。
- **快照待复核/过期**：按产品规则提醒重新核验，不是数据源服务失效、投资判断失效或法律许可到期。
- **时点不明**：有保存时间不等于有观测时间，不把未知时点当作新鲜证据。
- **近期快照**：仅指时间规则，仍需核对来源、授权、字段和研究问题；不等于“证据已证实观点”。

结果是研究整理线索，不自动给投资建议。列表若有截断会显示提示，需回到项目完整记录核验，不以摘要代替完整档案。

## 四、每周复盘回到具体项目

在每周复盘的到期项目、待验证任务和下次复盘列表中，可以直接打开对应项目。任务入口使用项目 ID，不误跳到任务 ID。切换报告日期时不继续显示或导出旧日期结果；日期未选择或加载中暂不导出。

推荐节奏：日间看变化并核验 → 选择项目保存必要线索或个人笔记 → 写下反证和下一步 → 每周回到项目检查增量 → 明确确认复盘，并自行更新观点与复盘日。

## 五、安装、升级与数据边界

正常停止旧服务，再完整解压 v1.2.0 正式 ZIP，双击 `start-macos.command`。Python 仍为 3.11–3.13，主要适配 Apple Silicon MacBook Air，普通用户无需 Node.js。停止使用原启动终端的 Control+C 或 `stop-macos.command`；关闭浏览器不等于停止服务。

研究 schema 保持 1600，检查点与重试凭据使用现有本地设置存储，随数据库备份恢复，不保存完整项目正文副本或 FRED 响应。没有强制搬移用户目录，不读取实际凭据或替用户操作个人研究库。升级前按原流程创建备份，恢复后核验项目与实际数据路径。

自有代码 MIT 不转授数据权利，保存入口、质量门或自备 Key 都不证明商业/机构授权。FRED 查询引用、无数值导出和 AI 隔离继续沿用；原规则核验日期 2026-11-02，本版未重新出具法律核查。参见 [数据规则](../DATA_USAGE.md)、[v1.1.1 补充](./AKDesk-Fixed-v1.1.1-升级与使用说明.md)。
