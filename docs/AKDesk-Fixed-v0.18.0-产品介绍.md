# AKDesk Fixed v0.18.0 产品介绍

> 面向个人使用的本地宏观固收行情与投研工作台  
> 适用版本：v0.18.0「低门槛交付版」

## 产品是什么

AKDesk Fixed 把公开市场数据、宏观数据和个人研究资料组织在一套本地工作流中。它既可以作为每日观察市场的第二屏，也可以用于建立研究项目、管理证据、跟踪信用主体和完成周期复盘。

产品默认运行在用户自己的 Mac 上。研究项目、自选、提醒、信用观察和摘要缓存在本地 SQLite；AIHubMix 与 FRED 使用用户自己的 API Key，Key 保存于 macOS Keychain。不同入口共享同一套数据，不需要在“行情软件”和“研究软件”之间迁移资料。

## 适合谁

- 需要观察中国利率、资金、现券、国债期货与外汇的个人研究者；
- 需要把 FRED、World Bank 和外部事件线索纳入研究过程的宏观研究者；
- 需要管理单券、发行人、组合与人工复核信号的信用研究者；
- 希望用轻量本地工具建立“问题—证据—结论—复盘”闭环的学习者。

它不是交易下单、正式估值、信用评级、会计入账或风险限额系统，也不应作为投资决策的唯一依据。

## 四类任务入口

| 入口 | 默认落地页 | 典型任务 |
| --- | --- | --- |
| 每日看市场 | 市场变化 | 先找可信异动，再回到资金、曲线、现券、期货或外汇核验 |
| 利率与宏观研究 | 研究首页 | 建项目、整理专题、比较宏观序列、保存证据并复盘 |
| 信用观察 | 信用观察 R2 | 跟踪主体、单券、组合、事件和待人工确认的信号 |
| 全球跨市场 | 外汇市场 | 观察汇率，并联动 FRED、World Bank、图表研究和发布复盘 |

入口只决定首次落地页和导航顺序。用户仍可随时切换市场 / 投研导航，也可以在“入口设置”中修改默认场景。

## 功能模块与使用场景

### 市场观察

| 模块 | 作用 | 使用场景 |
| --- | --- | --- |
| 市场变化 | 聚合上一收盘以来及上次查看后的可信变化，支持优先级、质量和已读筛选 | 盘前快速浏览、盘中检查、收盘后复核 |
| 今日市场 | 汇总资金、曲线、期货、现券、外汇和事件 | 需要一屏掌握当日状态时 |
| 资金面 | 查看 Shibor、FR、FDR、LPR 等独立数据源 | 判断短端资金松紧，并核对单源异常 |
| 收益率曲线 | 查看国债与政策金融债期限结构、前值和 BP 变化 | 观察曲线平陡、期限利差和关键期限变化 |
| 现券市场 | 收益率、净价、成交量、筛选、保存视图与 CSV 导出 | 查券、比较成交与形成候选清单 |
| 国债期货 | 查看 TS、TF、T、TL 近季合约 | 配合现券和曲线观察方向与期限表现 |
| 外汇市场 | 查看人民币日频参考价及全球外币对询价 | 分析人民币、美元和跨市场风险线索 |
| 可转债与发行 | 转债筛选、备用源降级标识、国债发行日历 | 补充固收+观察与发行事件检查 |

### 研究工作流

| 模块 | 作用 | 使用场景 |
| --- | --- | --- |
| 研究首页 | 汇总进行中项目、待复盘、宏观准备度和自选 | 开始一天研究或回到未完成任务 |
| 研究项目 | 管理问题、假设、结论、置信度、证据、反证、任务和复盘 | 对一个判断形成可追溯记录 |
| 研究行动助手 | 根据项目缺口生成任务、反证和复盘草稿 | 不确定下一步该补什么时；勾选并二次确认后才写入 |
| 专题投研 | 组织跨源组件、时间线、证据篮和项目摘要 | 长期跟踪一个主题、主体或宏观问题 |
| 图表研究室 | 最多比较 6 条 FRED 序列并进行变换 | 做利率、通胀、就业和增长的跨序列分析 |
| 全球主权比较 | 比较 World Bank 指标、共同年份、排名与 Z-Score | 进行跨经济体结构研究 |
| 数据发布复盘 | 保存发布前预期并核对实际值与本地市场窗口 | 复盘重要宏观数据发布 |
| 每日 / 每周复盘 | 汇总市场、项目更新、反证、任务和下周待验证 | 固化日常观察和周期研究节奏 |

### 信用观察 R2

信用观察支持 CSV / Excel 映射导入、多期单券历史、发行人主档、自定义组合、事件日历和人工确认信号。利差只在评级日期、收益率日期、基准日期和期限匹配都满足门禁时机械试算。

适用场景包括：

- 跟踪一组债券在多个观察日的字段变化；
- 从发行人主档进入事件专题或创建研究项目；
- 按组合查看风险线索和到期复核事项；
- 为信号补充核验备注，并沉淀到研究复盘。

系统不会自动生成评级、违约概率或买卖建议。

### 自选、提醒与数据健康

- 统一自选可管理证券、外汇与宏观指标的分组、标签、备注、状态和复盘日期；
- 提醒支持阈值、静默时段、每日上限、触发历史和 macOS 本地通知；
- 只有健康、未过期的真实数据能触发提醒，演示或过期数据不会触发；
- 数据健康中心同时展示连接状态和研究可用性，可查看缓存年龄、连续失败、熔断和单源重试；
- 市场休市不等于数据不可用，系统会区分未开盘、午间休市、已收盘、非交易日和日频数据。

## AI 能力与可信边界

AI 不是单一聊天入口。v0.18.0 提供两类使用方式：

1. 顶部 AI 助手：产品向导、市场观察和研究教练；
2. 页面 AI 洞察：今日市场、研究项目、信用观察和专题综述中的场景化摘要。

页面洞察默认全部关闭。用户需要逐模块授权，并选择“仅手动、数据变化后、每日首次打开”之一。系统会在发送前说明裁剪范围，只提交完成当前任务所需的摘要，不发送数据库、完整行情表、附件或新闻正文。

专题综述只使用标题级摘要与来源 / 时点元数据；研究行动助手先生成本地草稿，只有用户勾选并二次确认后才会写入项目，且支持撤销。AI 摘要不会自动改变业务数据。

## 数据来源与本地存储

| 数据源 | 用途 | 凭据与缓存 |
| --- | --- | --- |
| AKShare / AKTools | 中国固收、期货、转债、外汇与发行数据访问 | 无用户 Key；真实快照有本地缓存和健康门禁 |
| FRED | 美国宏观、利率、图表和发布复盘 | 用户 Key 存于 Keychain；观测值不写 SQLite |
| World Bank | 全球主权结构比较 | 无 Key；观测缓存 7 天 |
| GDELT | 待核验外部事件线索 | 无 Key；只缓存元数据 12 小时，不保存新闻正文 |
| AIHubMix | 助手与页面摘要 | 用户 Key 存于 Keychain；受预算、授权和裁剪上下文约束 |

核心研究库位于 `data/akdesk-fixed.db`，市场缓存位于 `data/market-cache.db`。系统会对研究库执行启动检查并滚动保留安全备份。

## 运行环境

- macOS 12 或更高版本；
- Python 3.11–3.13；
- 推荐 Apple Silicon MacBook Air；
- 推荐 1440×900 或更大视口；
- 首次安装依赖、获取实时数据及使用外部 API 时需要网络。
