# AKDesk Fixed v1.5.0 · 连续复盘版

这周写下的判断，下周还能找到、核对和继续跟踪。不需要建立项目或连接 AI；复盘记录只保存在当前 Mac 的研究库。

## 第一次：留一句判断

1. 打开「股债金汇周复盘」，选择周结束日。可选「读取本周」核对沪深 300、10 年期国债收益率、Au99.99 和人民币参考中间价。暂时缺数或没读行情，也能保存人工记录。
2. 在「本周判断」写一句自己的观察；可选填「下周待核验事项」。点击「保存到本机」，确认页面显示已保存。未保存编辑仅在当前标签页保留，关闭或重载后可能丢失。
3. 「导出已保存底稿」和保存是两个操作。导出的是最后一次成功保存的版本，不会自动保存正在编辑的文字。

## 下一周：接续，而不是重做

- 「接着上一周复盘」只找周结束日恰好早七天的记录，不把较早的其他周当作上周。自定义周结束日时，下一周继续用同一星期几。
- 为上一周的问题标记「支持、部分支持、不支持、仍待核验」。除「仍待核验」外，须填写人工依据；这些标签不代表系统确认行情准确，也不是投资结论。
- 保存后会引用当时看到的上周修订。上周后来改过时仍显示引用的原修订；选择「改用上一周最新修订」会清空原核验状态，须重新核验。
- 从「周复盘历史」按周浏览或搜索最新保存的人工文字。打开「本周修订」能看旧版本，不会覆盖当前编辑。超过 90 天的旧记录能回看和导出，旧周行情不再主动查询。
- 两个标签页编辑同一周时，旧草稿不会覆盖新修改。重新读取后，可以保留草稿并确认新的基线，或放弃草稿载入已保存记录。请求超时先读取核对；同内容重试不会重复创建修订。
- 删除需明确确认，会从当前研究库移除该周及其全部修订。已保存的其他周若曾引用它，会显示引用已不可用；原来的备用副本和导出文件不会一起删除。

## 练习与安装

- [在线做一次两周合成复盘](https://raistlinsha-plus.github.io/akdesk-fixed/#/week-story) · [60 秒合成导览](https://raistlinsha-plus.github.io/akdesk-fixed/akdesk-continuity-60s.mp4) · [Markdown 成品](./examples/AKDesk-v1.5.0-连续两周复盘样例.md)。本地也可点「练习连续两周」。样例只在当前页面内存中运行，不写入研究库，不连接行情或 AI；本地演示服务也拒绝真实记录写入。
- 从 [GitHub Releases](https://github.com/raistlinsha-plus/akdesk-fixed/releases/latest) 下载版本 ZIP 和 `SHA256SUMS`，在下载目录运行 `shasum -a 256 -c SHA256SUMS`，完整解压后双击 `start-macos.command`。无需 Node.js；首次安装锁定依赖须有 Python 3.11–3.13 和可连接的软件源。停止用同目录 `stop-macos.command` 或原窗口的 Control+C。
- 升级前先停止旧版并生成备份。数据库从 schema 1600 增量迁至 1700，新表保存人工记录与修订，既有项目和自选不变。全库备份包含周复盘；恢复旧备份前另存当前库。需要退回旧版时使用升级前备份，不让两个版本同时访问同一数据目录。

## 数据和产品边界

“股债金汇周复盘”是市场观察与个人判断；“每周研究复盘”仍汇总项目活动，两者不合并。仅保存用户自撰文字、所选区间、时间及修订引用，不把行情值、派生涨跌、来源观测日或 API 响应写入新表或导出。查询引用不是历史行情快照。请勿把受限行情、凭据或私人资料粘贴到公开反馈。详见 [数据使用边界](../DATA_USAGE.md)。

不新增数据源、行情权限、实盘交易、云同步、AI 评分或遥测。自有数据与组合复盘是后续候选，不属于本版。

## 验收项目

| 场景 | 通过条件 |
| --- | --- |
| 连续两周 | 无需行情即可保存；重开能恢复；只接续恰好早七天的已保存记录 |
| 写入冲突 | 不覆盖较新的修订；超时重试不重复写；未保存文字得以保留 |
| 修订、删除 | 原修订可查看；显式删除后原引用显示不可用，不自动指向重建记录 |
| 迁移、备份 | 1600 → 1700 保留旧项目；完整备份恢复可读取两周及原修订，源备份不变 |
| 合成隔离 | 静态两周任务可下载；不请求真实接口，本地演示服务拒绝写入 |
| 导出边界 | 只输出保存版、查询引用及人工内容，排除行情值、派生涨跌和来源观测日 |
| 交付 | 压缩包完整性、启停、Chrome 静态/真实路径、准确标签提交 CI、附件回下载及 Pages |

外部用户复访、另一台机器的默认联网冷装和 Safari 不能用本机测试代替。试用后欢迎在[使用场景讨论](https://github.com/raistlinsha-plus/akdesk-fixed/discussions/16)自愿说明是否完成、卡在哪一步、下一周是否实际回来；不分享真实持仓、研究笔记或 Key。

本机验收：前端 168 项，Python 3.11／3.12／3.13 后端各 355 项通过；生产界面和静态站构建、全量 npm 审计通过。Apple Silicon MacBook Air 从空环境用预先下载的锁定依赖冷装，Chrome 验证两周保存、重开恢复、真实数据按需读取与仅引用导出；演示环境端到端验证拒绝写入，静态两周样例可下载，安装包启停与实例隔离通过。公开构建及发行附件的当前状态以 GitHub Release 为准。
