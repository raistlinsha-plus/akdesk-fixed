# AKDesk Fixed v1.1.0 用户手册

文档日期：2026-10-22。本文说明 v1.1.0「GitHub 自助体验版」已实现的操作；在线站点、正式安装包和验收结果以仓库发布记录为准。

v1.1 保留 v1.0 的全部原有功能。本手册重点介绍新增入口；资金、曲线、现券、信用观察、FRED、研究项目、备份和 AI 的详细操作继续参见 [v1.0 完整用户手册](./AKDesk-Fixed-v1.0.0-用户手册.md)。

## 1. 先选择一种体验方式

| 方式 | 需要准备 | 能做什么 |
| --- | --- | --- |
| 静态在线演示 | 浏览器 | 走完市场变化、曲线核验、一页简报三步，体验固定合成数据 |
| 本地完整应用 | macOS、Python 3.11–3.13、首次安装网络 | 请求公开数据，保存自选、研究项目和复盘，使用原有完整功能 |
| 独立 CLI 案例 | Python 3.11–3.13 | 默认不装依赖生成固定合成简报；可选真实 AKShare 模式 |

从 [项目 README](../README.md) 查找演示和下载入口。若静态演示尚未部署，开发者可在 `frontend/` 执行 `npm ci`、`npm run dev:demo`，打开终端给出的地址。演示站点的发布不影响本地应用的运行。

## 2. 三步静态演示

点击“开始 3 步体验”，或先从“先看简报成品”了解输出。

1. **市场变化**：查看资金、曲线和期货三类变化，可按类别筛选并展开依据。这里展示的是固定样例计算，不是实际异动提醒。
2. **曲线核验**：查看各期限收益率，可切换国债/国开债；国债支持对照样例前值，观察 BP 变化和期限利差。
3. **一页简报**：查看资金、10Y 国债与期限利差、国债期货、待核验事项、出处与时间；可填写临时备注，复制/下载 Markdown，或打印为 PDF。

演示日期固定为 **2026-08-03**，数值和时间均为 AKDesk 内置合成样例，不代表该日或当前真实市场。演示无需登录、FRED Key 或 AI Key，不请求行情服务，也不连接本地研究数据库。“重置体验”会恢复筛选和图表选择并清除临时体验状态。

在线演示中的备注仅在当前简报视图临时使用，离开视图、重置、刷新或关闭页面后可能清空。需要留存时请先导出。可先阅读 [固定样例简报](./media/v1.1.0/示例-固收简报.md)。

## 3. 安装本地完整应用

主要适配 Apple Silicon MacBook Air，要求 macOS 12 或更高版本、Python 3.11/3.12/3.13。首次安装需要访问 Python 软件源，建议保留至少 1 GB 空间。正式包包含预构建界面，普通使用无需 Docker、Rust 或常驻 Node.js。

普通用户优先选择 GitHub Release 中明确标注版本的 `AKDesk-Fixed-v1.1.0.zip` 正式资源，核对对应 SHA-256 后完整解压；若该版本资源尚未发布，请以 Release 页面实际可用版本为准。

GitHub 自动生成的“Source code”压缩包主要用于源码查看和开发，不等于经过发布清单、资源构建与执行权限校验的正式包。源码用户应按 [贡献指南](../CONTRIBUTING.md) 准备环境；缺少 `frontend/dist/index.html` 时需要构建前端。

双击项目中的 `start-macos.command`。系统阻止脚本时，可右键选择“打开”。若执行权限丢失，在项目目录执行：

```bash
chmod +x start-macos.command start-macos-demo.command stop-macos.command
```

启动器会寻找受支持的 Python，执行本地预检，再创建/复用 `.venv` 并安装锁定依赖，随后打开 `http://127.0.0.1:8765`。中国固收市场功能不要求配置 FRED 或 AI Key。

## 4. 看懂预检与恢复提示

预检仅检查本地环境，不通过它测试行情连接，也不会读取 Keychain 或创建研究数据库。

| 提示类别 | 如何处理 |
| --- | --- |
| Python 缺失或版本不符 | 安装 Python 3.11–3.13；使用 Homebrew 时可执行 `brew install python@3.13` |
| 缺少锁定依赖/预构建界面 | 普通用户重新下载并完整解压正式 ZIP；开发者检查构建步骤 |
| 项目或数据目录不可写 | 将项目移到可写文件夹，检查自定义 `AKDESK_DATA_DIR`；不要删除数据库来修复权限 |
| 磁盘空间不足 | 释放空间后重新启动 |
| 未找到默认 TLS 证书位置 | 这是位置检查提示；若后续安装实际报证书错误，按提示运行 Python 的 `Install Certificates.command`，不要关闭证书校验 |
| 现有 `.venv` 失效 | 停止服务，将 `.venv` 重命名为备份名称后再启动重建；无需处理研究数据库 |
| 依赖安装失败 | 按证书、磁盘、权限、包兼容或网络提示处理，再次启动继续安装 |
| 8765 已占用或运行旧版 | 回到对应启动窗口停止旧服务，或使用相应版本的停止脚本后重试 |

高级用户可在项目目录独立执行 `python3 scripts/preflight.py --json`，得到不含个人绝对路径的预检输出。此输出不是行情健康报告。

停止应用时，在原启动终端按 `Control+C`，或双击 `stop-macos.command`。只关闭浏览器不会停止服务。离线体验完整本地界面可用 `start-macos-demo.command`；该方式仍需要本地 Python 和应用依赖，与无需安装的静态演示不同。

## 5. 本地的一页简报与完整复盘

在“每日复盘”中，默认进入“一页简报”，也可切换“完整复盘”。

- 一页简报集中呈现资金面、10Y 国债与三项期限利差、国债期货、待核验事项和逐源时点，适合形成短底稿。
- 完整复盘保留活跃现券、发行事件、数据说明和投研工作流等原有内容。
- 两个视图使用同一份日报数据。日期选择可查看本地历史归档，返回“今天”后查看当前生成结果。
- 一页简报的复制、Markdown 下载和打印会携带当前临时备注。备注不写入 SQLite，不自动成为研究笔记；当前模块内按日报日期暂存，切换视图或查看另一日期后可返回继续编辑，刷新浏览器或离开模块后可能清空。完整复盘的独立导出以复盘内容为准。

浏览器不允许复制时使用“下载 Markdown”。“打印 / PDF”调用浏览器打印界面，可选择保存为 PDF；备注很长或系统字体差异可能使内容分为多页，“一页”表示精简视图，不保证任意内容恰好占一张纸。

## 6. 判断一份简报能否使用

| 标识 | 含义与动作 |
| --- | --- |
| 示例数据 · 非实时 | 内容含演示值，只用于体验，不作为真实行情底稿 |
| 含示例数据 · 不作为真实市场简报 | 真实源与示例源混合，需逐项核验，不把整份当成真实市场记录 |
| 真实数据 · 请核对各来源时点 | 来源为真实请求/缓存；仍要检查是否过期、部分可用，以及观测时间差异 |
| 来源信息不完整 · 待核验 | 常见于旧归档缺少逐源元数据；不推定其为真实或实时数据 |

“观测区间”只是按各来源日期汇总，不代表所有指标同步采集。观测时间表示源数据对应的时间；抓取时间表示应用取得该份数据的时间；简报生成时间不等于行情观测时间。

`—` 表示缺失，不是 `0`。关键资金变动或 10Y 水平/变动缺失时，相关方向显示待核验，不因字段为空推断市场平稳。旧归档不会凭空获得当时未保存的来源信息；需要新的可核验输出时，返回今日简报并核对当前来源。

## 7. 使用与反馈

打开导航中的“使用与反馈”。页面提供三步操作入口，以及功能/界面、行情/连接、场景建议三类 GitHub 反馈入口。打开反馈页面不会自动提交内容。

遇到行情异常，先查看“数据健康”。如需辅助说明，点击“生成诊断摘要”，预览后自行选择复制或下载 Markdown，再决定是否贴到 Issue 中。

摘要只包含应用版本与模式、系统/Python/架构、存储目录类型与可写状态，以及各适配器的连接、研究可用性、可信状态、缓存年龄、连续失败和错误分类。它不包含 API Key、个人绝对路径、原始错误正文、数据库或研究内容，不读取 Keychain，也不会自动上传。摘要按已有状态生成，不会为排障额外验证外部接口。

反馈时补充“做了什么、希望发生什么、实际发生什么”。分享前仍应检查自行附加的文字与截图；请不要上传 Key、数据库、账户或未公开研究材料。

## 8. 无需完整应用的 CLI 案例

在项目根目录执行：

```bash
python3 examples/fixed_income_brief.py --output brief-example.md
```

默认仅用标准库，输出可复现的固定合成简报。CLI 是独立教学样例，固定日期为 2026-07-27，与静态演示的 2026-08-03 样例分别维护。

已经安装项目依赖后可选择真实模式：

```bash
.venv/bin/python examples/fixed_income_brief.py --live --timeout 15 --output brief-live.md
```

真实模式只顺序请求中国资金、国债曲线和期货适配器；每源限制超时，失败继续，演示回退值会被丢弃，不读取研究库或 Keychain。详见 [CLI 说明](../examples/README.md) 与 [AKShare 案例](./examples/AKShare-一页固收简报.md)。
