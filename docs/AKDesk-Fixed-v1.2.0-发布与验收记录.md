# AKDesk Fixed v1.2.0 发布与验收记录

日期：2026-11-04 至 2026-11-05。主题：每日研究工作流版。本页记录实现与测试范围；实际 tag、资源和 CI/Pages 状态以 [GitHub Release](https://github.com/raistlinsha-plus/akdesk-fixed/releases/tag/v1.2.0)为准，不以本地通过代替公网发布。

## 实现范围

选择已有项目关联合格市场变化；主动将简报人工备注转为笔记；显式复盘基线、增量与证据时点分类；每周复盘返回项目并防止日期请求竞态。包含此前本地 v1.1.2 的三条合成案例、反馈、分享、启动器与午夜测试修复。详见[产品与使用指南](./AKDesk-Fixed-v1.2.0-产品与使用指南.md)。

不新增源、模型、默认遥测、跨平台支持或生产交易；schema 1600。FRED 引用/导出/AI 限制不放宽，不修改用户实际库、Keychain 或源备份。

## 验收口径

自动化使用隔离 HOME、临时数据库、测试 Keychain 替身与 mock/合成来源。重点验证确认前不写、重复重试不重复写、内容变化冲突、跨项目/来源/日期竞态、失败保留备注、复盘并发409、未知/过期/FRED引用不误标新鲜、读取不写入、备份与 schema 兼容。真实上游当前可用性和使用授权另行核验。

## 已知限制

- 当前去重针对同一请求标识；主动刷新/离开页面后临时请求状态不保留。若中断时结果不明，先核对原项目，不能把再次新建请求理解成全局语义去重。
- 回执尚无自动清理；删除项目后可能保留孤立的哈希/ID 元数据。基线全量计算随项目记录增长，100 项限制只用于展示，不是海量项目的性能保证。
- 7天是人工复核提示窗口；不证明来源正确、实时、可商用或已获机构授权。当前关联对象/专题链接纳入指纹，关联对象/专题正文与单纯活动日志不作差异比较。
- 生产构建仍提示主 JS chunk 超过 550 kB（约 562 kB，gzip 约 168 kB），属于后续拆包优化项；本轮没有以调高阈值隐藏提示。
- 未对真实行情全源在线可用性、付费 AI 调用、真实用户数据升级、完整冷安装或长期稳定性重新认证。
