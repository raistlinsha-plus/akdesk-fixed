# AKDesk Fixed v0.13.1「AI 运行底座版」

v0.13.1 把 v0.13.0.1 的单次 AI 对话能力扩展为可治理的本地运行底座，为后续页面内 AI 洞察提供预算、授权、状态与缓存边界。

## 本版变化

- 顶部 AI 入口增加全局状态点，可区分未配置、可用、生成中和预算耗尽。
- AI 助手新增“预算与页面洞察”设置：
  - 每日调用上限，默认 20 次；
  - 每日 token 预算，默认 100,000；
  - 今日已用次数、tokens 和任务状态；
  - 今日市场、研究项目、信用观察三个模块的独立开关；
  - 仅手动、数据变化后、每日首次打开三种触发策略。
- 三个页面洞察开关默认全部关闭。只有用户主动开启后，后续页面洞察才可向 AIHubMix 发送裁剪上下文。
- 所有 AI 请求仍保持单并发；达到每日次数或 token 预算后拒绝新请求，并给出可操作提示。
- 连接测试不计入每日预算；成功的问答和页面洞察才计数。
- AI 对话仍是请求级处理，关闭抽屉后不保存；页面洞察缓存采用独立、受限的持久化结构。

## 本地持久化边界

SQLite schema 从 1201 升级到 1301：

- `ai_usage_daily` 只保存每日调用次数与 prompt / completion / total token 汇总；
- `ai_insights` 只允许保存最终摘要、上下文指纹、场景、模型、状态和生成时间；
- 不保存 API Key、完整提示词、模型思维过程、附件正文、新闻正文或发送给模型的上下文副本。

正式数据库升级前已创建并校验：

`data/backups/before-v0.13.1-20260727.db`

## 状态语义

AI 运行底座统一使用以下任务状态：

- `idle`：当前无请求；
- `queued`：已有待处理页面洞察；
- `running`：一个请求正在生成。

页面洞察记录支持“从未生成、生成中、已就绪、已过期、失败”等状态；v0.13.1 完成数据契约和存储边界，页面内洞察卡在 v0.14.0 启用。

## 验证结果

- 后端：134 项测试通过；
- 前端：64 项测试通过；
- Ruff、ESLint、TypeScript 和生产构建通过；
- SQLite schema 1301、迁移记录、备份和完整性检查通过。

## 仍然适用的边界

AI 输出可能出错，不构成投资建议、评级、违约概率或交易指令。页面规则、行情、研究项目和信用门禁不依赖 AI；关闭 AI 或第三方服务不可用时，原有功能继续运行。
