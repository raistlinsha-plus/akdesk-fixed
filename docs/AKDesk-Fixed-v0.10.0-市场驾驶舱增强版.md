# AKDesk Fixed v0.10.0「市场驾驶舱增强版」

> 最终交付版本：包含 v0.9.2.2 与 v0.9.3 的全部改进  
> 适用设备：Apple Silicon MacBook Air，推荐 1440×900 或更高  
> 数据库兼容：SQLite schema 900，无迁移

## 版本目标

v0.10.0 在保留“个人宏观固收投研终端”定位的同时，加强高频市场观察入口。市场模式负责快速回答“今天发生了什么”，投研模式负责回答“这对我的问题和观点意味着什么”；两种入口共享同一套数据、自选、提醒、专题和研究项目。

## 市场驾驶舱

“今日市场”可以按个人习惯显示或隐藏以下模块：

- 收益率曲线：观察国债期限结构和关键期限变化；
- 国债期货：查看 TS、TF、T、TL 等主力合约；
- 活跃现券：观察可追溯的债券代码、收益率和变动；
- 重要事件：查看本地事件与发布日历；
- 跨市场外汇：结合人民币参考价与主要外币对观察外部环境。

提供“全景、利率优先、跨市场”三套预设。模块选择和最近查看仅写入当前浏览器的本地偏好，不写入研究数据库。

## 利率与汇率联动观察

驾驶舱新增四个跨资产观察指标：

- 10Y 国债收益率本地历史分位；
- FDR007 本地历史分位；
- 10Y–1Y 曲线斜率及偏平/倒挂提示；
- T 主力方向和 USD/CNY 变化的并列观察。

历史分位只使用本地可信历史，卡片显示实际交易日样本数；没有有效历史时显示空值，不用演示数据补造分位。该区域可直接进入投研工作台，继续保存市场证据、更新观点或安排复盘。

详细边界见 [v0.9.2.2 说明](./AKDesk-Fixed-v0.9.2.2-可信呈现修复版.md) 与 [v0.9.3 说明](./AKDesk-Fixed-v0.9.3-研究工作流收口版.md)。

## 升级与回退

1. 停止旧版服务；
2. 双击项目根目录的 `start-macos.command`；
3. 启动器校验后端版本为 v0.10.0 并打开 `http://127.0.0.1:8765`；
4. 首次启动会自动检查并生成研究库安全备份。

升级前已生成 `before-v0.10.0-20260717.db` 安全副本。因为 schema 保持 900，必要时可停止服务后使用研究项目页的恢复功能回到该副本。任何恢复操作都会先生成当前库的 `before-restore-*.db` 安全备份。
