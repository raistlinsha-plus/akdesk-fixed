## MacBook Air 快速开始

已针对 Apple Silicon MacBook Air 和 1440×900 视口适配。日常运行不需要 Docker、Rust，也不需要常驻 Node.js；前端静态资源已经预构建。

前置条件：

- macOS 12 或更高版本；
- Python 3.11–3.13；
- 首次安装依赖时需要网络。

推荐从 [GitHub Releases](https://github.com/raistlinsha-plus/akdesk-fixed/releases/latest) 下载 `AKDesk-Fixed-v1.0.0.zip`，校验 SHA-256 后解压。直接下载 GitHub “Source code” 不包含发布清单的可执行权限保证，普通用户优先使用正式发布包。

直接双击 [start-macos.command](./start-macos.command)。第一次启动会创建项目专属的 `.venv` 并安装依赖，之后会自动打开：

```text
http://127.0.0.1:8765
```

关闭启动器所在的终端窗口，或在该窗口按 `Control+C`，即可停止服务。如果找不到原启动窗口，或服务是由其他终端 / Codex 会话启动的，直接双击 [stop-macos.command](./stop-macos.command)；停止器只会在确认 8765 端口运行的是当前 AKDesk 版本后发送正常终止信号。只关闭浏览器页面不会停止服务。应用只监听本机回环地址，不会对局域网或公网开放。

首次打开时可按任务选择“每日看市场、利率与宏观研究、信用观察、全球跨市场”。场景只改变默认落地页和导航优先级，不会拆分数据、专题、自选、提醒、信用观察或研究项目；顶部仍可临时切换市场 / 投研导航，入口设置中可随时修改默认场景。

## AI 助手配置与边界

点击顶部“AI 助手”，输入本人 AIHubMix API Key。应用使用 `deepseek-v4-flash-think`，验证成功后只把 Key 保存到 macOS Keychain；也可通过 `AKDESK_AIHUBMIX_API_KEY` 环境变量提供。Key 不写入 SQLite、日志、前端缓存或导出文件。

每次对话调用前都会显示发送内容类型并要求确认。AKDesk 只发送当前问题和场景所需的裁剪摘要，不发送数据库文件、完整行情表、附件正文或新闻正文。提示词和对话回答只在当前请求与当前打开的抽屉中处理，不自动写入研究项目、专题、证据或复盘。

用户可在“预算与页面洞察”中设置每日次数、token 预算，并分别授权今日市场、研究项目、信用观察和专题综述。所有模块默认关闭；授权后可选择仅手动、数据变化后或每日首次打开。页面卡片只在授权后提交其“发送范围”中列出的裁剪上下文，本机只缓存最终摘要、上下文指纹、模型和生成时间，不缓存完整提示词、思维过程或上下文副本。页面洞察不会修改业务数据，摘要可继续带入不落库的助手追问。

如果 macOS 首次阻止脚本运行，请右键启动器选择“打开”。如果脚本没有执行权限，可在项目目录运行：

```bash
chmod +x start-macos.command start-macos-demo.command
```

如同时使用独立停止器：

```bash
chmod +x stop-macos.command
```

若尚未安装新版 Python，使用 Homebrew：

```bash
brew install python@3.13
```

## 实时模式与演示模式

正常启动时，后端通过 AKShare 拉取公开行情。数据源失败时采用以下策略：

1. 优先显示仍在有效期内的本地缓存；
2. 缓存过期时立即显示最近一次真实数据，并在后台刷新；
3. 实时更新失败时继续保留最近一次真实数据；
4. 从未成功取得真实数据时才切换到内置演示数据；
5. 页面显著标出“降级”“过期”或“演示”，并在“数据健康”展示错误、缓存年龄、连续失败次数和单源重试入口。

系统区分“未开盘、交易中、午间休市、已收盘、非交易日、日频数据”，盘前不会再被误报为已收盘。所有 AKShare 任务最多两路并发，并在独立子进程中执行；单源超时或 native 崩溃不会带走主服务。自 v0.4 起，连续失败的数据源会自动熔断并定时恢复探测，避免异常公开端点被高频重复调用。数据健康中心把连接状态与研究可用性分开，连接成功但质量可疑的数据不会被计为“研究可用”。

只有健康且未过期的真实数据可以触发提醒；演示数据和过期缓存不会触发系统通知。

需要完全离线演示时，双击 [start-macos-demo.command](./start-macos-demo.command)。演示数据仅用于体验界面，不代表真实市场。

## FRED 配置

美国宏观与利率数据使用 FRED 官方 API。首次进入“美国宏观与利率”页面时，输入本人申请的 32 位 FRED API Key；应用先完成真实连接验证，成功后才保存到 macOS Keychain。Key 不会写入 SQLite、日志、前端缓存或研究导出，写入 Keychain 时也不会进入进程命令行参数。开发环境可使用 `AKDESK_FRED_API_KEY` 环境变量。

未配置或未验证 Key 时，精选指标目录、研究项目和中国固收行情仍可正常使用。FRED 观测值按用户请求实时获取，只在当前请求中处理，不写入 SQLite，也不提供 FRED 离线缓存。用户主动执行的 CSV 导出会保留数值、vintage、来源、变换和非背书声明。FRED Key 可从 [FRED API Key 页面](https://fred.stlouisfed.org/docs/api/api_key.html)申请，使用前应阅读 [FRED 当前完整条款](https://fred.stlouisfed.org/legal/terms/)。

This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis.

## GDELT 事件线索

GDELT 不需要 API Key。专题工作台可以添加“外部事件雷达”，信用观察的发行人主档也可以直接打开事件专题。应用只按需查询并缓存标题、原文链接、来源、语言和时间等元数据 12 小时，不抓取或保存新闻正文。

GDELT 匹配是待核验线索，不是事实确认、舆情评分或信用风险判断。请打开原文、核对主体与事件，再把选中的引用加入证据篮并提交到研究项目。公共 API 可能限流；存在缓存时应用会明确降级复用，不能把缓存伪装成本次实时验证。

## 已实现功能

- 外部数据连接器：统一展示 AKShare / AKTools、FRED、World Bank 和 GDELT 的访问、凭据、缓存、许可、署名和研究边界；
- 专题投研工作台：围绕统一研究对象保存市场历史、FRED 图表、World Bank 比较、GDELT 事件雷达、项目摘要和最近证据组件；
- 跨源时间线：按研究活动顺序聚合市场快照、FRED 引用、World Bank 快照、GDELT 线索、笔记、反证、任务、发布复盘和观点变化；
- 证据篮：市场快照、FRED 图表、主权比较和经用户选择的事件引用可以跨页面临时收集，再批量写入研究项目并关联专题；
- 规则化项目摘要：整理问题、假设、结论、支持证据、反证、未完成任务、结论变化、复盘日期和缺失字段，不生成自动投资判断；
- 场景化 AI 洞察：在今日市场、研究项目、信用观察和专题投研中按页面语义生成短摘要，明确可信边界、证据缺口或人工复核任务；独立授权默认关闭，支持手动、数据变化后和每日首次打开；
- 跨源专题综述：按专题整理共同变化、来源分歧、证据缺口和下一步核验，只发送标题级摘要与来源 / 时点元数据；
- 市场变化中心：集中显示上一收盘以来和上次查看后的变化，支持可信门禁、质量阈值、优先级过滤、标记已读和回到原始模块；
- 研究行动助手：把项目缺口整理为任务、反证和复盘草稿，只有勾选并二次确认后写入，支持撤销；
- 任务入口：每日看市场、利率与宏观研究、信用观察、全球跨市场四种默认场景，共享全部数据与研究资产；
- 可配置市场驾驶舱：曲线、期货、现券、事件与外汇可以按偏好显示，提供全景、利率优先、跨市场预设和最近查看入口；
- 跨资产观察：使用本地可信历史显示 10Y 国债与 FDR007 分位、10Y–1Y 曲线、T 主力和 USD/CNY 方向，样本不足时保持为空；
- 市场增强：首页统一展示资金、国债 10Y、期限利差、国债期货、USD/CNY 和 USD/JPY 六项跨市场脉搏；
- 外汇市场：人民币日频参考价覆盖 USD/CNY、EUR/CNY 和 100 JPY/CNY；全球外币对展示银行间买卖询价、中间值和点差；
- 外汇可信边界：即时询价源缺少可信观测时点时标记为部分可用，可搜索和自选，但不写入研究历史、不触发自动提醒；
- 研究首页：汇总进行中项目、待复盘事项、统一自选和宏观数据准备度，并用五步导航连接问题、项目、证据、观点与复盘；
- 市场研究线索：从资金、曲线、期货和现券提炼最多 8 项带来源、观察时间、质量分和显著程度的线索；
- 可信市场快照：把非演示、非异常且质量合格的中国固收市场状态保存到指定研究项目；
- 研究项目：记录研究问题、假设、期限、标签、主观置信度、当前结论和复盘日期，显示六项闭环完成度和下一步，并自动保留状态、置信度、结论与证据变更轨迹；
- 研究生产力：从行情、自选、市场线索一键立项，提供利率、宏观发布、转债事件和信用观察模板，以及笔记、反证、任务、复盘记录；项目支持 JSON/Markdown 导出、JSON 导入和整库备份恢复；
- 可配置市场线索：资金、曲线、期货和现券阈值可在本地调整，每条线索明确展示触发原因；
- 每周研究复盘：按周汇总项目更新、研究笔记、反证、任务、本周观点、下周待验证、下次复盘与到期项目，并可导出 Markdown；
- 自动安全备份：启动时检查研究主库，默认每 24 小时创建经完整性验证的原子快照并滚动保留 14 份；
- 研究证据：FRED 图表只保存序列、来源、观察区间和变换引用，不保存观测值；证据可检查并以当前官方版本重新打开，旧版冻结值会在升级时自动校准为引用；
- 美国宏观与利率：20 条 FRED 精选指标，覆盖政策与流动性、美债利率、通胀、实际利率、就业和增长；
- 图表研究室：支持最多 6 条序列，保留缺失日期，提供原值、单期变化、FRED 官方 `pc1` 同比、归一化和 Z-Score，并支持带来源/vintage 的 CSV 与引用证据保存；
- 全球主权比较：通过无需 API Key 的 World Bank Indicators API v2，比较中国、美国、日本、德国、英国、法国、印度、巴西、南非和印度尼西亚的 10 条精选 WDI 指标；
- 主权比较方法：单次选择 2–8 个经济体和最长 51 年区间，严格按同一年度对齐，支持水平值、单年变化、横截面数值排名与 Z-Score；缺失值保持为空，不跨年填充；
- World Bank 研究闭环：展示覆盖率、最新共同年份、指标元数据、来源、许可和署名；支持 CSV 导出、一键创建“主权基本面比较”项目，并把可信比较快照保存为本地研究证据；
- World Bank 可信缓存：成功请求按经济体、指标和年份持久化 7 天，官方刷新失败时可明确降级到过期缓存；World Bank 有独立健康状态、熔断、重试、统计和清理入口；
- 数据发布日历：展示 FRED 发布计划，并明确区分计划日期和实际数据更新时间；
- 数据发布复盘：先保存用户预期，再按需请求 FRED 官方实际值，比较 surprise 和 vintage 变化，并关联本地中国资金、曲线、期货前后窗口；FRED 实际值仍不写入 SQLite；
- 统一自选：证券、外汇与宏观指标共享分组、标签、研究状态、置顶、备注和复盘日期；宏观与缺少可信时间的外汇数据不会误入行情提醒；
- 今日市场：资金、曲线、现券、期货、外汇与事件一屏总览；
- 资金面：稳定提供 Shibor O/N、Shibor 1W；FR、FDR、LPR 使用独立适配器、缓存和健康状态，单一扩展源失败不影响其他指标；
- 收益率曲线：国债/政策金融债期限结构、前值对比和 BP 变化；
- 收益率曲线研究：10Y–1Y、10Y–5Y、30Y–10Y 利差和 10Y 日变动；
- 历史研究：可信行情自动保存为轻量序列，滚动保留 400 天；曲线源可回填最近交易日；
- 每日固收复盘：自动汇总资金、曲线、期货、现券异动、发行事件和数据说明，区分盘中/收盘口径，展示可信度，支持本地日期归档、Markdown 与打印 PDF；
- 现券市场：收益率、净价、成交量、自选、多条件筛选、分页、可管理保存视图和 CSV 导出；
- 国债期货：TS/TF/T/TL 近季合约；
- 可转债：价格、溢价率、双低值、到期收益率、多条件筛选与保存视图；主比价源失败时切换价格备用源并明确标出缺失字段；
- 发行与事件：国债发行日历；
- 全局搜索：按代码、名称或正股名称搜索现券、国债期货、可转债、外汇、FRED 精选指标和专题研究，并直接定位到对应页面；
- 自选与提醒：跨页面即时同步自选状态，为自选标的创建阈值规则，支持当前值试算、每日触发上限、静默时段、暂停、删除、未读计数、触发历史、最近判断值和 macOS 本地通知；后台调度会在条件首次满足或重新穿越时触发；
- 固收计算器：YTM、全价、应计利息、久期、凸性、DV01、情景价格、现金流，以及 ACT/365、ACT/ACT、30/360 三种计息日规则；
- SQLite 本地存储自选、提醒规则、触发历史、标的索引和最近一次真实行情；
- 信用观察 R2：支持 CSV/Excel 映射导入、单券历史、发行人主档、自定义组合、事件日历和人工确认信号；单券按 20 条分段显示，页签或筛选后自动回到结果区，组合成员支持搜索和仅看已选；仅在字段完整、评级日期有效、收益率与基准同日且期限匹配时机械试算利差，不生成评级或违约概率；
- 每个行情模块展示来源、观测时间、抓取时间、市场状态、数据状态、质量评分、缓存年龄和降级状态。

信用观察仍坚持“人工核验字段 + 严格计算门禁”，不会为了扩充覆盖而把不稳定公开信用字段包装成正式评级数据。主权比较中的数值排名只表示当年指标数值由高到低，不代表信用评级、主权质量或投资建议。

## 技术结构

```text
浏览器 React UI
       │ /api/v1
       ▼
FastAPI 本地服务 ── 最多 2 个隔离数据进程 ── AKShare
       │
       ├── 内存 TTL 热缓存
       ├── SQLite 最近真实行情缓存
       ├── FRED 官方 API（用户 Key / 请求级数据 / 重试熔断与健康状态）
       ├── World Bank API v2（免 Key / 7 天持久缓存 / 主权比较与研究证据）
       ├── GDELT DOC 2.0（免 Key / 按需请求 / 12 小时元数据缓存 / 待核验事件线索）
       ├── AIHubMix（用户 Key / 单并发队列 / 每日预算 / 裁剪上下文 / 四类页面洞察）

```

- `frontend/`：React + TypeScript + Vite，图表使用按需加载的 ECharts；
- `backend/app/`：FastAPI、AKShare/FRED 数据适配、研究项目、缓存、SQLite 和债券计算；
- 全新发布包默认把运行数据放在 `~/Library/Application Support/AKDesk Fixed/`；已有旧版项目检测到本地 `data/` 时继续使用原目录，避免静默迁移；
- API 文档：启动后访问 `http://127.0.0.1:8765/docs`。
